# 双向链表

## 为什么需要双向链表

单链表只有一个方向（next → next → ...）：

- 在单链表中要删除一个节点 px，必须找到 px **前一个节点** pr
- 遍历时不仅要找到 px，还要找到 px 前一个节点 pr
- 插入操作也类似

**双向链表**通过两个指针解决这个问题：
- `next`：指向后面的那个节点
- `prev`：指向前面的那个节点

### 为什么双向链表能实现 O(1) 删除

给定一个节点的指针 `px`，在双向链表中删除该节点只需要操作其前后节点的指针：

```
px->prev->next = px->next;
px->next->prev = px->prev;
free(px);
```

这里我们直接通过 `px->prev` 就知道了前一个节点是谁，不需要再次遍历。而在单链表中，给定 `px` 根本无法知道它的前驱是谁——必须从头遍历链表找到前驱节点，时间复杂度为 O(n)。这就是双向链表的核心优势：**在已知节点指针的前提下，删除和插入操作的时间复杂度从 O(n) 降为 O(1)**。

### 单链表 vs 双向链表：性能权衡

| 特性 | 单向链表 | 双向链表 |
|------|---------|---------|
| 每个节点额外内存 | 1 个指针 (8B) | 2 个指针 (16B) |
| 已知节点指针时删除 | O(n) | O(1) |
| 已知节点指针时前插 | O(n) | O(1) |
| 倒序遍历 | 不支持（需反转） | O(1) 通过 prev |
| 代码复杂度 | 低 | 中 |
| 适用范围 | 简单场景、节省内存 | 需要频繁插入/删除、倒序遍历 |

双向链表以**额外 8 字节/节点**（64位系统）的内存开销，换来了删除和前插操作从 O(n) 降为 O(1) 的性能提升。在嵌入式实时系统中，这种权衡往往是值得的。

### LRU 缓存 — 双向链表最经典的工程应用

LRU（Least Recently Used，最近最少使用）缓存管理机制是双向链表最著名的应用场景之一，其核心结构是**双向链表 + 哈希表**：

```
         哈希表 (O(1) 查找)
   +-----------------------+
   | key → Node*           |
   | 1    → [addr_of_node1]|
   | 2    → [addr_of_node2]|
   | ...                    |
   +-----------------------+

   双向链表 (O(1) 插入/删除)
   head → [1|data] ⇄ [2|data] ⇄ [3|data] → tail
          最近使用             最久未使用
```

**工作原理：**
- **get(key)**：哈希表 O(1) 定位节点，将该节点移动到链表头部（表示最近使用过）
- **put(key, value)**：若 key 已存在，更新值并移到头部；若不存在，在头部插入新节点。当缓存满时，删除链表尾部节点（最久未使用）

**为什么必须用双向链表？**
- 将一个节点移动到头部，需要操作其前后两个节点
- 单链表中给定一个节点指针，无法 O(1) 获取其前驱，就无法快速摘除该节点
- 双向链表 + 哈希表的组合被称为**"黄金搭档"**：哈希表提供 O(1) 查找，双向链表提供 O(1) 插入/删除

**嵌入式场景示例：**
- 数据库管理系统的 buffer pool（用 LRU 策略决定哪些 page 换出到磁盘）
- CPU 缓存替换策略
- 嵌入式文件系统的 block 缓存管理

## 双向链表的主要操作

### 增 — 创建一个带头结点的双向链表

```c
/*
 * Cretat_linklist:
 *   创建一个带有头结点的双向链表
 *   返回值: 头结点
 */
struct h_node *Cretat_linklist(struct h_node *l)
{
    int d;
    struct node *p = NULL;
    while (1)
    {
        scanf("%d", &d);
        if (d == 0)
        {
            break;
        }
        p = (struct node *)malloc(sizeof(struct node));
        p->data = d;
        p->next = NULL;
        p->prev = NULL;
        if (l->first == NULL)
        {
            l->first = p;
            l->last = p;
        }
        else
        {
            // 尾插法
            l->last->next = p;
            p->prev = l->last;
            l->last = p;
        }
    }
    return l;
}
```

### 插入排序

```c
void insert_sort(struct h_node *l)
{
    int d;
    struct node *p = NULL;
    struct node *px = NULL;
    while (1)
    {
        scanf("%d", &d);
        if (d == 0)
        {
            break;
        }
        p = (struct node *)malloc(sizeof(struct node));
        p->data = d;
        p->next = NULL;
        p->prev = NULL;
        if (l->first == NULL)
        {
            l->first = p;
            l->last = p;
        }
        else
        {
            px = l->first;
            while (px)
            {
                if (px->data > p->data)
                {
                    break;  // 找到插入位置
                }
                px = px->next;
            }
            if (px == l->first)      // 头插法
            {
                l->first = p;
                p->next = px;
                px->prev = p;
            }
            else if (px == NULL)     // 尾插法
            {
                l->last->next = p;
                p->prev = l->last;
                l->last = p;
            }
            else                     // 中间插入
            {
                px->prev->next = p;
                p->prev = px->prev;
                p->next = px;
                px->prev = p;
            }
        }
    }
}
```

### 打印链表（正序 + 倒序）

```c
void printf_linklist(struct h_node *l)
{
    if (l->first == NULL)
    {
        return;
    }
    // 正序打印
    struct node *p = l->first;
    while (p)
    {
        printf("%d ", p->data);
        p = p->next;
    }
    printf("\n");

    // 倒序打印（利用 prev 指针）
    p = l->last;
    while (p)
    {
        printf("%d ", p->data);
        p = p->prev;
    }
    printf("\n");
}
```

### 删 — 删除一个节点

```c
void delete_x(struct h_node *l, int x)
{
    if (l->first == NULL)
    {
        return;
    }
    struct node *px = l->first;
    while (px)
    {
        if (px->data == x)
        {
            break;  // 找到了！
        }
        px = px->next;
    }

    if (px == l->first)  // 删除第一个节点
    {
        l->first = l->first->next;
        l->first->prev = NULL;
        px->next = NULL;
        free(px);
    }
    else if (px->next == NULL)  // 删除最后一个节点
    {
        l->last = px->prev;
        l->last->next = NULL;
        px->prev = NULL;
        free(px);
    }
    else  // 删除中间节点
    {
        px->prev->next = px->next;
        px->next->prev = px->prev;
        px->next = NULL;
        px->prev = NULL;
        free(px);
    }
}
```

### 删 — 删除所有值为 x 的节点

```c
void delete_all_x(struct h_node *l, int x)
{
    if (l->first == NULL)
    {
        return;
    }
    struct node *px = l->first;
    struct node *pr = NULL;
    while (px)
    {
        if (px->data == x)
        {
            if (px == l->first)
            {
                l->first = l->first->next;
                l->first->prev = NULL;
                px->next = NULL;
                free(px);
                px = l->first;
            }
            else if (px->next == NULL)
            {
                l->last = px->prev;
                l->last->next = NULL;
                px->prev = NULL;
                free(px);
                px = NULL;
            }
            else
            {
                pr = px->next;
                px->prev->next = px->next;
                px->next->prev = px->prev;
                px->next = NULL;
                px->prev = NULL;
                free(px);
                px = pr;
            }
        }
        else
        {
            px = px->next;
        }
    }
}
```

## 嵌入式系统中的真实应用场景

### FreeRTOS 任务调度列表

FreeRTOS 内核使用双向链表管理所有就绪任务。每个优先级对应一个就绪列表，任务的 TCB（Task Control Block）通过双向链表节点链入：

```c
/* FreeRTOS 源码中的链表节点定义（简化） */
typedef struct xLIST_ITEM
{
    TickType_t xItemValue;              /* 任务优先级/延时值 */
    struct xLIST_ITEM *pxNext;          /* 指向下一个节点 */
    struct xLIST_ITEM *pxPrevious;      /* 指向上一个节点 */
    void *pvOwner;                      /* 指向所属的 TCB */
} ListItem_t;

typedef struct xLIST
{
    UBaseType_t uxNumberOfItems;
    ListItem_t *pxIndex;               /* 用于遍历的当前指针 */
    MiniListItem_t xListEnd;           /* 链表末尾哨兵节点 */
} List_t;
```

当一个任务因时间片耗尽需要被切换时，调度器通过双向链表 O(1) 地将任务节点从当前链表摘除并挂到链表末尾。这种频繁的"摘除-重挂"操作正是双向链表的强项。

### 内存管理器的空闲链表

许多嵌入式内存分配器（如 TLSF — Two-Level Segregated Fit）使用双向链表来管理不同大小级别的空闲内存块。因为合并相邻空闲块时需要访问前一个和下一个块：

```c
/* TLSF 空闲块结构（简化） */
typedef struct block_header {
    struct block_header *prev_phys;     /* 前一个物理块 */
    size_t size;                        /* 本块大小（含标志位） */
    struct block_header *next_free;     /* 空闲链表后继 */
    struct block_header *prev_free;     /* 空闲链表前驱 */
} block_header_t;
```

合并时直接用 `prev_phys` 和 `next` 指针判断前后块是否空闲，O(1) 时间复杂度完成合并，避免内存碎片化。

## 面试练习题

### LRU 缓存机制

**虚拟互联网公司甲 2022 · 虚拟电商公司乙 2021**

**题目**：设计一个 LRU（最近最少使用）缓存机制，支持 `get(key)` 和 `put(key, value)` 操作，要求 get 和 put 的时间复杂度均为 O(1)。

**解题思路**：
LRU 缓存的核心是**双向链表 + 哈希表**的组合：
- **哈希表**：以 key 为索引，存储对应链表节点的指针，实现 O(1) 查找
- **双向链表**：按最近使用顺序排列节点，头部为最近使用的节点，尾部为最久未使用的节点

**get(key)**：
1. 哈希表中查找 key，若不存在返回 -1
2. 存在则将对应节点移动到链表头部（表示最近使用），返回 value

**put(key, value)**：
1. 若 key 已存在于哈希表中：更新 value，将节点移到头部
2. 若不存在：
   - 创建新节点，插入链表头部
   - 缓存未满时直接加入哈希表
   - 缓存已满时，删除链表尾部节点（最久未使用），从哈希表中移除，再插入新节点

```c
#define CAPACITY 3  /* 缓存容量 */

/* 双向链表节点 */
typedef struct DLinkedNode {
    int key;
    int value;
    struct DLinkedNode *prev;
    struct DLinkedNode *next;
} DLinkedNode;

/* LRU 缓存结构 */
typedef struct {
    DLinkedNode *head;          /* 虚拟头节点（不存数据） */
    DLinkedNode *tail;          /* 虚拟尾节点（不存数据） */
    int size;                   /* 当前缓存大小 */
    int capacity;               /* 缓存容量 */
    DLinkedNode **hash;         /* 简易哈希表：key -> node* */
} LRUCache;

/* 将节点移到头部 */
void moveToHead(LRUCache *obj, DLinkedNode *node) {
    /* 先把节点从原位摘除 */
    node->prev->next = node->next;
    node->next->prev = node->prev;
    /* 插入到虚拟头节点之后 */
    node->next = obj->head->next;
    node->prev = obj->head;
    obj->head->next->prev = node;
    obj->head->next = node;
}

int lruGet(LRUCache *obj, int key) {
    if (obj->hash[key] == NULL) return -1;
    DLinkedNode *node = obj->hash[key];
    moveToHead(obj, node);  /* 最近使用，移到头部 */
    return node->value;
}

void lruPut(LRUCache *obj, int key, int value) {
    if (obj->hash[key] != NULL) {
        /* key 已存在：更新值并移到头部 */
        DLinkedNode *node = obj->hash[key];
        node->value = value;
        moveToHead(obj, node);
    } else {
        /* key 不存在：创建新节点 */
        DLinkedNode *node = (DLinkedNode *)malloc(sizeof(DLinkedNode));
        node->key = key;
        node->value = value;
        obj->hash[key] = node;
        /* 插入链表头部 */
        node->next = obj->head->next;
        node->prev = obj->head;
        obj->head->next->prev = node;
        obj->head->next = node;
        obj->size++;
        /* 超出容量，删除尾部节点 */
        if (obj->size > obj->capacity) {
            DLinkedNode *removeNode = obj->tail->prev;
            removeNode->prev->next = obj->tail;
            obj->tail->prev = removeNode->prev;
            obj->hash[removeNode->key] = NULL;
            free(removeNode);
            obj->size--;
        }
    }
}
```

**关键点**：为什么用双向链表不用单向？因为在 LRU 中每个操作都可能需要**摘除任意位置的节点**（移动到头部或删除尾部）。单链表无法在 O(1) 时间内获取前驱节点，也就无法完成摘除操作。

### 二叉搜索树转双向链表

**某软件厂商 2019 · 虚拟搜索公司丁 2020**

**题目**：输入一棵二叉搜索树，将该二叉搜索树转换成一个排序的双向链表。要求不能创建任何新的节点，只能调整树中节点指针的指向。链表中的节点按升序排列，且 prev 指向前一个节点，next 指向后一个节点。

**解题思路**：
二叉搜索树的**中序遍历**正好是升序序列。在中序遍历过程中，将每个节点的左右指针重新指向，使其成为双向链表：
- 用 `prev` 指针记录当前已处理链表的最后一个节点
- 当前节点的 `left` 变为链表的 `prev`，`prev` 的 `right` 指向当前节点
- 递归处理，最后返回链表头节点

```c
/* 二叉树节点定义（和链表节点共用结构体） */
struct TreeNode {
    int data;
    struct TreeNode *left;   /* 转换后作为 prev */
    struct TreeNode *right;  /* 转换后作为 next */
};

/* 全局指针：记录当前已转换链表的最后一个节点 */
struct TreeNode *prev = NULL;

/* 中序遍历，同时转换指针指向 */
void inorderConvert(struct TreeNode *node) {
    if (node == NULL) return;

    inorderConvert(node->left);  /* 递归处理左子树 */

    /* 当前节点转换 */
    node->left = prev;           /* left 改为链表 prev 指针 */
    if (prev != NULL) {
        prev->right = node;      /* right 改为链表 next 指针 */
    }
    prev = node;                 /* 更新 prev 为当前节点 */

    inorderConvert(node->right); /* 递归处理右子树 */
}

struct TreeNode *treeToDoublyList(struct TreeNode *root) {
    if (root == NULL) return NULL;
    prev = NULL;
    inorderConvert(root);
    /* 找到链表头节点（最左边的节点） */
    struct TreeNode *head = root;
    while (head->left != NULL) {
        head = head->left;
    }
    return head;
}
```

**核心思路**：二叉搜索树的中序遍历天生就是有序序列，利用递归在中序遍历过程中修改指针指向，不额外申请任何内存空间，空间复杂度为 O(h)，h 为树高（递归栈深度）。

### 回文链表判断（双向链表）

**虚拟生活服务公司戊 2021**

**题目**：给定一个带头结点的双向链表，判断该链表是否为回文链表。

**解题思路**：
由于双向链表同时有 `first` 和 `last` 指针，同时还有 `next` 和 `prev`，我们可以从两端向中间遍历：
- 用 `left` 指针从头部开始向右移动
- 用 `right` 指针从尾部开始向左移动
- 每次比较 `left->data == right->data`
- 当 `left == right`（奇数长度）或 `left->prev == right`（偶数长度）时停止

```c
/**
 * isPalindrome: 判断带头结点的双向链表是否为回文链表
 * @l: 头结点（含 first 和 last 指针）
 * 返回值: 1 表示回文，0 表示非回文
 */
int isPalindrome(struct h_node *l) {
    if (l->first == NULL) {
        return 1;  /* 空链表视为回文 */
    }

    struct node *left = l->first;
    struct node *right = l->last;

    while (left != right && left->prev != right) {
        if (left->data != right->data) {
            return 0;  /* 发现不匹配 */
        }
        left = left->next;
        right = right->prev;
    }
    return 1;
}

/* 测试用例 */
void testPalindrome() {
    /* 测试 1: 1 2 2 1 → YES */
    /* 测试 2: 1 2 → NO */
    /* 测试 3: 1 2 3 4 2 1 → NO */
    /* 测试 4: 1 2 3 4 3 2 1 → YES */
}
```

**对比单链表解法**：如果使用单链表，判断回文需要先找到中间节点（快慢指针），然后反转后半部分，再逐一比较。而双向链表利用 `prev` 和 `last` 指针，从两端向中间遍历即可，不需要反转，代码更简洁。时间复杂度 O(n)，空间复杂度 O(1)。

### 二进制链表转整数

**虚拟通信公司己 2020**

**题目**：给定一个带头结点的双向链表，每个节点存储 0 或 1（高位在 first 端），将二进制数转换为十进制整数。

**解题思路**：
最简单的办法是在遍历过程中逐步构建整数值：从高位开始，`result = result * 2 + node->data`。每向后一个节点，相当于二进制左移一位再加当前位。

也可以利用双向链表从低位开始计算（从 `last` 往 `first` 遍历），用幂次累加，但第一种方法更简洁。

```c
#include <math.h>

/**
 * binaryToInt: 将二进制链表转换为整数
 * @l: 头结点（first 指向最高位）
 * 返回值: 十进制整数值
 *
 * 举例: 1 → 0 → 1 → 0 → 1
 *       1 + 0×2 + 1×4 + 0×8 + 1×16 = 21
 */
int binaryToInt(struct h_node *l) {
    if (l->first == NULL) {
        return 0;
    }

    int result = 0;
    struct node *p = l->first;
    while (p != NULL) {
        result = result * 2 + p->data;
        p = p->next;
    }
    return result;
}

/**
 * binaryToIntByPower: 从低位开始计算（利用双向链表的 last 指针）
 */
int binaryToIntByPower(struct h_node *l) {
    if (l->first == NULL) {
        return 0;
    }

    int result = 0;
    int exp = 0;
    struct node *p = l->last;
    while (p != NULL) {
        result += p->data * (int)pow(2, exp);
        exp++;
        p = p->prev;
    }
    return result;
}
```

**方法一（从高位开始）**：`result = result * 2 + data`，时间复杂度 O(n)，空间 O(1)。这种方法扩展性好，还能用于二进制字符串转整数的场景。

**方法二（从低位开始）**：利用双向链表的 `last` 指针从最低位开始，用 2 的幂次累加。但调用 `pow()` 有浮点数精度问题，推荐方法一。

### 两两交换链表节点

**虚拟互联网公司甲 2021**

**题目**：给定一个双向链表，两两交换其中的相邻节点，并返回交换后的链表。不能只交换节点的 data 域，必须实际交换节点。如果链表长度是奇数，最后一个节点保持不变。

**解题思路**：
使用递归或迭代法。以迭代为例，每次取两个节点 `first` 和 `second`，交换它们的连接关系：
1. 将 `first` 的前驱与 `second` 相连
2. `first->next = second->next`，如果 `second->next` 非空，更新其 `prev`
3. `second->prev = first->prev`
4. `second->next = first`
5. `first->prev = second`
6. 移动指针到下一对

```c
/**
 * swapPairs: 两两交换双向链表的相邻节点
 * @l: 头结点（更新 first 和 last）
 *
 * 输入: 1 2 3 4 5 6 7 8
 * 输出: 2 1 4 3 6 5 8 7
 *
 * 输入: 1 2 3 4 5
 * 输出: 2 1 4 3 5
 */
void swapPairs(struct h_node *l) {
    if (l->first == NULL || l->first->next == NULL) {
        return;  /* 少于2个节点，无需交换 */
    }

    struct node *first = l->first;   /* 当前第一个节点 */
    struct node *prevNode = NULL;    /* 前一对交换后的第二个节点 */

    while (first != NULL && first->next != NULL) {
        struct node *second = first->next;   /* 第二个节点 */
        struct node *nextPair = second->next; /* 下一对的第一个节点 */

        /* 交换 first 和 second */
        first->next = nextPair;
        if (nextPair != NULL) {
            nextPair->prev = first;
        }

        second->prev = first->prev;
        second->next = first;
        first->prev = second;

        /* 更新前驱节点的 next 指针 */
        if (prevNode == NULL) {
            l->first = second;  /* 更新头结点 first */
        } else {
            prevNode->next = second;
        }

        /* 移动到下一对 */
        prevNode = first;
        first = nextPair;
    }

    /* 更新头结点的 last 指针 */
    struct node *p = l->first;
    while (p->next != NULL) {
        p = p->next;
    }
    l->last = p;
}
```

**关键点**：处理指针时需要注意双向链表的 `prev` 和 `next` 都需要正确更新。特别是要处理好边界情况：第一对交换时更新 `first` 指针，最后一对时更新 `last` 指针。

**递归解法（更简洁）**：
```c
struct node *swapPairsRecursive(struct node *head) {
    if (head == NULL || head->next == NULL) {
        return head;
    }
    struct node *newHead = head->next;     /* second 变成新头 */
    struct node *nextPair = newHead->next; /* 下一对 */

    newHead->next = head;      /* second->next = first */
    head->prev = newHead;
    head->next = swapPairsRecursive(nextPair);  /* 递归处理剩余节点 */
    if (head->next != NULL) {
        head->next->prev = head;
    }

    return newHead;
}
```

### 删除排序链表中所有重复节点

**题目**：在一个**排序**的双向链表中，删除所有重复的节点，只保留没有重复出现的节点。注意：不是"去重"，而是把重复的节点**全部删除**。

**解题思路**：
由于链表已排序，重复的节点必定相邻。使用双指针：
- `px` 遍历链表
- 用 `count` 记录当前值出现的次数
- 遇到值变化时，若前一个值出现超过 1 次，则删除所有这些节点
- 需要特别处理头节点和尾节点的边界

```c
/**
 * deleteDuplicates: 删除排序链表中所有重复节点
 * @l: 头结点（更新 first 和 last）
 *
 * 输入: 1 1 2 2 3 4 4 4 5
 * 输出: 3 5
 *
 * 输入: 1 2 2 2 2 2 3 3 4 5
 * 输出: 1 4 5
 */
void deleteDuplicates(struct h_node *l) {
    if (l->first == NULL || l->first->next == NULL) {
        return;  /* 0或1个节点，不可能有重复 */
    }

    struct node *px = l->first;
    struct node *next = NULL;

    while (px != NULL) {
        /* 记录当前值的出现次数 */
        int count = 0;
        struct node *start = px;  /* 当前值的第一个节点 */

        while (px != NULL && px->data == start->data) {
            count++;
            px = px->next;
        }

        if (count > 1) {
            /* 删除所有值为 start->data 的节点 */
            struct node *del = start;
            while (del != px) {  /* px 此时指向下一个不同值的第一个节点 */
                next = del->next;
                if (del == l->first) {
                    l->first = next;
                    if (next != NULL) {
                        next->prev = NULL;
                    }
                } else if (del == l->last) {
                    l->last = del->prev;
                    l->last->next = NULL;
                } else {
                    del->prev->next = del->next;
                    del->next->prev = del->prev;
                }
                free(del);
                del = next;
            }
        }
    }
}
```

**关键点**：
- 利用排序特性，重复节点必然连续，无需哈希表
- 使用 `start` 和 `px` 两个指针确定重复的范围
- 删除时处理三种情况：头节点、尾节点、中间节点
- 时间复杂度 O(n)，空间复杂度 O(1)
