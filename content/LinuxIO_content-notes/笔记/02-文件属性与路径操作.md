# 文件属性与路径操作

> 本章目标：掌握 Linux 中文件权限、路径、删除、截断和属性读取相关接口。

## 1. umask：默认权限掩码

创建文件时，最终权限会受到 `umask` 影响。

```c
#include <sys/stat.h>

mode_t old = umask(0);
```

例如创建文件时传入 `0666`，如果当前 `umask` 为 `0022`，最终权限通常会变成 `0644`。

```text
最终权限 = 请求权限 & ~umask
```

> 自学建议：不要死记数字，先理解 `r=4`、`w=2`、`x=1` 的组合方式。

## 2. 获取当前工作目录

当前工作目录会影响相对路径解析。

```c
#include <unistd.h>
#include <stdio.h>

int main(void) {
    char buf[1024];
    if (getcwd(buf, sizeof(buf)) == NULL) {
        perror("getcwd");
        return 1;
    }
    printf("cwd = %s\n", buf);
    return 0;
}
```

也可以使用会动态分配内存的接口：

```c
char *p = get_current_dir_name();
if (p != NULL) {
    puts(p);
    free(p);
}
```

## 3. 改变当前工作目录

```c
#include <unistd.h>

chdir("/tmp");
```

通过文件描述符切换目录：

```c
int fd = open("/tmp", O_RDONLY | O_DIRECTORY);
fchdir(fd);
close(fd);
```

典型用途：

- 程序启动后切换到资源目录。
- 在递归遍历中临时切换目录。
- 服务程序初始化工作目录。

## 4. 文件截断

`truncate` 可以把文件截断或扩展到指定长度。

```c
#include <unistd.h>

truncate("data.bin", 1024);
```

对已经打开的文件使用：

```c
ftruncate(fd, 1024);
```

注意：

- 变短会丢弃后面的数据。
- 变长通常会用 `0` 填充新区域。
- 修改前应确认目标文件路径，避免误操作。

## 5. 删除文件和目录

删除普通文件：

```c
#include <unistd.h>

unlink("old.log");
```

删除空目录：

```c
rmdir("empty_dir");
```

区别：

| 接口 | 删除对象 |
|---|---|
| `unlink` | 文件名目录项 |
| `rmdir` | 空目录 |

当文件被 `unlink` 后，如果仍有进程打开它，数据会等到最后一个文件描述符关闭后才真正释放。

## 6. stat：读取文件属性

```c
#include <sys/types.h>
#include <sys/stat.h>
#include <unistd.h>
#include <stdio.h>

int main(void) {
    struct stat st;
    if (stat("data.txt", &st) < 0) {
        perror("stat");
        return 1;
    }

    printf("size = %ld\n", (long)st.st_size);
    printf("mode = %o\n", st.st_mode & 0777);
    return 0;
}
```

常见接口：

| 接口 | 说明 |
|---|---|
| `stat(path, &st)` | 按路径读取属性，符号链接会被跟随 |
| `lstat(path, &st)` | 读取符号链接本身属性 |
| `fstat(fd, &st)` | 按文件描述符读取属性 |

## 7. 判断文件类型

```c
if (S_ISREG(st.st_mode)) {
    puts("regular file");
}

if (S_ISDIR(st.st_mode)) {
    puts("directory");
}
```

常见宏：

| 宏 | 含义 |
|---|---|
| `S_ISREG` | 普通文件 |
| `S_ISDIR` | 目录 |
| `S_ISCHR` | 字符设备 |
| `S_ISBLK` | 块设备 |
| `S_ISFIFO` | FIFO |
| `S_ISLNK` | 符号链接 |
| `S_ISSOCK` | socket |

## 8. 路径操作建议

- 写程序时尽量区分“用户输入路径”和“程序内部路径”。
- 使用相对路径前先确认当前工作目录。
- 递归处理目录时注意拼接路径，不要只保存文件名。
- 删除、截断、覆盖文件前，先打印目标路径用于确认。
