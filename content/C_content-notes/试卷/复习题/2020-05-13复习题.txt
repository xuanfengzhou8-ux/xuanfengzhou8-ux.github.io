2020-05-13复习题
1、有以下程序
#include<stdio.h>
Voidf(int*p,int*q);
int Main()
{
intm=1,n=2,*r=&m;
f(r,&n);
printf(“%d,%d,m,n);
}
Voidf(int*p,int*q)
{p=p+1;*q=*q+1;}
程序运行后的输出结果是（）
A 1,3
B 2,3
C 1,4
D 1,2

2、有以下程序
#include<stdio.h>
int b=2;
int fun(int*k)
{
b=*k+b;
return(b);
}
main
{
int a[10]={1,2,3,4,5,6,7,8},i;
for(i=2;i<4;i++) {
b=fun(&a[i])+b;
printf(“%d”,b);
}
printf(“\n”);
}
程序运行后的输出结果是（）
A 10 12
B 8 10
C 10 28
D 10 16
