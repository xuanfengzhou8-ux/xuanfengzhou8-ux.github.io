# 网络编程预备知识

> 本章目标：建立网络编程的基础概念，理解 IP、端口、字节序、网段和协议分层。

## 1. 网络通信需要什么

两台设备能够通信，至少需要两个条件：

1. **物理或链路媒介**：网线、无线网络、虚拟网络等。
2. **通信协议**：双方都理解的数据格式和交互规则。

网络编程关注的是协议和应用接口：应用程序如何把数据交给系统，由系统通过网络发送给对端。

## 2. TCP/IP 分层模型

常用简化模型：

| 层次 | 作用 | 常见协议/内容 |
|---|---|---|
| 应用层 | 定义应用数据格式 | HTTP、FTP、自定义协议 |
| 传输层 | 端到端传输 | TCP、UDP |
| 网络层 | 主机到主机寻址 | IP、ICMP |
| 链路层 | 本地链路传输 | 以太网、Wi-Fi |

分层的好处是：每一层只关心自己的职责。应用层不用直接处理网卡收发细节。

## 3. TCP 与 UDP

| 对比项 | TCP | UDP |
|---|---|---|
| 连接 | 面向连接 | 无连接 |
| 可靠性 | 提供可靠传输 | 不保证可靠 |
| 数据形式 | 字节流 | 数据报 |
| 典型用途 | 文件传输、命令通道 | 实时数据、广播、简单请求 |
| 编程复杂度 | 稍高 | 较低 |

TCP 有连接建立和关闭过程，适合需要可靠顺序传输的场景。UDP 不建立连接，开销小，但丢包、乱序需要应用自己处理。

## 4. IP 地址

IP 地址用于标识网络中的主机接口。IPv4 常用点分十进制表示：

```text
192.168.1.10
```

网络通信时，程序通常需要知道：

- 对端 IP 地址。
- 对端端口号。
- 本地是否需要绑定固定端口。

## 5. 子网掩码与网段

子网掩码用于判断两个 IP 是否处于同一网段。

示例：

```text
IP:      192.168.1.10
mask:    255.255.255.0
network: 192.168.1.0
```

同一网段内通常可以直接通过二层网络通信；不同网段通常需要网关转发。

## 6. 端口号

端口用于区分同一台主机上的不同网络应用。

```text
网络地址 = IP 地址 + 端口号
```

示例：

```text
192.168.1.10:8080
```

端口范围：

| 范围 | 说明 |
|---|---|
| 0 ~ 1023 | 常见系统保留端口 |
| 1024 ~ 49151 | 注册端口 |
| 49152 ~ 65535 | 临时端口 |

## 7. 网络字节序

不同 CPU 可能使用不同字节序。网络协议规定多字节整数使用网络字节序，也就是大端序。

常用转换函数：

```c
htons();  // host to network short
htonl();  // host to network long
ntohs();  // network to host short
ntohl();  // network to host long
```

端口号转换示例：

```c
addr.sin_port = htons(8080);
```

IP 地址转换示例：

```c
inet_pton(AF_INET, "192.168.1.10", &addr.sin_addr);
```

## 8. 网关、路由和交换

| 概念 | 作用 |
|---|---|
| 交换设备 | 扩展局域网连接，转发同一网段内的数据帧 |
| 路由器 | 在不同网络之间选择下一跳 |
| 网关 | 当前主机访问其他网段时的出口 |

做网络调试时，常见检查顺序：

1. 本机 IP 是否正确。
2. 子网掩码是否正确。
3. 网关是否正确。
4. 对端端口是否监听。
5. 防火墙是否拦截。

## 9. 常用排查命令

```bash
ip addr
ip route
ping 192.168.1.1
ss -lntup
```

说明：

| 命令 | 用途 |
|---|---|
| `ip addr` | 查看本机地址 |
| `ip route` | 查看路由表 |
| `ping` | 测试网络可达性 |
| `ss -lntup` | 查看监听端口 |
