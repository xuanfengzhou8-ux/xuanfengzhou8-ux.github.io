2020-05-18复习题
设有6个结点的无向图，该图至少应有（）条边才能确保是一个连通图。
A、5		B、6		C、7		D、8

答案是A。
无向图：任意两顶点之间的边都是无向边，则该图为无向图。
连通图：若无向图中任意两个不同的顶点都连通(即有路径)，则为连通图。
如果一个无向图是连通的，那么边的数目大于等于顶点的数目减一：|E|>=|V|-1，而反之不成立。
没有回路的无向图是连通的当且仅当它是树，即等价于：|E|=|V|-1。
因此最少为顶点的数目减一，即为5。

2、假定x=65530，下面函数的返回值是多少？（ ）
        int func(x)
        {
            int countx=0;
            while(x)
            {
                countx++;
                x=x&(x-1);
            }
            return countx;
        }

A.100			B.14				C.20				D.16

答案：B
        参考解析：
        此函数的作用是为了计算二进制数中的1的个数。65535 = 2的16 -1；
        65530 = 0000 0000 0000 0000 1111 1111 1111 1010 有14个1 是如何计算的呢?
        用一个小点的数来计算：1010 当进入while循环，此时的countx = 1 ；
         x = 1010 & 1001 = 1000 此时的x = 8 第二次进入while循环时 countx = 2
         x = 1000 & 0111 = 0000 此时的x = 0 退出循环，此时输出countx = 2;
