# 目录遍历与递归统计

> 本章目标：学会用 `opendir/readdir/closedir` 遍历目录，并能递归统计目录大小或筛选文件。

## 1. 目录和普通文件的区别

目录也是一种文件，但它的内容由文件系统维护，应用程序通常不直接用 `read` 解析目录内容，而是使用目录操作接口。

常用接口：

| 接口 | 作用 |
|---|---|
| `opendir` | 打开目录 |
| `readdir` | 读取目录项 |
| `closedir` | 关闭目录 |
| `rewinddir` | 回到目录开头 |

## 2. 基本遍历流程

```c
#include <dirent.h>
#include <stdio.h>

int main(void) {
    DIR *dir = opendir(".");
    if (dir == NULL) {
        perror("opendir");
        return 1;
    }

    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL) {
        printf("%s\n", entry->d_name);
    }

    closedir(dir);
    return 0;
}
```

## 3. struct dirent 常用字段

| 字段 | 含义 |
|---|---|
| `d_name` | 目录项名称 |
| `d_type` | 文件类型提示，某些文件系统可能不可用 |

> 实际项目中，如果需要可靠判断文件类型，建议结合 `stat/lstat`。

## 4. 跳过 "." 和 ".."

递归遍历时必须跳过当前目录和父目录：

```c
if (strcmp(entry->d_name, ".") == 0 ||
    strcmp(entry->d_name, "..") == 0) {
    continue;
}
```

否则程序可能无限递归。

## 5. 拼接完整路径

`readdir` 返回的是目录项名称，不是完整路径。递归时要拼接路径。

```c
char child[1024];
snprintf(child, sizeof(child), "%s/%s", path, entry->d_name);
```

注意：

- 不要使用固定太小的缓冲区。
- 用 `snprintf` 比 `sprintf` 更安全。
- 拼接后再调用 `stat` 判断类型。

## 6. 递归统计目录大小

```c
#include <dirent.h>
#include <stdio.h>
#include <string.h>
#include <sys/stat.h>

long long dir_size(const char *path) {
    struct stat st;
    if (lstat(path, &st) < 0) {
        perror("lstat");
        return 0;
    }

    if (S_ISREG(st.st_mode)) {
        return st.st_size;
    }

    if (!S_ISDIR(st.st_mode)) {
        return 0;
    }

    DIR *dir = opendir(path);
    if (dir == NULL) {
        perror("opendir");
        return 0;
    }

    long long total = 0;
    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL) {
        if (strcmp(entry->d_name, ".") == 0 ||
            strcmp(entry->d_name, "..") == 0) {
            continue;
        }

        char child[1024];
        snprintf(child, sizeof(child), "%s/%s", path, entry->d_name);
        total += dir_size(child);
    }

    closedir(dir);
    return total;
}
```

## 7. 遍历目录的常见用途

- 找出某类文件，例如 `.bmp`、`.jpg`、`.log`。
- 构建文件列表。
- 统计目录大小。
- 批量删除临时文件。
- 为电子相册、媒体播放器等项目准备资源列表。

## 8. 易错点

- 忘记跳过 `"."` 和 `".."`。
- 只保存文件名，不保存完整路径。
- 递归层次太深导致栈压力。
- 对 `d_type` 过度依赖，不用 `stat` 复核。
- 目录打开失败后继续使用空指针。
