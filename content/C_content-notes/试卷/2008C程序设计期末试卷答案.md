## 试题一、判断题（共10分，每题1分）

1. **正确（√）**
   - 不同类型的变量在内存中占用的存储空间大小确实可以不一样。例如：char占1字节，int通常占4字节，double通常占8字节。

2. **错误（×）**
   - switch语句中default语句和break语句都不是必须的。default可以省略，break也可以根据需要选择是否使用。

3. **正确（√）**
   - 指针变量确实是把另一个变量的地址作为其值的变量。

4. **错误（×）**
   - 取模运算符%要求两个操作数都必须是整型，2.5是浮点数，因此表达式625%2.5不合法。

5. **正确（√）**
   - 若指针变量指向一维数组的第一个元素，将指针变量加整数3，指针确实会后移3个元素。

6. **错误（×）**
   - 数组名不仅仅是一个符号，它还代表数组的首地址，是一个指针常量。

7. **正确（√）**
   - C语言中所有类型的数据在计算机内部都是以二进制形式存储的。

8. **错误（×）**
   - 格式符"%o"是按8进制输出整数，按16进制输出整数应使用"%x"或"%X"。

9. **正确（√）**
   - 如果s1、s2是两个字符（char类型），C语言中可以用s1==s2比较这两个字符是否相等。

10. **正确（√）**
    - 结构体类型中各成员项的数据类型可以不同，这正是结构体的特点。

## 试题二、单选题（共10分，每题1分）

1. **答案：C（2.0）**
   - 解析：x是double类型，值为1；3/2是整数除法结果为1；1+1=2，由于x是double，结果自动转换为2.0。

2. **答案：B（a[1][1]+1的值为6）**
   - 解析：数组初始化为{{1,2},{4,5},{6,0}}，a[1][1]=5，5+1=6。
   - A错误：a[3][2]越界；C错误：a[2][1]=0；D错误：a[0][0]=1。

3. **答案：C（y,yoy）**
   - 解析：
     - 初始：s="Boy"
     - s[0]=s[2]='y'，s变为"yoy"
     - s[2]=s[0]='y'，s仍为"yoy"
     - s[1]=s[3]='\0'，s变为"y\0y"
     - s[3]=s[1]='\0'
     - printf输出s[0]='y'，字符串s="yoy"（遇到第一个'\0'停止）

4. **答案：B（*pa的值是6.3）**
   - 解析：
     - *pa*=3执行后，a=2.5*3=7.5
     - pa=&b执行后，pa指向b
     - 因此*pa=b=6.3

5. **答案：A（for(;i<100;i++) s=s+i;）**
   - 解析：while循环当i>=100时跳出，即i<100时执行s+=i和i++，与选项A功能相同。

6. **答案：B（b,d,d）**
   - 解析：
     - s='b'（ASCII码98）
     - c1=s++：先赋值c1='b'，再s自增为'c'
     - c2=++s：先s自增为'd'，再赋值c2='d'
     - 此时s='d'
     - 输出：b,d,d

7. **答案：C（花括号）**
   - 解析：C语言中复合语句（语句块）使用花括号{}括起来。

8. **答案：D（无数次）**
   - 解析：while(i=8)中，i=8是赋值表达式，值为8（非0），条件恒为真，形成死循环。

9. **答案：C（int a[6]={}；）**
   - 解析：
     - A错误：不能用表达式6*1
     - B错误：逗号之间必须有值或全部省略
     - C正确：空初始化列表，所有元素初始化为0
     - D错误：应使用大括号{}而非小括号()

10. **答案：B（printf("%s",st[2].name);）**
    - 解析：
      - 数组下标从0开始，Paul在st[2]位置
      - name是字符数组，st[2].name本身就是字符串首地址
      - A和D中name[0]是单个字符，不能用%s

## 试题三、程序阅读（共24分）

### 1. 程序输出结果（6分）

**输入：5782**

**输出结果：**
```
k=2875,s=22
```

**解析：**
- 循环过程：
  - x=5782, d=2, k=2, s=2, x=578
  - x=578, d=8, k=28, s=10, x=57
  - x=57, d=7, k=287, s=17, x=5
  - x=5, d=5, k=2875, s=22, x=0
- k将原数字反转，s计算各位数字之和

### 2. 程序输出结果（6分）

**输出结果：**
```

 8 5 6 9 3 2
 5 6 9 3 2 8

```

**解析：**
- 外层循环执行6次，每次将数组循环左移一位
- 每次移位后输出整个数组

**问题2：输入1-2*10-10/2=，输出结果**

**输出结果：**


- 读入2，计算-20/2=-10，res=-10，data1=-10，op='='

**更正：重新仔细分析**
程序逐个字符读取，包括空格和换行：
- scanf读入1
- getchar读到'-'

- scanf读入10

- getchar读到'/'

## 试题四、程序填空题（共26分，每空2分）

### 1. 温度转换程序

**(1)** `fahr <= upper`

**(2)** `fahr += 2`

**(3)** `%.1f` 或 `%5.1f`

**完整程序：**
```c
#include <stdio.h>
void main( )
{  int fahr, lower, upper;
   double celsius;
   printf("输入 lower:");
   scanf("%d", &lower);
   printf("输出 upper:");
   scanf("%d", &upper);
   printf("fahr  celsius\n");
   for (fahr = lower; fahr <= upper; fahr += 2){
      celsius = 5.0*(fahr-32)/9.0;
      printf("%d   %.1f\n", fahr, celsius);
   }
}
```

### 2. 排序程序

**(1)** `sort(a+2, 6)` 或 `sort(&a[2], 6)`

**(2)** `k = i;`

**(3)** `a[j] < a[k]`

**解析：**
- 第一次排序从第3个元素（下标2）开始，排序6个元素（下标2到7）
- sort函数实现选择排序
- k记录最小值的下标

### 3. 字符串处理程序

**(1)** `str[k] = str[i] - 32` 或 `str[k] = toupper(str[i])`

**(2)** `k++`

**(3)** `i++`

**(4)** `j--`

**解析：**
- 将小写字母转换为大写（ASCII码相差32）
- k记录新字符串的位置
- i遍历原字符串
- j从后向前，k从前向后比较判断对称
