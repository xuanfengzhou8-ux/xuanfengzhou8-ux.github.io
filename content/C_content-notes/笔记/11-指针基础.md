# 指针基础

## 学习目标

- 理解指针的概念：内存地址与指针变量的区别与联系
- 熟练掌握取地址运算符 `&` 和解引用运算符 `*` 的用法
- 理解数组名与指针的关系，明确数组名不是指针变量，以及数组名在哪些场合退化为指针
- 掌握指针运算（加减、比较）及指针算术的含义
- 理解 `const` 与指针的组合规则，能正确从右向左解读声明
- 理解野指针、悬空指针、空指针的区别及其危险性（空指针解引用和野指针解引用都是未定义行为）
- 理解 void* 的用途与限制，掌握指针作为函数参数的典型用法
- 了解指针在嵌入式开发中的核心应用（MMIO、DMA、寄存器操作）

---

## 本章与工作的关系

嵌入式开发无法离开指针，以下是几个核心原因：

1. **直接寄存器访问（MMIO，Memory-Mapped I/O）**：MCU（微控制器）的外设寄存器映射到特定的内存地址。读写寄存器必须通过指针（通常加 `volatile` 修饰）操作。例如配置 GPIO 输出电平、读取 ADC 转换结果，本质上都是对某个地址的解引用。

2. **动态内存管理（堆）**：嵌入式系统中，`malloc` / `free` 返回 `void*` 指针，管理堆内存必须通过指针完成。任务控制块（TCB）、消息队列、缓冲池等底层机制均依赖指针。

3. **DMA（直接存储器访问）传输**：DMA 控制器需要知道源地址、目标地址和传输长度，这些参数通过指针设置。DMA 描述符链表本质上是一个指针结构的数组。

4. **高效传递大数据**：传递大型结构体（如传感器数据帧、图像缓冲区）时，传指针（4 或 8 字节）比传值（可能数百字节）效率高得多，避免了栈拷贝的开销。

5. **回调机制**：函数指针是实现中断服务函数表（ISR table）、定时器回调、状态机跳转的核心手段。

6. **裸机编程的底层特性**：没有操作系统提供抽象层时，链接脚本定义的变量地址、启动代码中的栈指针设置，全部依赖指针。

**一句话总结**：在嵌入式领域，指针不是"高级技巧"，而是"生存技能"。

## 什么是指针

### 内存地址

计算机内存可以看作一排连续编号的"房间"，每个房间有一个唯一的号码 —— 这就是**地址**（Address）。变量就住在一个或多个房间里。例如一个 `int` 可能占用4个连续的房间（4字节），它的地址就是第一个房间的号码。

```
内存示意图：
地址： 0x1000   0x1001   0x1002   0x1003   0x1004   0x1005
       ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
       │      │ │      │ │      │ │      │ │      │ │      │
       └──────┘ └──────┘ └──────┘ └──────┘ └──────┘ └──────┘
       ▲
       │
   变量 a (int, 4字节)
   地址 = 0x1000
```

### 指针变量

**指针变量**（Pointer Variable）是一个特殊的变量，它不存储普通数据，而是存储另一个变量的**地址**。通俗地说：指针变量保存的是"房间号"，而不是房间里的东西。

```c
#include <stdio.h>

int main()
{
    int a = 42;         // 普通变量：a 存整数 42
    int *p;             // 指针变量：p 可以存 int 类型变量的地址

    p = &a;             // 取出 a 的地址，存入 p

    printf("a  的值 = %d\n", a);
    printf("a  的地址 = %p\n", (void *)&a);
    printf("p  的内容（存的地址）= %p\n", (void *)p);
    printf("通过 p 访问 a 的值 = %d\n", *p);

    return 0;
}
```

输出示例（64位Linux系统下，地址值每次运行可能不同）：

```
a  的值 = 42
a  的地址 = 0x7ffeefbff5ac
p  的内容（存的地址）= 0x7ffeefbff5ac
通过 p 访问 a 的值 = 42
```

### 指针类型是什么意思

`int *p` 中的 `int *` 表示"p 是一个指向 int 类型变量的指针"。类型信息告诉编译器：

- 当执行 `*p` 解引用时，应该从地址开始读取多少个字节（`int` 通常是 4 字节）。
- 当执行 `p + 1` 时，地址增加多少（`int *` 增加 4 字节，`char *` 增加 1 字节）。

### 指针的大小

指针的大小取决于系统的地址总线宽度（即平台相关），而不是它指向的类型。

- **32 位系统**：所有指针均为 4 字节
- **64 位系统**（如大多数桌面 Linux、macOS）：所有指针均为 8 字节

```c
#include <stdio.h>

int main()
{
    printf("void*   = %zu 字节\n", sizeof(void *));
    printf("int*    = %zu 字节\n", sizeof(int *));
    printf("char*   = %zu 字节\n", sizeof(char *));
    printf("double* = %zu 字节\n", sizeof(double *));

    return 0;
}
```

在 64 位 Linux 系统下的输出：

```
void*   = 8 字节
int*    = 8 字节
char*   = 8 字节
double* = 8 字节
```

**关键理解**：无论指向什么类型，所有指针的大小相同，因为地址的长度是一样的。类型信息只影响解引用时的读写宽度和指针算术的步长。

## 取地址&与解引用*

这两个运算符是指针操作的核心工具。

### &（取地址运算符）

`&` 后面跟一个变量，返回该变量在内存中的首地址。

```c
int a = 10;
printf("%p\n", (void *)&a);  // 打印 a 的地址
```

### *（解引用 / 间接访问运算符）

`*` 后面跟一个指针变量，表示"访问这个指针所指向的那个对象"。

```c
int a = 10;
int *p = &a;

*p = 20;           // 通过 p 修改 a，等价于 a = 20
printf("%d\n", a); // 输出 20
```

### 完整示例

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 20;
    int *p = &a;    // p 指向 a

    printf("a = %d, *p = %d\n", a, *p);  // a = 10, *p = 10

    *p = 30;        // 通过 p 修改 a 的值
    printf("a = %d, *p = %d\n", a, *p);  // a = 30, *p = 30

    p = &b;         // p 改为指向 b
    *p = 50;        // 通过 p 修改 b 的值
    printf("b = %d, *p = %d\n", b, *p);  // b = 50, *p = 50

    return 0;
}
```

### 关键提示：声明中的 * 与表达式中的 * 是不同的

```c
int *p;      // 声明：* 表示"p 是一个指针变量" —— 语法的一部分
*p = 10;     // 表达式：* 是解引用运算符 —— 访问 p 指向的对象
```

这是初学者最容易混淆的地方。记住：**声明时靠右读，表达式中靠上下文判断**。

## 指针声明与初始化

### 从右向左读

解读指针声明的标准方法是从右向左：

```
int *p;
// 从右向左：p → * → int
// 读作："p 是一个指针，指向 int"
```

```c
int *p;           // p 是 int*（指向 int 的指针）
char *cp;         // cp 是 char*（指向 char 的指针）
double *dp;       // dp 是 double*（指向 double 的指针）
```

### 声明风格

C 语言中指针声明的星号位置有三种写法，含义完全相同：

| 写法 | 示例 | 说明 |
|------|------|------|
| `int *p` | 星号靠近变量名 | C 语言传统风格，强调 `*p` 的类型是 `int` |
| `int* p` | 星号靠近类型 | C++ 风格，强调 `p` 的类型是 `int*` |
| `int * p` | 星号居中 | 两边空格，可读性较好 |

**陷阱提醒**（为什么推荐 `int *p` 而不是 `int* p`）：

```c
int* p, q;   // p 是 int*，但 q 是 int！不是 int*
int *p, q;   // 同样的含义，但视觉上更清楚 q 是 int

int *p, *q;  // 两个都是 int* —— 每个变量前都要加 *
```

**本笔记推荐风格**：`int *p`。

### 初始化

在声明指针的同时初始化是最安全的做法：

```c
int a = 10;
int *p = &a;        // 声明并初始化，p 指向 a

int *q = NULL;      // 初始化空指针（暂不指向任何有效对象）

int *r;             // ❸ 未初始化 —— 野指针！危险！
```

### 未初始化指针（野指针）的危险性

```c
int *p;      // p 中存储的是随机地址（野指针）
*p = 42;     // 未定义行为（UB）！可能：
             // - 崩溃（段错误）
             // - 覆盖其他变量的数据
             // - 看起来正常运行（最危险，bug 潜伏）
```

**最佳实践**：声明指针时总是初始化，要么指向有效对象，要么设为 `NULL`。

## 空指针NULL

### 什么是 NULL

`NULL` 是一个宏，在标准头文件中定义。在 C 语言中，它通常被定义为 `((void*)0)` 或简单地为 `0`。

```c
#include <stddef.h>   // 或 #include <stdio.h>、#include <stdlib.h> 等

int *p = NULL;        // p 不指向任何有效对象
```

C23 标准引入了 `nullptr` 关键字（`nullptr_t` 类型），但在 C23 之前的代码中依然广泛使用 `NULL`。

### 解引用 NULL 是未定义行为

```c
int *p = NULL;
*p = 42;    // 未定义行为（UB）
```

解引用 NULL 指针通常会导致段错误（segmentation fault）和程序崩溃。但更危险的是：由于这是 UB，编译器可能假设"这段代码永远不会执行"并进行激进的优化，导致程序行为变得不可预测。

```c
#include <stdio.h>

int main()
{
    int *p = NULL;

    // 危险！不要这样做
    printf("%d\n", *p);  // 未定义行为，可能崩溃

    return 0;
}
```

### 使用前检查

```c
if (p != NULL)
{
    *p = 100;   // 安全
}
else
{
    // 处理空指针情况
}
```

### 在嵌入式中的意义

在嵌入式开发中，外设寄存器基地址通常通过指针访问。一些外设在某些芯片型号上不存在，其基地址可能为 `0`（或被宏定义为 `NULL`）。此时必须先检查再使用，否则解引用空指针可能导致硬件异常（HardFault）。

```c
// 示意：某个可选外设的基地址
#define OPTIONAL_PERIPHERAL_BASE ((volatile uint32_t *)0x00000000)

void init_optional_peripheral(void)
{
    volatile uint32_t *reg = OPTIONAL_PERIPHERAL_BASE;
    if (reg != NULL)
    {
        *reg = 0x01;   // 安全：确认非空后才操作
    }
}
```

## 指针与数组（CRITICAL SECTION）

数组和指针的关系是 C 语言中最重要的概念之一，也是各种面试题的高频考点。

### 核心结论

**数组名不是指针变量（Array name is NOT a pointer variable）。**

数组名是一个**不可修改的左值**，代表整个数组对象。但在**大多数表达式**中，数组名会隐式转换为指向其首元素的指针。这一点必须牢记。

### 数组名的退化（Decay）

```c
#include <stdio.h>

int main()
{
    int arr[5] = {10, 20, 30, 40, 50};

    // 以下两个值相同，但类型不同
    printf("arr     = %p\n", (void *)arr);      // 退化后：类型 int*，指向 arr[0]
    printf("&arr[0] = %p\n", (void *)&arr[0]);  // 类型 int*

    // 数组名退化为指针后，可以赋值给指针变量
    int *p = arr;       // arr 退化为 &arr[0]，等价于 int *p = &arr[0];
    printf("p       = %p\n", (void *)p);

    // 通过指针访问数组元素
    printf("p[2] = %d\n", p[2]);   // p[2] 等价于 arr[2]

    return 0;
}
```

### 数组名不退化为指针的例外情况

数组名保持数组类型的三种例外：

1. **`sizeof(arr)`**：计算的是整个数组的字节数
2. **`&arr`**：取数组的地址，得到的是 `int(*)[N]`（数组指针），而非 `int*`
3. **字符串字面量用于初始化字符数组**：`char s[] = "hello";` 中的 `"hello"` 不会退化为指针

```c
#include <stdio.h>

int main()
{
    int arr[5] = {1, 2, 3, 4, 5};
    int *p = arr;

    printf("sizeof(arr)  = %zu\n", sizeof(arr));   // 20 (5 * 4，64位Linux int为4字节)
    printf("sizeof(p)    = %zu\n", sizeof(p));      // 8（64位系统）

    printf("arr 的值     = %p\n", (void *)arr);     // 类型 int*
    printf("&arr 的值    = %p\n", (void *)&arr);    // 数值相同，但类型是 int(*)[5]
    printf("arr + 1      = %p\n", (void *)(arr + 1));  // 偏移 4 字节（一个 int）
    printf("&arr + 1     = %p\n", (void *)(&arr + 1)); // 偏移 20 字节（整个数组）

    return 0;
}
```

输出示例（64位Linux系统下）：

```
sizeof(arr)  = 20
sizeof(p)    = 8
arr 的值     = 0x7ffdf8423f10
&arr 的值    = 0x7ffdf8423f10
arr + 1      = 0x7ffdf8423f14
&arr + 1     = 0x7ffdf8423f24
```

**关键洞察**：`arr` 和 `&arr` 的数值相同（都是数组首地址），但类型不同：
- `arr` 退化为 `int*`，指向首元素
- `&arr` 是 `int(*)[5]`，指向整个数组（因此 `&arr + 1` 跳过整个数组）

### 指针算术

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;

// p + i 的地址 = p 的地址 + i * sizeof(int)
printf("*(p + 0) = %d\n", *(p + 0));  // 10
printf("*(p + 1) = %d\n", *(p + 1));  // 20
printf("*(p + 2) = %d\n", *(p + 2));  // 30
printf("*(p + 3) = %d\n", *(p + 3));  // 40
printf("*(p + 4) = %d\n", *(p + 4));  // 50
```

### 下标的本质

`p[i]` 是 `*(p + i)` 的语法糖。因此：

```c
arr[i]   == *(arr + i)   == *(p + i)   == p[i]
```

所有以下写法等价：

```c
#include <stdio.h>

int main()
{
    int arr[5] = {10, 20, 30, 40, 50};
    int *p = arr;
    int i = 2;

    printf("arr[i]    = %d\n", arr[i]);      // 30
    printf("*(arr+i)  = %d\n", *(arr + i));  // 30
    printf("*(p+i)    = %d\n", *(p + i));    // 30
    printf("p[i]      = %d\n", p[i]);        // 30

    return 0;
}
```

### 数组与指针对比表

| 特性 | 数组名 `arr` | 指针变量 `p` |
|------|-------------|-------------|
| 类型 | `int [N]` | `int *` |
| 存储 | 编译器分配，固定位置 | 变量，占用栈/数据段空间 |
| 可否重新赋值指向 | **不可以**（不是可修改左值） | **可以**（随时指向不同的对象） |
| `sizeof` | 整个数组的字节数 `N * sizeof(元素)` | 指针本身的字节数（4 或 8） |
| `&arr` vs `&p` | `&arr` 得到 `int(*)[N]`（数值相同但类型不同） | `&p` 得到 `int**`（指针变量的地址） |
| `arr++` / `p++` | **非法**（数组名不是左值） | 合法（指针前移一个元素） |

## 指针与const

`const` 和指针组合时，有三个变体，其含义取决于 `const` 在 `*` 的哪一侧。

### 从右向左读

解读方法：从右向左读声明，`const` 修饰它左边的最近内容（如果 `const` 在最左边，则修饰右边的最近内容）。

### 三种组合

#### 1. `const int *p`（指向 const int 的指针）

`const` 修饰 `int`，即"指向的对象是 const 的"。

```c
const int a = 100;
const int *p = &a;   // 或写成 int const *p = &a;

// *p = 200;         // 编译错误！不能通过 p 修改 a
p = &b;              // 可以！p 本身可以指向别处
```

**数据只读，指针可改**。

#### 2. `int * const p`（const 指针，指向 int）

`const` 修饰 `*p`（指针本身），即"指针本身是 const 的"。

```c
int a = 10, b = 20;
int * const p = &a;

*p = 100;            // 可以！可以通过 p 修改 a
// p = &b;           // 编译错误！不能修改 p 的指向
```

**数据可改，指针固定**。

#### 3. `const int * const p`（const 指针，指向 const int）

两者都 const。

```c
const int a = 100;
const int * const p = &a;

// *p = 200;         // 编译错误！数据只读
// p = &b;           // 编译错误！指针固定
```

**两者都不可改**。

### 阅读方法总结

| 声明 | 从右向左读 | 含义 |
|------|-----------|------|
| `const int *p` | p → * → int → const | p 是一个指针，指向 const int |
| `int const *p` | p → * → const int | 同上，等效写法 |
| `int * const p` | p → const → * → int | p 是一个 const 指针，指向 int |
| `const int * const p` | p → const → * → int → const | p 是一个 const 指针，指向 const int |

### 完整示例

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = 20;

    // 1. pointer to const int
    const int *p1 = &a;
    // *p1 = 100;     // ❌ 编译错误
    p1 = &b;           // ✅ OK

    // 2. const pointer to int
    int * const p2 = &a;
    *p2 = 100;         // ✅ OK
    // p2 = &b;        // ❌ 编译错误

    // 3. const pointer to const int
    const int a2 = 50;
    const int * const p3 = &a2;
    // *p3 = 60;       // ❌ 编译错误
    // p3 = &b;        // ❌ 编译错误

    return 0;
}
```

### 嵌入式应用场景

在嵌入式中，`const` 指针常用于定义只读外设寄存器映射：

```c
// 只读寄存器（如标志位寄存器）
volatile const uint32_t *status_reg = (volatile const uint32_t *)0x40021000;

// 读写寄存器
volatile uint32_t * const gpio_odr = (volatile uint32_t *)0x40020014;
// gpio_odr 是 const 指针（地址固定），指向 volatile uint32_t
```

## 多级指针

### 概念

多级指针是指向指针的指针。`int **p` 表示：
- `p` 的类型是 `int **`（指向 `int*` 的指针）
- `*p` 的类型是 `int *`（一个指向 int 的指针）
- `**p` 的类型是 `int`（一个整数）

### 图解

```
p (int**)       *p (int*)        **p (int)
┌────────┐     ┌────────┐     ┌────────┐
│ 地址A  │ ──→ │ 地址B  │ ──→ │  42    │
└────────┘     └────────┘     └────────┘
```

### 代码示例

```c
#include <stdio.h>

int main()
{
    int a = 42;
    int *p = &a;      // p 指向 a
    int **pp = &p;    // pp 指向 p

    printf("a   = %d\n", a);       // 42
    printf("*p  = %d\n", *p);      // 42
    printf("**pp = %d\n", **pp);   // 42

    // 通过二级指针修改
    **pp = 100;
    printf("a = %d\n", a);         // 100

    return 0;
}
```

### 典型应用：`argv`

`main` 函数的第二个参数 `argv` 就是 `char **`：

```c
int main(int argc, char **argv)
// argv 是指向 char* 的指针
// argv[0] 是 char*（指向第一个参数字符串）
// argv[1] 是 char*（指向第二个参数字符串）
```

### 应用：通过函数修改指针本身

如果要在函数中修改传入的指针（而不是指针指向的内容），需要传递指针的地址：

```c
#include <stdio.h>
#include <stdlib.h>

void allocate_memory(int **ptr, int size)
{
    *ptr = (int *)malloc(size * sizeof(int));
    if (*ptr != NULL)
    {
        (*ptr)[0] = 10;
    }
}

int main()
{
    int *arr = NULL;

    allocate_memory(&arr, 5);  // 传入指针变量的地址
    if (arr != NULL)
    {
        printf("arr[0] = %d\n", arr[0]);  // 10
        free(arr);
    }

    return 0;
}
```

### 更多级数

```c
int ***p3;    // 指向 (int**) 的指针，即三级指针
int ****p4;   // 四级指针
```

在实际工程中，超过三级指针的情况极其罕见，过度使用多级指针会严重降低代码可读性。

## 野指针与悬空指针

这两种指针都是危险的，解引用它们会导致**未定义行为（UB，Undefined Behavior）**。

### 野指针（Wild Pointer）

野指针是指针变量未被初始化，其值是一个随机地址。

```c
int *p;       // 未初始化！p 中存放的是栈上的随机垃圾值
*p = 42;      // UB！向随机地址写入数据
```

**何时出现**：
- 指针变量声明后未赋值
- 指针指向已释放的内存后未置 NULL
- 指针超出变量的作用域（悬空指针的一种）

### 悬空指针（Dangling Pointer）

悬空指针是指针原本指向有效的内存，但该内存已经被释放或回收，指针仍然保留着原来的地址。

**情况一：free 后未置 NULL**

```c
#include <stdlib.h>

int main()
{
    int *p = (int *)malloc(sizeof(int));
    *p = 42;
    free(p);         // 释放内存，但 p 仍然指向该地址
    // *p = 100;     // UB！悬空指针解引用，内存已被回收
    p = NULL;        // ✅ 最佳实践：释放后立即置 NULL
    return 0;
}
```

**情况二：返回局部变量的地址**

```c
#include <stdio.h>

int *dangling(void)
{
    int local = 42;
    return &local;   // 危险！函数返回后，local 的栈空间被回收
}

int main()
{
    int *p = dangling();
    // *p 现在是悬空指针
    printf("%d\n", *p);  // UB：访问已销毁的栈内存
    return 0;
}
```

### 对比总结

| 类型 | 定义 | 产生原因 | 危险性 |
|------|------|---------|--------|
| **野指针** | 指针未初始化，指向随机地址 | 声明后未赋值 | 可能破坏任何内存位置 |
| **悬空指针** | 指针指向已释放/失效的内存 | `free` 未置 NULL；返回局部变量地址 | 可能在不知情下访问已回收内存 |
| **空指针** | 指针为 NULL，不指向任何有效对象 | 显式赋 NULL；malloc 失败 | 解引用是 UB（通常会崩溃） |

### 最佳实践

```c
// 1. 声明时初始化
int *p = NULL;

// 2. free 后置 NULL
free(p);
p = NULL;

// 3. 使用前检查
if (p != NULL)
{
    *p = 42;
}

// 4. 不返回局部变量地址（改用 malloc 或 static）
int *safe_func(void)
{
    int *p = (int *)malloc(sizeof(int));
    if (p != NULL)
        *p = 42;
    return p;    // 调用者负责 free
}
```

## 指针与函数

### 指针作为参数：实现"传引用"效果

C 语言的参数传递是**值传递**。传递指针可以间接实现"传引用"的效果，即在函数内部修改函数外部的变量。

```c
#include <stdio.h>

// 用指针实现 swap
void swap(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main()
{
    int x = 10, y = 20;

    printf("交换前: x = %d, y = %d\n", x, y);

    swap(&x, &y);    // 传入地址

    printf("交换后: x = %d, y = %d\n", x, y);  // x = 20, y = 10

    return 0;
}
```

### 避免拷贝大型结构体

```c
#include <stdio.h>

typedef struct {
    int id;
    char name[64];
    float scores[100];
    // ... 可能还有很多字段
} Student;

// 传指针（高效）：只复制 8 字节的指针
void print_student(const Student *s)
{
    printf("ID: %d, Name: %s\n", s->id, s->name);
    // s->id = 100;    // ❌ const 修饰，不可修改
}

// 传值（低效）：复制整个结构体，可能数百字节
void print_student_by_value(Student s)  // 不推荐
{
    printf("ID: %d, Name: %s\n", s.id, s.name);
}
```

### 指针作为返回值

```c
#include <stdio.h>
#include <stdlib.h>

// 正确：返回 malloc 分配的内存（调用者负责 free）
int *create_array(int size)
{
    int *arr = (int *)malloc(size * sizeof(int));
    if (arr != NULL)
    {
        for (int i = 0; i < size; i++)
            arr[i] = i;
    }
    return arr;
}

// 正确：返回静态变量的地址
int *get_counter(void)
{
    static int counter = 0;
    counter++;
    return &counter;
}

// 错误：返回局部变量的地址（悬空指针）
int *bad_func(void)
{
    int local = 42;
    return &local;   // ❌ 函数返回后 local 被销毁
}

int main()
{
    int *arr = create_array(5);
    if (arr != NULL)
    {
        for (int i = 0; i < 5; i++)
            printf("%d ", arr[i]);
        printf("\n");
        free(arr);
    }

    int *cnt = get_counter();
    printf("counter = %d\n", *cnt);  // 1
    printf("counter = %d\n", *get_counter());  // 2

    return 0;
}
```

## void *

### 概念

`void *` 是**通用指针类型**（generic pointer）。任何类型的指针都可以隐式转换为 `void *`，反之则需要显式转换（在 C 语言中，`void *` 到其他指针的赋值不需要显式强制转换；但在 C++ 中需要）。

### 特性与限制

```c
int a = 42;
void *vp = &a;      // 任何指针都可赋值给 void*

// printf("%d\n", *vp);   // ❌ 编译错误：不能解引用 void*
// vp++                    // ❌ 编译错误：void* 不知道步长

int *p = (int *)vp; // 使用前必须转换为具体类型
printf("%d\n", *p);  // 42
```

- **不能解引用**：编译器不知道目标类型，无法确定读取多少字节。
- **不能进行指针算术**：编译器不知道步长。不过在 GCC 等编译器中，`void *` 的算术被当作 `char *` 处理（非标准扩展）。

### 典型应用

```c
// malloc 返回 void*，自动转换为任意指针类型
int *arr = (int *)malloc(10 * sizeof(int));

// memcpy 接受 void*（来源和目标）
void *memcpy(void *dest, const void *src, size_t n);

// 通用函数，可处理任意类型
void print_bytes(const void *data, size_t size)
{
    const unsigned char *p = (const unsigned char *)data;
    for (size_t i = 0; i < size; i++)
        printf("%02x ", p[i]);
    printf("\n");
}
```

### void* 与 char* 的关系

C 标准要求 `void *` 和 `char *` 具有相同的表示和对齐要求。实际上，`char *` 也常用作"通用字节指针"。在 `void *` 被引入之前，`char *` 曾扮演通用指针的角色。

## 嵌入式中的指针

### 内存映射寄存器访问（MMIO）

在嵌入式系统中，外设寄存器被映射到特定的内存地址。读写这些地址需要使用指针，并且通常需要 `volatile` 关键字来防止编译器优化。

```c
// 定义寄存器基地址
#define GPIOA_BASE      0x40020000U
#define GPIOA_MODER     (*(volatile uint32_t *)(GPIOA_BASE + 0x00))
#define GPIOA_ODR       (*(volatile uint32_t *)(GPIOA_BASE + 0x14))
#define GPIOA_BSRR      (*(volatile uint32_t *)(GPIOA_BASE + 0x18))

// 设置 PA5 为输出（MODER 寄存器的 bit[11:10] = 01）
GPIOA_MODER &= ~(0x3 << 10);   // 清零
GPIOA_MODER |= (0x1 << 10);    // 设置为输出模式

// 点亮 LED（PA5 输出高电平，使用 BSRR 寄存器）
GPIOA_BSRR = (1 << 5);

// 熄灭 LED（PA5 输出低电平，使用 BSRR 寄存器的高半字）
GPIOA_BSRR = (1 << (5 + 16));
```

**这段代码逐行解释**：

1. `GPIOA_BASE` 是 GPIOA 外设的起始地址（STM32 系列中的典型值）。
2. `GPIOA_MODER`：将基地址 + 0x00 处的内存解释为 `volatile uint32_t`。`volatile` 防止编译器将读写操作优化掉，因为寄存器的值可能被硬件改变。
3. 通过写 `GPIOA_MODER` 配置引脚模式，通过 `GPIOA_BSRR` 控制引脚电平。

### volatile 的重要性

```c
// 没有 volatile 时，编译器可能优化成只读一次
uint32_t *flag_reg = (uint32_t *)0x40021000;
while (*flag_reg == 0)  // 可能被优化为无限循环，因为编译器认为 *flag_reg 不变
{
    // 等待硬件设置标志位
}

// 正确的做法
volatile uint32_t *flag_reg = (volatile uint32_t *)0x40021000;
while (*flag_reg == 0)  // 每次循环都从内存读取
{
    // 等待硬件设置标志位
}
```

### DMA 描述符

DMA 传输中，描述符通常是一个结构体，包含源地址、目标地址、传输长度等指针字段：

```c
typedef struct {
    volatile uint32_t   next;         // 下一个描述符地址
    volatile uint32_t   src_addr;     // 源地址
    volatile uint32_t   dst_addr;     // 目标地址
    volatile uint32_t   ctrl;         // 控制字
    volatile uint32_t   status;       // 状态
} DMA_Descriptor;

// 定义描述符数组
DMA_Descriptor dma_desc[4] __attribute__((aligned(16)));

// 配置传输
dma_desc[0].src_addr = (uint32_t)src_buffer;   // 源指针转为地址值
dma_desc[0].dst_addr = (uint32_t)dst_buffer;   // 目标指针转为地址值
dma_desc[0].ctrl = (1024 << 0) | (1 << 31);    // 长度 1024，启用
```

### 函数指针在中断向量表中的使用

```c
// 中断向量表本质上是一个函数指针数组
typedef void (*ISR_Func)(void);

// 在启动文件中，向量表定义为：
ISR_Func __attribute__((section(".isr_vector"))) vector_table[] = {
    (ISR_Func)0x20010000,          // 栈顶指针
    reset_handler,                 // 复位中断
    NMI_Handler,                   // NMI
    HardFault_Handler,             // 硬件错误
    // ...
};
```

## 面试直连

### Q1: 指针和数组的区别是什么？

**A:**
- **数组**是一段连续内存空间的集合，数组名代表整个数组对象。数组名的值在大多数表达式中退化为指向首元素的指针，但数组名**不是**指针变量。
- **指针**是一个存储地址的变量，可以重新指向不同的对象。
- 关键区别点：
  - `sizeof(arr)` 返回整个数组的字节数，`sizeof(p)` 返回指针本身的字节数（4或8）。
  - `&arr` 类型为 `int(*)[N]`（数组指针），`&p` 类型为 `int**`。
  - 数组名不可赋值（不是可修改左值），指针可以重新指向。

### Q2: 什么是空指针？什么是野指针？什么是悬空指针？有什么区别？

**A:**

| 类型 | 定义 | 产生原因 | 可否安全解引用 |
|------|------|---------|-------------|
| 空指针 | 值为 NULL 的指针 | `int *p = NULL;` | ❌ 解引用是 UB |
| 野指针 | 未初始化，值随机 | 声明后未赋值 | ❌ 解引用是 UB |
| 悬空指针 | 指向已释放/失效内存 | `free` 后未置 NULL；返回局部变量地址 | ❌ 解引用是 UB |

- **空指针**可以安全地检查：`if (p != NULL) { ... }`
- **野指针和悬空指针**无法通过简单检查发现，更危险。
- 最佳实践：声明时初始化，`free` 后置 NULL。

### Q3: `const int *p` 和 `int * const p` 有什么区别？怎么读？

**A:**
- `const int *p`（从右向左读：p 是一个指针，指向 const int）：**数据只读，指针可改**。不能通过 `*p` 修改指向的值，但可以让 `p` 指向别处。
- `int * const p`（从右向左读：p 是一个 const 指针，指向 int）：**数据可改，指针固定**。可以通过 `*p` 修改值，但不能让 `p` 指向别处。
- 记忆口诀：`const` 在 `*` **左侧**，修饰**指向的对象**；`const` 在 `*` **右侧**，修饰**指针本身**。

### Q4: `void*` 是什么？有什么用途和限制？

**A:**
- `void*` 是通用指针类型，可以指向任何类型的数据。
- **用途**：
  - `malloc`、`calloc` 等内存分配函数返回 `void*`
  - `memcpy`、`memset`、`memcmp` 等内存操作函数接受 `void*`
  - 实现通用数据结构（如链表的节点可以存储任意类型数据）
- **限制**：
  - **不能解引用**：编译器不知道目标类型
  - **不能做指针算术**：编译器不知道步长（GCC 扩展除外）
  - 使用前必须转换为具体类型

### Q5: 为什么指针有不同的类型（类型的意义是什么）？

**A:**
虽然所有指针变量的大小相同（地址长度相同），但指针的类型信息告诉编译器：

1. **解引用时读取多少字节**：`int*` 解引用读 4 字节，`char*` 读 1 字节。
2. **指针算术的步长**：`int* + 1` 跳 4 字节，`char* + 1` 跳 1 字节。
3. **类型安全检查**：编译器可以检查类型是否匹配，防止误用。
4. **并不是所有指针大小都相同**：在早期或特殊架构上（如 8086 的 far/near 指针），不同类型指针的大小可能不同。

### Q6: 数组名在什么情况下会被当作指针？什么情况下不是？

**A:**
**被当作指针**（退化为指向首元素的指针）：在大多数表达式中，包括：
- 将数组名赋值给指针
- 数组名作为函数参数
- 数组名参与算术运算（`arr + i`）

**保持数组类型**（不退化为指针）：
- `sizeof(arr)`：此时计算整个数组大小
- `&arr`：取数组地址，得到数组指针 `int(*)[N]`
- 字符串字面量初始化字符数组：`char s[] = "hello";`

### Q7: `sizeof(arr)` 和 `sizeof(pointer)` 有什么区别？

**A:**
```c
int arr[10] = {0};
int *p = arr;

sizeof(arr);   // 40（64位系统 int 4 字节 × 10）
sizeof(p);     // 8（64位系统，指针本身大小）

// 当数组作为函数参数时，退化为指针
void func(int arr_param[])   // 等价于 void func(int *arr_param)
{
    sizeof(arr_param);       // 8，退化为指针！（这是常见错误）
}
```

**面试常见陷阱**：认为在函数内部对数组参数使用 `sizeof` 能得到数组大小，实际上退化成了指针。

### Q8: 什么是解引用？解引用空指针会发生什么？

**A:**
- **解引用**（Dereference）是通过指针访问其指向的内存内容的操作，使用 `*` 运算符：`*p`。
- 解引用空指针是**未定义行为（UB）**。
  - 典型表现：段错误（segmentation fault），程序崩溃。
  - 编译器优化带来的风险：编译器可能假设"代码不会解引用空指针"，从而优化掉空指针检查，导致程序行为异常。
  - **即使只是读取**（`printf("%d", *p)` 其中 p 为 NULL），也同样是 UB。
- 正确做法：解引用前总是检查指针是否为 NULL。

### 阅读题 1

```c
#include <stdio.h>

int main()
{
    int arr[] = {1, 2, 3, 4, 5};
    int *p = arr;

    printf("%d\n", *(p + 3));
    printf("%d\n", p[1] + p[4]);

    return 0;
}
```

**问**：输出是什么？

**答案**：
```
4
7
```
- `*(p + 3)`：p 指向 arr[0]，偏移 3 个元素后指向 arr[3]，即 4。
- `p[1] + p[4]`：p[1] 是 arr[1] = 2，p[4] 是 arr[4] = 5，和为 7。

```c
#include <stdio.h>

int main()
```

**问**：在 64 位 Linux 系统（int 4 字节）上，如果 arr 的地址是 0x1000，输出的各值是什么？

**答案**：
```
sizeof(arr) = 20     // 5 × 4 字节
sizeof(p)   = 8      // 64位指针大小
arr + 1     = 0x1004 // 偏移一个 int（4 字节）
&arr + 1    = 0x1014 // 偏移整个数组（20 字节）
```

### 阅读题 3

```c
#include <stdio.h>

void modify(int *p)
{
    static int temp = 999;
    p = &temp;
}

int main()
{
    int a = 10;
    int *ptr = &a;

    modify(ptr);
    printf("%d\n", *ptr);

    return 0;
}
```

**问**：输出是什么？有没有 bug？

**答案**：
输出 `10`。函数 `modify` 的参数 `p` 是**指针的副本**，在函数内修改 `p` 本身（让它指向 `temp`）不会影响外部的 `ptr`。如果要在函数中修改指针本身，需要传递 `int **`（指针的指针）或返回新指针。这段代码没有 UB，只是达不到预期目的——它没有产生 bug，但逻辑是错误的。

### 阅读题 4

```c
#include <stdio.h>

int *get_value(void)
{
    int x = 42;
    return &x;
}

int main()
{
    int *p = get_value();
    printf("%d\n", *p);

    int y = 100;
    printf("%d\n", *p);

    return 0;
}
```

**问**：这段代码有什么问题？两次输出的结果可能是怎样的？

**答案**：
这段代码有**悬空指针**问题。函数 `get_value` 返回了局部变量 `x` 的地址，函数返回后 `x` 的栈空间被回收。`p` 成为悬空指针。

- 第一次 `*p`：可能还能输出 42（栈上的旧数据还没被覆盖），但这是 UB。
- 第二次 `*p`：声明 `y` 时复用了同一块栈空间，`*p` 的值可能变为 100，也可能变为任意值——这是**未定义行为**。

**永远不要返回局部变量的地址**。

### 阅读题 5

```c
#include <stdio.h>

void func(int arr[5])
{
    printf("sizeof(arr) = %zu\n", sizeof(arr));
}

int main()
{
    int arr[5] = {0};
    printf("sizeof(arr) = %zu\n", sizeof(arr));
    func(arr);
    return 0;
}
```

**问**：两次 `sizeof` 的输出分别是多少？为什么？

**答案**：
```
sizeof(arr) = 20     // main 中：arr 是真正的数组，5 × 4 = 20
sizeof(arr) = 8      // func 中：arr 参数退化为指针，64位系统指针 8 字节
```

原因：函数的数组参数实际上就是指针参数，`int arr[5]` 等价于 `int *arr`，函数内部并不知道数组的大小。这是一个常见的陷阱。

### 练习 2：用指针遍历数组（下标和指针两种方式）

```c
#include <stdio.h>

int main()
{
    int arr[] = {10, 20, 30, 40, 50, 60};
    int len = sizeof(arr) / sizeof(arr[0]);

    // 方式一：下标法（使用数组下标访问）
    printf("下标法: ");
    for (int i = 0; i < len; i++)
    {
        printf("%d ", arr[i]);
    }
    printf("\n");

    // 方式二：指针法（使用指针算术遍历）
    printf("指针法: ");
    int *p = arr;
    for (int i = 0; i < len; i++)
    {
        printf("%d ", *(p + i));  // 或 p[i]
    }
    printf("\n");

    // 方式三：指针移动法（直接移动指针）
    printf("移动指针: ");
    for (int *q = arr; q < arr + len; q++)
    {
        printf("%d ", *q);
    }
    printf("\n");

    return 0;
}
```

### 练习 3：自己实现 strlen（用指针算术）

```c
#include <stdio.h>

// 要求：不使用下标运算符 []，仅使用指针算术实现
size_t my_strlen(const char *s)
{
    // 你的代码
}

int main()
{
    char str[] = "Hello, Embedded World!";

    printf("字符串: \"%s\"\n", str);
    printf("长度: %zu\n", my_strlen(str));

    return 0;
}
```

**参考实现**：

```c
size_t my_strlen(const char *s)
{
    const char *p = s;
    while (*p != '\0')
    {
        p++;
    }
    return (size_t)(p - s);  // 指针相减得到元素个数
}
```

**说明**：`p - s` 的结果是 `ptrdiff_t` 类型（有符号整型），但 `strlen` 返回 `size_t`（无符号整型），所以需要强制转换。另外注意，`s` 和 `p` 都是 `const char *`，确保不会意外修改字符串内容。

### 练习 4：实现函数返回多个值（通过指针参数）

```c
#include <stdio.h>

// 要求：编写一个函数，接收一个整数数组和数组长度，
// 通过指针参数返回数组的最大值、最小值、和、平均值
// 函数原型：
void analyze_array(const int *arr, size_t len,
                   int *max, int *min, int *sum, float *avg)
{
    // 你的代码
}

int main()
{
    int data[] = {23, 45, 12, 67, 34, 89, 5, 78};
    size_t count = sizeof(data) / sizeof(data[0]);

    int max_val, min_val, sum_val;
    float avg_val;

    analyze_array(data, count, &max_val, &min_val, &sum_val, &avg_val);

    printf("数组: ");
    for (size_t i = 0; i < count; i++)
        printf("%d ", data[i]);
    printf("\n");

    printf("最大值: %d\n", max_val);
    printf("最小值: %d\n", min_val);
    printf("之和: %d\n", sum_val);
    printf("平均值: %.2f\n", avg_val);

    return 0;
}
```

**参考实现**：

```c
void analyze_array(const int *arr, size_t len,
                   int *max, int *min, int *sum, float *avg)
{
    if (arr == NULL || len == 0 || max == NULL || min == NULL || sum == NULL || avg == NULL)
        return;  // 参数检查

    *max = arr[0];
    *min = arr[0];
    *sum = 0;

    for (size_t i = 0; i < len; i++)
    {
        if (arr[i] > *max) *max = arr[i];
        if (arr[i] < *min) *min = arr[i];
        *sum += arr[i];
    }

    *avg = (float)(*sum) / len;
}
```

**注意**：如果数组长度很大，`*sum += arr[i]` 可能导致**有符号整数溢出**，这是未定义行为（UB）。在需要处理大数组的工业级代码中，应该使用 `long long` 或分段累加等方式避免溢出。

## 本章总结

- **指针是存储地址的变量**。指针类型决定了解引用时的读写宽度和指针算术的步长。
- **指针的大小取决于平台**（32位=4字节，64位=8字节），与指向的类型无关。
- **`&` 取地址，`*` 解引用**。声明中的 `*` 和表达式中的 `*` 含义不同，需注意区分。
- **数组名不是指针变量**。数组名在大多数表达式中退化为指向首元素的指针，但 `sizeof(arr)` 和 `&arr` 是例外。
- **指针算术的偏移量 = 偏移的元素个数 × 元素大小**。`p[i]` 本质上是 `*(p + i)` 的语法糖。
- **NULL 指针解引用是未定义行为**，野指针和悬空指针同样危险。声明时初始化，free 后置 NULL。
- **`void*` 是通用指针**，不能解引用，不能做算术，使用前需要转换为具体类型。
- **`const` 与指针组合**：`const` 在 `*` 左侧修饰数据，在 `*` 右侧修饰指针本身。
- **函数参数传指针**可以实现修改外部变量、避免大型数据拷贝。
- **嵌入式开发极度依赖指针**：MMIO 寄存器操作、DMA 描述符、中断向量表、动态内存管理等。
- **有符号整数溢出是未定义行为**，在多元素累加等场景中需要注意。
