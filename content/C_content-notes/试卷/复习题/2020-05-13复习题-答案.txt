2020-05-13复习题-答案
1、有以下程序
#include<stdio.h>
Voidf(int*p,int*q);
int Main()
{
intm=1,n=2,*r=&m;
f(r,&n);
printf(“%d,%d,m,n);
}
Voidf(int*p,int*q)
{p=p+1;*q=*q+1;}
程序运行后的输出结果是（）
A 1,3
B 2,3
C 1,4
D 1,2

答案：A 注意C语言中函数的值传递规律

2、有以下程序
#include<stdio.h>
int b=2;
int fun(int*k)
{
b=*k+b;
return(b);
}
main
{
int a[10]={1,2,3,4,5,6,7,8},i;
for(i=2;i<4;i++) {
b=fun(&a[i])+b;
printf(“%d”,b);
}
printf(“\n”);
}
程序运行后的输出结果是（）
A 10 12
B 8 10
C 10 28
D 10 16

答案：C
b是全局变量，当b=2时，i<4符合，执行b=fun(&a[i])+b对于fun(&a[i])得b=a[2]+2=5所以b=b+b=10
i++,i=3,i<4符合fun(&a[i])，得b=a[3]+10=14,b=b+b=28所以答案是C

输入一个整数将其倒着输出，如54321——12345
参考答案：
1. （方法一）
#include<stdio.h>
#include<conio.h>
#include<string.h>
main()
{
      char a[100];
      int len,i;
      printf("请输入一个整数:\n");
      scanf("%s",a);
      len=strlen(a);
      for(i=len-1;i>=0;i--)
      printf("%c",a[i]);
getch();
}
（方法二）
#include<stdio.h>
#include<conio.h>
main()
{
      int num,t;
      printf("请输入一个整数:\n");
      scanf("%d",&num);
      while(num>0)
      {
                  t=num%10;
                  num=num/10;
                  printf("%d",t);
      }
getch();
}
在这里强调一下，由于所给答案是在vs上的版本，头文件 conio.h不是标准头文件，函数getch()是在这conio.h中的头文件，所以也不是标准函数。大家认得这个就好，但是在写程序的时候不需要加上这些，按照标准的来就行。
总结：这个题给大家的启示就是如果题目没有要求你输入的是什么类型，输入的时候只要符合题目要求就行，本题既可以用字符串输入，又可以用整数输入。此题的基本思想是将一个数倒着输出来。当用字符串输入的时候，可以联想到求字符串长度的公式strlen()，注意此函数包含在string.h头文件，故要引入此头文件，并且此函数的本质是根据字符串的结束符判断字符串长度。当求到字符串长度之后，问题基本解决了，按索引输出即可。当用整数输入的时候，如果我们直接求其长度，反而会比较麻烦，所以我们选择依次取得最后一个数字从后往前输出就可以了，重点就是大家一定要灵活掌握如何取得一个N位数的某个数字，通常用到%或者/，即可做到，请大家注意两者的区别。
