# 正则表达式基础

> 本章目标：理解正则表达式不是“神秘符号”，而是一种描述文本模式的语言。

## 1. 正则表达式适合解决什么问题

正则表达式用于描述一类字符串，而不是某一个固定字符串。例如：

- 匹配所有 `.c` 文件名。
- 检查字符串是否像 IP 地址。
- 找出以 `#include` 开头的代码行。
- 从日志中筛选日期、错误码或关键字段。

## 2. 普通字符与特殊字符

普通字符会匹配它本身：

```text
abc
```

可以匹配文本中的 `abc`。

特殊字符有额外含义，例如：

| 符号 | 含义 |
|---|---|
| `.` | 任意单个字符 |
| `^` | 行首 |
| `$` | 行尾 |
| `*` | 前一个元素重复 0 次或多次 |
| `+` | 前一个元素重复 1 次或多次 |
| `?` | 前一个元素重复 0 次或 1 次 |
| `[]` | 字符集合 |
| `()` | 分组 |
| `|` | 或 |

## 3. 字符集合

匹配一个数字：

```regex
[0-9]
```

匹配一个小写字母：

```regex
[a-z]
```

匹配一个十六进制字符：

```regex
[0-9a-fA-F]
```

排除数字：

```regex
[^0-9]
```

## 4. 重复次数

| 写法 | 含义 |
|---|---|
| `a*` | `a` 出现 0 次或多次 |
| `a+` | `a` 出现 1 次或多次 |
| `a?` | `a` 出现 0 次或 1 次 |
| `a{3}` | `a` 恰好出现 3 次 |
| `a{2,5}` | `a` 出现 2 到 5 次 |

匹配 1 到 3 位数字：

```regex
[0-9]{1,3}
```

## 5. 行首与行尾

匹配以 `error` 开头的行：

```regex
^error
```

匹配以 `.c` 结尾的行：

```regex
\.c$
```

注意：`.` 是特殊字符，如果要匹配真正的点号，需要写成 `\.`。

## 6. 分组与或

匹配 `error` 或 `failed`：

```regex
(error|failed)
```

匹配简单的日志级别：

```regex
(INFO|WARN|ERROR)
```

## 7. 在 grep 中使用

使用扩展正则：

```bash
grep -E "^(INFO|ERROR)" app.log
```

匹配 C 语言 include 行：

```bash
grep -E '^#include[[:space:]]+<' *.c
```

匹配空行：

```bash
grep -n '^$' file.txt
```

## 8. 在 C 语言中使用 regex API

C 标准库提供了 POSIX 风格的正则接口，常用流程是：

1. `regcomp` 编译正则表达式。
2. `regexec` 执行匹配。
3. `regfree` 释放资源。

示例：

```c
#include <regex.h>
#include <stdio.h>

int main(void) {
    regex_t reg;
    const char *pattern = "^[0-9]{1,3}(\\.[0-9]{1,3}){3}$";
    const char *text = "192.168.1.10";

    if (regcomp(&reg, pattern, REG_EXTENDED) != 0) {
        return 1;
    }

    int ok = regexec(&reg, text, 0, NULL, 0) == 0;
    printf("match = %d\n", ok);

    regfree(&reg);
    return 0;
}
```

## 9. 易错点

- 正则里的 `.` 不等于普通点号，要匹配点号需要转义。
- shell 中使用正则时，建议用引号包起来，避免被 shell 先解释。
- 不同工具支持的正则语法略有差异，遇到问题先确认工具文档。
- 正则只适合处理规则明确的文本，不适合解析复杂嵌套结构。
