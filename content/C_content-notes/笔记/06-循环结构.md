# 循环结构

## 学习目标

完成本模块的学习后，应能够：

1. 理解循环（loop）的本质：将一段代码重复执行有限或无限次数。
2. 掌握 `for` 循环的完整语法，理解三个表达式的各自含义；了解 C99 起循环变量的作用域规则；能写出并解读 `for(;;)` 无限循环。
3. 掌握 `while` 循环（先判断后执行，可能执行 0 次）和 `do - while` 循环（先执行后判断，至少执行 1 次）的语法和适用场景。
4. 理解 `break` 和 `continue` 的区别：`break` 终止整个循环，`continue` 跳过本次循环的剩余部分。
5. 理解嵌套循环的复杂度含义，能够在嵌套循环中使用 `break`（注意只跳出当前层）。
6. 了解常见的循环优化手段：循环展开（loop unrolling）、避免循环内重复计算、嵌入式中的循环计时（cycle counting）。
7. 识别并避免循环相关的常见错误：永真/永假条件、数组越界、错误修改循环变量、浮点数做循环计数器。
8. 掌握循环与数组配合的遍历模式（正序、逆序、相邻元素）。
9. 回答不少于 5 道面试高频问题，完成至少 3 道代码阅读题和 3 道编程练习题。

---

## 本章与工作的关系

循环结构是程序中最频繁执行的部分，直接决定系统的吞吐量和实时性。

- **嵌入式主循环（super loop）：** 裸机嵌入式程序最常见的结构就是 `while (1) { /* ... */ }`，每次循环处理传感器采集、通信收发、控制输出。
- **数据处理和过滤：** 循环遍历数组或缓冲区（buffer），对每个采样点执行滤波（filtering）或阈值判断。循环效率直接影响采样率。
- **DMA 数据传输后的遍历：** DMA（Direct Memory Access，直接内存访问）完成数据传输后，CPU 通常用循环遍历结果缓冲区。此时循环的指令数直接计入实时任务的 deadline。
- **通信协议解析：** 报文拆包、CRC（Cyclic Redundancy Check，循环冗余校验）计算、帧边界扫描都依赖循环。

因此，写好循环——不仅要能跑对，还要知道它跑多快——是嵌入式 C 工程师的核心基本功。

## 一、`for` 循环详解

### 1.1 直觉

"从 1 加到 100"——你有一种规律：起始值 `1`，每次加 `1`，加到 `100` 为止。`for` 循环正为这种**有明确起、止、步长**的重复而设计。

### 1.2 定义

```c
for (初始化表达式; 条件表达式; 更新表达式)
    循环体语句;
```

三个表达式的各自含义：

| 组成部分 | 位置 | 执行时机 | 作用 |
|---|---|---|---|
| 初始化表达式 | 第一个 `;` 前 | 进入循环前**执行一次** | 设置循环计数器或其他初始状态 |
| 条件表达式 | 第一个 `;` 后 | **每次迭代开始前**求值 | 为真（非零）继续循环；为假（零）退出 |
| 更新表达式 | 第二个 `;` 后 | **每次迭代结束后**执行 | 修改循环计数器或其他循环状态 |

**完整执行流程：**

```
初始化表达式（执行一次）
    ↓
┌→ 条件表达式（为真？） ──假──→ 退出循环
│   ↓ 真
│  循环体语句
│   ↓
│  更新表达式
│   ↓
└── 回到条件表达式 ──┘
```

### 1.3 代码与输出

```c
#include <stdio.h>

int main(void)
{
    int sum = 0;

    /* i 从 1 到 100，步长 +1 */
    for (int i = 1; i <= 100; i++)
    {
        sum += i;
    }

    printf("1 + 2 + ... + 100 = %d\n", sum);

    return 0;
}
```

```
1 + 2 + ... + 100 = 5050
```

### 1.4 循环变量作用域（C99 规则）

在 C99 及以后的标准中，`for` 的初始化部分可以声明变量：

```c
for (int i = 0; i < 10; i++)   /* i 的作用域仅限于这个 for 循环 */
{
    printf("%d ", i);
}
/* 此处 i 已不可见 —— 编译错误 */
```

这一特性由 C99 引入。如果使用 C90 标准（`-std=c90`），在 `for` 的初始化部分声明变量会导致编译错误。因此：

- 面试题中如果提到"在 `for` 里声明的变量循环外是否可用"，答案取决于 C 标准版本：C99 起不可用（作用域在循环内），C90 不允许这种写法。
- 这在不同编译器/标准下行为不同——属于标准版本差异，不是编译器 bug。

### 1.5 `for (;;)` 无限循环

当省略三个表达式时：

```c
for (;;)      /* 初始化省略、条件省略（默认真）、更新省略 */
{
    /* 循环体 —— 无限执行，直到遇到 break 或 return */
}
```

`for (;;)` 和 `while (1)` 在语义上等价，编译器通常会生成相同的机器码。这是一个平台无关的实现行为，不是 C 标准强制规定的——但主流的 GCC、Clang、ARMCC 都做相同处理。

### 1.6 三个表达式均可灵活使用

`for` 的三部分不仅仅是 `i++` 和 `i < n`。

```c
#include <stdio.h>

int main(void)
{
    /* 多个变量同时更新，使用逗号运算符 */
    for (int i = 0, j = 10; i < j; i++, j--)
    {
        printf("i = %d, j = %d\n", i, j);
    }

    /* 更新表达式可以是任何表达式，不只是 i++ */
    for (int n = 100; n > 0; n /= 2)
    {
        printf("n = %d\n", n);
    }

    return 0;
}
```

## 二、`while` 循环详解

### 2.1 直觉

"只要温度超过阈值，就继续冷却；一旦降到阈值以下，就停止。"你不知道会循环多少次——取决于运行时的实际数据。`while` 循环适合这种**循环次数不确定、先检查条件**的场景。

### 2.2 定义

```c
while (条件表达式)
    循环体语句;
```

先计算条件表达式，为真（非零）则执行循环体；执行完循环体后再次计算条件，直到条件为假退出。循环体**可能一次都不执行**（入口条件循环，entry-condition loop）。

### 2.3 代码与输出

```c
#include <stdio.h>

int main(void)
{
    int n;
    printf("请输入一个正整数: ");
    scanf("%d", &n);

    /* 逆序输出各位数字 */
    printf("逆序: ");
    while (n > 0)
    {
        printf("%d", n % 10);    /* 输出最低位 */
        n /= 10;                 /* 去掉最低位 */
    }
    printf("\n");

    return 0;
}
```

```
输入: 12345  →  逆序: 54321
输入: 7      →  逆序: 7
输入: 0      →  逆序:       (条件 n > 0 为假，完全不执行)
```

**注意：** 输入 `0` 时循环体一次都不执行，没有任何输出。这是 `while` 与 `do - while` 的重大区别。

### 2.4 哨兵控制循环（sentinel-controlled loop）

哨兵（sentinel）是一个特殊标记值，用于指示输入结束。这种模式在通信协议处理和交互式输入中非常常见。

```c
#include <stdio.h>

int main(void)
{
    int value;
    int sum = 0;
    const int SENTINEL = -1;     /* 哨兵值：表示输入结束 */

    printf("请输入整数（输入 -1 结束）:\n");
    while (1)
    {
        scanf("%d", &value);
        if (value == SENTINEL)
        {
            break;               /* 遇到哨兵即终止循环 */
        }
        sum += value;
    }

    printf("总和: %d\n", sum);

    return 0;
}
```

```
输入: 10 20 30 -1  →  总和: 60
```

**嵌入式应用：** UART（通用异步收发器）接收数据时，常以 `0x0D 0x0A`（回车换行）或自定义帧尾作为哨兵。

## 三、`do - while` 循环详解

### 3.1 直觉

"显示菜单，然后读取用户选择；如果用户没选"退出"，就继续显示菜单。"——菜单至少显示一次。`do - while` 适合这种**循环体至少需要执行一次**的场景。

### 3.2 定义

```c
do
    循环体语句;
while (条件表达式);      /* 注意末尾有分号！ */
```

先执行一次循环体，再判断条件。为真则重复，为假则退出。循环体**至少执行一次**（出口条件循环，exit-condition loop）。

### 3.3 代码与输出

```c
#include <stdio.h>

int main(void)
{
    int x = 10;

    /* while：条件为假，一次都不执行 */
    printf("while: ");
    while (x < 5)
    {
        printf("进入循环 ");
        x++;
    }
    printf("(退出, x = %d)\n", x);

    /* do - while：先执行一次，再判断 */
    x = 10;
    printf("do-while: ");
    do
    {
        printf("进入循环 ");
        x++;
    }
    while (x < 5);
    printf("(退出, x = %d)\n", x);

    return 0;
}
```

```
while: (退出, x = 10)
do-while: 进入循环 (退出, x = 11)
```

### 3.4 典型应用：输入验证循环

```c
#include <stdio.h>

int main(void)
{
    int score;

    do
    {
        printf("请输入成绩 (0-100): ");
        scanf("%d", &score);
    }
    while (score < 0 || score > 100);   /* 条件为真时继续循环（重新输入） */

    printf("有效成绩: %d\n", score);

    return 0;
}
```

```
请输入成绩 (0-100): -5
请输入成绩 (0-100): 105
请输入成绩 (0-100): 85
有效成绩: 85
```

**嵌入式场景：** 等待硬件外设就绪——先发出操作指令，再检查状态寄存器，若未就绪则重试。

```c
/* 概念示意：等待 ADC 转换完成 */
do
{
    /* 启动 ADC 转换（写触发寄存器） */
    ADC_CR = 0x01;
    /* 读取状态寄存器 */
    status = ADC_SR;
}
while ((status & ADC_READY_BIT) == 0);   /* 未就绪则重试 */
```

**注意：** 上述 ADC 示例中的寄存器直接操作是特定于 MCU 硬件的语法（如 `ADC_CR` 是 8051 或 ARM Cortex 外设的寄存器名），不同芯片的命名和位定义不同。这里只是展示 `do - while` 在硬件轮询（polling）中的典型用法。

## 四、`break` 与 `continue`

### 4.1 `break`：终止整个循环

`break` 立即终止**当前所在的最内层循环**（或 `switch` 结构），程序继续执行循环外的下一条语句。

```c
#include <stdio.h>

int main(void)
{
    int primes_found = 0;
    int n = 2;

    while (1)
    {
        /* 检查 n 是否为素数，简化版 */
        int is_prime = 1;
        for (int d = 2; d * d <= n; d++)
        {
            if (n % d == 0)
            {
                is_prime = 0;
                break;           /* 只终止内层 for 循环 */
            }
        }

        if (is_prime)
        {
            printf("%d ", n);
            primes_found++;
            if (primes_found >= 5)
            {
                break;           /* 终止外层 while 循环 */
            }
        }
        n++;
    }
    printf("\n");

    return 0;
}
```

```
2 3 5 7 11
```

**关键点：** `break` 只跳出**一层循环**。如果在多层嵌套循环中需要跳出外层，要么用标志变量（flag），要么将多层循环封装在一个函数中用 `return` 替代。

### 4.2 `continue`：跳过本次循环的剩余部分

`continue` 跳过本次循环后面的代码，直接进入下一次迭代的条件判断（`while` / `do - while`）或更新表达式（`for`）。

```c
#include <stdio.h>

int main(void)
{
    int sum = 0;
    int count = 0;

    while (count < 10)
    {
        count++;
        if (count == 5)
        {
            continue;           /* 跳过 printf 和 sum += count */
        }
        printf("%d ", count);
        sum += count;
    }
    printf("\n总和 (不含5): %d\n", sum);

    return 0;
}
```

```
1 2 3 4 6 7 8 9 10
总和 (不含5): 50
```

**注意：** `for` 循环中使用 `continue` 时，更新表达式**仍会执行**（更新表达式处于循环体之后、条件判断之前）。而在 `while` 循环中，`continue` 会跳过循环体内后续代码直接回到条件判断。这是一个容易引发错误的行为差异。

```c
for (int i = 0; i < 10; i++)
{
    if (i == 3) continue;   /* 跳过 printf，但 i++ 仍会执行 */
    printf("%d ", i);
}
/* 输出: 0 1 2 4 5 6 7 8 9 */

int i = 0;
while (i < 10)
{
    if (i == 3) continue;   /* 跳过 printf 和 i++，导致 i 永远等于 3，死循环！ */
    printf("%d ", i);
    i++;
}
```

这是 C 标准规定的行为，所有编译器都遵从这个语义。

### 4.3 多层循环中的 `break` —— 只跳出一层

```c
#include <stdio.h>

int main(void)
{
    for (int i = 0; i < 3; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            if (i == 1 && j == 1)
            {
                break;    /* 只跳出内层 for (j) 循环 */
            }
            printf("(%d, %d) ", i, j);
        }
        printf("\n");
    }

    return 0;
}
```

```
(0, 0) (0, 1) (0, 2)
(1, 0)
(2, 0) (2, 1) (2, 2)
```

**如何跳出多层循环？** 面试高频问题，见面试直连 Q2。

## 五、循环嵌套与复杂度

### 5.1 嵌套循环

一个循环的循环体内包含另一个完整的循环，称为嵌套循环（nested loop）。

```c
#include <stdio.h>

int main(void)
{
    /* 打印 9×9 乘法表 */
    for (int i = 1; i <= 9; i++)
    {
        for (int j = 1; j <= i; j++)
        {
            printf("%d*%d=%-2d ", j, i, i * j);
        }
        printf("\n");
    }

    return 0;
}
```

```
1*1=1
1*2=2  2*2=4
1*3=3  2*3=6  3*3=9
...（略）
```

### 5.2 时间复杂度

嵌套循环的**时间复杂度**（time complexity）是内层循环迭代次数的总和。

- 二层循环都循环 `n` 次：总迭代 ≈ `n * n` → **O(n^2)**
- 外层 `n` 次，内层 `i` 次（如乘法表）：总迭代 ≈ `n * (n+1) / 2` → 仍然是 **O(n^2)**

在嵌入式系统中，O(n^2) 的嵌套循环要格外留意：当输入规模翻倍时，执行时间变为 4 倍。如果硬实时系统（hard real-time system）中有一个 O(n^2) 的循环在中断服务函数（ISR, Interrupt Service Routine）中运行，可能导致错过 deadline。

## 六、循环优化基础

> 以下优化手段的效果**高度依赖于目标平台**（CPU 架构、内存层次结构、编译器版本和优化级别）。在应用任何优化之前，应明确：这是特定编译器/硬件的可实现行为，不是 C 标准的要求。

### 6.1 避免循环内重复计算

将循环内不变的表达式提到循环外面：

```c
/* 低效：每轮都计算 strlen —— O(n^2) */
for (int i = 0; i < strlen(s); i++) { /* ... */ }

/* 高效：先在循环外计算一次 len */
size_t len = strlen(s);
for (int i = 0; i < len; i++) { /* ... */ }
```

在 `-O2` 或以上优化级别下，现代 GCC 可能会自行将 `strlen` 提到循环外（如果编译器能证明字符串长度不变），但不是所有编译器都做这个优化。**不要依赖编译器的优化智能**。

### 6.2 循环展开（loop unrolling）

循环展开是指手动将多次迭代的代码复制展开，减少循环开销（条件判断和跳转）：

```c
/* 原始：每次迭代处理 1 个元素 */
for (int i = 0; i < 16; i++)
{
    out[i] = in[i] * coeff;
}

/* 展开 4 次：每轮处理 4 个元素，循环次数从 16 减为 4 */
for (int i = 0; i < 16; i += 4)
{
    out[i]     = in[i]     * coeff;
    out[i + 1] = in[i + 1] * coeff;
    out[i + 2] = in[i + 2] * coeff;
    out[i + 3] = in[i + 3] * coeff;
}
```

**注意：** 手动循环展开会降低代码可读性和可维护性。高频嵌入式库（如 CMSIS-DSP）中常见展开版本，但应用代码一般不推荐这么做。先用编译器优化标志（`-O2 -funroll-loops`），profile 确认瓶颈后再手动展开。

### 6.3 嵌入式中的循环计时（cycle counting）

在嵌入式实时系统中，需要精确知道循环的执行时间（用 CPU 时钟周期衡量）。常用的方法：

```c
#include <stdint.h>

/* 概念示意：读取硬件定时器/周期计数器 */
/* 不同 MCU 的 API 完全不同，这里是通用伪代码 */
uint32_t start = read_cycle_counter();
for (int i = 0; i < 100; i++)
{
    process(data[i]);
}
uint32_t end = read_cycle_counter();
uint32_t total_cycles = end - start;
float avg_cycles = (float)total_cycles / 100.0f;
```

- 对于 Cortex-M3/M4 及以上内核，可以使用 DWT（Data Watchpoint and Trace）模块的 `CYCCNT` 寄存器。
- 对于更简单的 MCU，可以 toggle GPIO 引脚在循环前后各翻转一次，用示波器或逻辑分析仪测量脉宽。
- 上述读取硬件计数器的方法**不跨平台**，取决于具体 MCU 和调试工具。

## 七、常见错误

### 7.1 循环条件永真或永假

```c
/* 条件永假 —— 循环体永远不执行 */
for (int i = 10; i < 0; i--)   /* 初始 i = 10，10 < 0 为假，直接跳过 */
{
    printf("永远不会输出");
}

/* 条件永真 —— 无限循环（如果循环体内没有 break） */
int x = 1;
while (x > 0)    /* x 始终为正，永不退出（除非在循环体内修改 x 或 break） */
{
    x = 1;       /* x 恒为 1，死循环 */
}
```

### 7.2 数组越界

循环中使用数组时，最容易犯的错误是下标越界：忘记数组下标从 0 开始，导致多访问了一个元素。

```c
#include <stdio.h>

int main(void)
{
    int a[5] = {10, 20, 30, 40, 50};

    /* 错误：i <= 5 导致越界访问 a[5]（不存在）—— 未定义行为 */
    for (int i = 0; i <= 5; i++)
    {
        printf("a[%d] = %d\n", i, a[i]);
    }

    /* 正确：i < 5 */
    for (int i = 0; i < 5; i++)
    {
        printf("a[%d] = %d\n", i, a[i]);
    }

    return 0;
}
```

越界访问产生**未定义行为**（undefined behavior, UB）：可能读回错误的值、可能破坏其他变量、可能在嵌入式系统中触发硬件错误（HardFault）。它不定式给程序正确的执行——一切都是"未定义"的。

### 7.3 循环变量在循环体中被错误修改

```c
/* 错误：在循环体内意外修改循环变量 */
int n = 10;
while (n > 0)
{
    printf("%d ", n);
    n--;   /* 在复杂代码中可能被条件屏蔽或重复执行，导致行为异常 */
}
```

更隐蔽的问题是：用 `n--` 的同时又在循环体内修改了判断 `n` 的其他条件，导致循环提前或延迟退出。

### 7.4 浮点数做循环计数器

浮点数（`float` / `double`）不能精确表示所有十进制小数，累积误差会导致循环次数偏离预期。

```c
/* 问题：0.1 在二进制中循环小数，累积误差导致本应执行 10 次却只能执行 9 次 */
for (float x = 0.0f; x != 1.0f; x += 0.1f)   /* 浮点数 == 比较极不可靠 */
{
    printf("x = %f\n", x);
}
```

**正确做法：** 用整数计数器控制循环，需要浮点值时再计算。

```c
/* 正确：整数控制循环，浮点值由整数推导 */
for (int i = 0; i <= 10; i++)
{
    float x = i / 10.0f;    /* 从整数推导出浮点值，无累积误差 */
    printf("x = %f\n", x);
}
```

## 八、循环与数组遍历模式

### 8.1 正序遍历

```c
int a[] = {2, 4, 6, 8, 10};
int n = 5;
for (int i = 0; i < n; i++)
{
    printf("%d ", a[i]);
}
/* 输出: 2 4 6 8 10 */
```

### 8.2 逆序遍历

```c
for (int i = n - 1; i >= 0; i--)
{
    printf("%d ", a[i]);
}
/* 输出: 10 8 6 4 2 */
```

**注意：** `i` 的类型应为 `int`（有符号整数）。如果声明为 `size_t`（无符号），`i >= 0` 永远为真，因为无符号数永远不会小于 0，循环退不出——这就是无符号循环变量的陷阱。

### 8.3 相邻元素对

```c
for (int i = 0; i < n - 1; i++)
{
    printf("(%d, %d) ", a[i], a[i + 1]);
}
/* 输出: (2, 4) (4, 6) (6, 8) (8, 10) */
```

这种模式在冒泡排序、差分计算（如传感器信号的相邻差值）中非常常见。

## 九、面试直连

**Q1：`for` 循环和 `while` 循环在性能上有区别吗？**

A：在语义等价的前提下（如 `for (int i = 0; i < n; i++)` vs `int i = 0; while (i < n) { ...; i++; }`），编译器通常生成相同的机器码。**C 标准没有规定性能差异**——主流编译器（GCC、Clang、ARMCC）在优化级别 `-O1` 以上会产生相同的汇编输出。所以性能不是选择依据，而是代码的语义贴合度：计数循环用 `for`，条件控制用 `while`。

**Q2：如何跳出多层嵌套循环？**

A：C 语言的 `break` 只能跳出当前最内层的一层循环。跳出多层循环的常见方案有三种：

1. **标志变量（flag）：** 在外层判断一个标志位，内层在需要退出时设置标志并 `break`，外层检测标志后也 `break`。
2. **`goto`：** 用 `goto` 跳出多层循环到指定的标签位置。虽然 `goto` 名声不好，但跳出多层嵌套循环是被广泛接受的合理用法（参考 Linux 内核、Linus Torvalds 的观点）。
3. **封装为函数 + `return`：** 将多层循环放在一个单独的函数中，需要退出时直接 `return`。

```c
/* 方法 1：标志变量 */
int found = 0;
for (int i = 0; i < 3 && !found; i++)
{
    for (int j = 0; j < 3 && !found; j++)
    {
        if (matrix[i][j] == target)
        {
            found = 1;
        }
    }
}

/* 方法 2：goto（合理使用） */
for (int i = 0; i < 3; i++)
{
    for (int j = 0; j < 3; j++)
    {
        if (matrix[i][j] == target)
        {
            goto found;
        }
    }
}
found:
    /* 继续执行 */
    ;
```

**Q3：`for (;;)` 和 `while (1)` 哪个更好？区别在哪？**

A：两者在语义上等价，主流编译器对二者生成完全相同的机器码。这是一种平台相关行为（各编译器实现自由），不是 C 标准规定的。个人或团队风格偏好是选择的唯一理由。在嵌入式裸机主循环中，两种写法都极为常见。没有性能或正确性差异。

**Q4：`break` 和 `continue` 的区别是什么？**

A：`break` 立即终止整个循环（或 `switch`），程序继续执行循环之后的第一条语句。`continue` 跳过本次循环的剩余语句，立即进入下一次迭代。对于 `for` 循环，`continue` 后更新表达式仍会执行；对于 `while` 循环，`continue` 后直接回到条件判断。

**Q5：为什么不能用浮点数做循环计数器？**

A：两个原因：(1) 浮点数的二进制表示不能精确存储大多数十进制小数（如 0.1），多次累加会产生累积误差（rounding error），导致循环次数偏离预期。(2) 浮点数的相等比较（`==`）本身不可靠。解决方案：用整数计数器控制循环，需要浮点值时由整数推导。

**Q6：什么是循环展开？什么时候有用？**

A：循环展开是将多次迭代的循环体手动复制一份，以减少循环控制（条件判断和跳转）的开销。在嵌入式 DSP（数字信号处理）或向量运算中，减少循环开销可以显著加速处理。但手动展开会降低可读性，建议先用编译器优化标志（如 GCC 的 `-funroll-loops`），profile 证明瓶颈后再动。

**Q7：嵌入式 `while (1)` 主循环中，如何保证一个任务的执行周期固定？**

A：通常用硬件定时器产生周期中断（tick interrupt）或者在循环中查询定时器。简单方案：使用 `while (1)` 配合定时器标志。

```
volatile uint32_t tick_1ms = 0;

void SysTick_Handler(void)    /* 1ms 中断服务函数，原型因 MCU 而异 */
{
    tick_1ms++;
}

int main(void)
{
    uint32_t last = tick_1ms;
    while (1)
    {
        if (tick_1ms - last >= 10)    /* 每 10ms 执行一次 */
        {
            last = tick_1ms;
            do_task();
        }
    }
}
```

**注意：** 上面的代码使用了 Cortex-M 的 SysTick 定时器（系统嘀嗒定时器）。不同 MCU 的中断服务函数名和定时器配置 API 完全不同——这里只是演示基于标志的循环定时模式，不是可移植的代码。

```c
#include <stdio.h>

int main(void)
{
    int a[] = {3, 1, 4, 1, 5, 9, 2, 6};
    int n = sizeof(a) / sizeof(a[0]);

    for (int i = 0; i < n / 2; i++)
    {
        int temp = a[i];
        a[i] = a[n - 1 - i];
        a[n - 1 - i] = temp;
    }

    }

}
```

### 题 3

```c
#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 5; i++)
    {
        if (i % 2 == 0)
            continue;

        for (int j = 1; j <= i; j += 2)
        {
            printf("%d ", j);
        }
        printf("\n");
    }

    return 0;
}
```

**问题：** 程序输出是什么？

<details>
<summary>答案</summary>
```
1
1 3
1 3 5
```
外层 `continue` 跳过偶数 `i`（2 和 4）。只在 `i` 为 1、3、5 时执行内层。内层 `j` 从 1 开始，步长 2，输出奇数。

## 本章总结

1. **三种循环结构：** `for`（计数控制，三部分集中）、`while`（先判断后执行，适合条件控制）、`do - while`（先执行后判断，至少执行一次）。
2. **`for` 循环**的初始化部分（C99 起）可声明变量，其作用域限于循环内。`for (;;)` 是无限循环的常见写法。
3. **`break`** 终止当前最内层循环；**`continue`** 跳过本次循环剩余部分。注意二者在 `for` 和 `while` 中的行为差异（`continue` 在 `for` 中仍执行更新表达式）。
4. **嵌套循环**的 `break` 只跳出一层。跳出多层循环的常见方案：标志变量、`goto`、封装函数 + `return`。
5. 循环优化（**提取不变计算**、**循环展开**）效果依赖编译器优化级和目标平台，profile 后再动手。
6. 常见错误：浮点数做计数器、数组越界（用 `<` 而非 `<=`）、无符号循环变量的死循环陷阱、条件永假永不执行。
7. 编译时始终使用 `gcc -std=c11 -Wall -Wextra -Wpedantic`。
