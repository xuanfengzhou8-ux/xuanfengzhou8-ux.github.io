# 树和二叉树

---

## 一、树的基本概念

### 定义

树 (Tree) 是由 n (n ≥ 0) 个节点的有限集。在任意一棵非空树中：
1. 有且只有一个特定的被称为**根节点 (Root)** 的节点
2. 当 n > 1 时，其余节点可以分成 m (m > 0) 个互不相交的有限集 T1, T2, T3...，其中每一个有限集又可以组成一棵树，称为根节点的**子树**

### 术语

| 术语 | 含义 |
|------|------|
| **节点的度** | 节点的子树的个数（节点分支的个数） |
| **叶子节点/终端节点** | 度为 0 的节点 |
| **分支节点/非终端节点** | 度不为 0 的节点 |
| **节点的层次** | 从根节点开始，根节点是第一层，根的孩子是第二层... |

---

## 二、二叉树 (Binary Tree)

### 定义

二叉树是一种树型结构，每个节点**至多只有两个分支**（两棵子树），不存在度大于 2 的节点，且有**左右之分**，次序不可以颠倒。

### 二叉树的 5 种状态

1. 空集（空树）
2. 只有一个节点（没有孩子节点）
3. 只有一个左孩子
4. 只有一个右孩子
5. 有左右孩子

---

## 三、二叉树的性质

### 性质 1

> 在二叉树中第 i 层上至多有 **2^(i-1)** 个节点

（数学归纳法证明）

### 性质 2

> 深度为 k 的二叉树至多有 **(2^k) - 1** 个节点

1 + 2 + 4 + 8 + ... + 2^(k-1) = (2^k) - 1

### 性质 3

> 对于任意一棵二叉树 T，若终端节点数为 n0，度为 2 的节点数为 n2，则有 **n0 = n2 + 1**

证明：
- 设 N 为二叉树的节点总数：N = n0 + n1 + n2
- 设 B 为总分支数：从下往上看，除根节点外每个节点对应一个分支，所以 N = B + 1
- 从上往下看：B = n1 + 2·n2
- 代入：n1 + 2·n2 + 1 = n0 + n1 + n2 → **n0 = n2 + 1**

### 性质 4

> 对一棵有 n 个节点的完全二叉树，从左向右、从上向下编号（从 1 开始），编号为 i 的节点：
> - 父节点编号：⌊i/2⌋
> - 左孩子编号：i × 2
> - 右孩子编号：i × 2 + 1

### 性质 5

> 具有 n 个节点的完全二叉树的深度为：⌊log₂n⌋ + 1

---

## 四、满二叉树 vs 完全二叉树

| 类型 | 定义 |
|------|------|
| **满二叉树** | 在不改变高度的情况下不能再增加新节点；深度为 k 且有 (2^k - 1) 个节点 |
| **完全二叉树** | ① 除最后一层外是满二叉树；② 最后一层的节点尽左边排（左边没有空洞） |

> 满二叉树一定是完全二叉树。

## 五、二叉树的存储

### 顺序存储

用一个数组（地址连续空间）保存树的每个节点及关系。

利用完全二叉树的性质：
- 第 i 个节点，双亲节点：i/2，左孩子：i×2，右孩子：i×2+1

对于**非完全二叉树**，先补成完全二叉树，空洞位置留空即可：

```c
#define VERY_BIG 65535
int data[1024];  // 存储 1024 个节点
data[1] = /* 根节点数据 */;
data[2] = /* 根节点左孩子（没有则为 VERY_BIG） */;
data[3] = /* 根节点右孩子 */;
// ...
```

### 链式存储

```c
struct Binode
{
    char data;              // 数据域：用来保存数据
    struct Binode *lchild;  // 指针域：左孩子地址
    struct Binode *rchild;  // 指针域：右孩子地址
};
```

## 六、二叉排序树 (BST)

### 定义

二叉排序树（二叉查找树）或是一棵空树，或满足以下性质：
1. 左子树上所有节点的值 < 根节点的值
2. 右子树上所有节点的值 > 根节点的值
3. 左子树和右子树也是一棵二叉排序树

### 创建过程

将节点插入二叉排序树并保持排序性：
1. **找到插入位置**：新节点一定是新添加的叶子节点，插入位置是查找路径最后一个节点（双亲节点）的孩子
2. **插入操作**：

```c
if (p->data < pr->data)
{
    pr->lchild = p;
}
else
{
    pr->rchild = p;
}
```

### 创建代码

```c
struct Binode *Create_Bitree(void)
{
    char d;
    struct Binode *root = NULL;
    struct Binode *pr = NULL;  // 要插入节点的双亲节点
    struct Binode *px = NULL;  // 遍历二叉排序树找插入位置
    while (1)
    {
        scanf("%c", &d);
        if (d == '#') break;
        struct Binode *p = (struct Binode *)malloc(sizeof(struct Binode));
        p->data = d;
        p->lchild = NULL;
        p->rchild = NULL;
        if (root == NULL)
        {
            root = p;
        }
        else
        {
            px = root;
            while (px)
            {
                if (px->data > p->data)
                {
                    pr = px;
                    px = px->lchild;
                }
                else
                {
                    pr = px;
                    px = px->rchild;
                }
            }
            // 找到插入位置的双亲节点 pr
            if (pr->data > p->data)
                pr->lchild = p;
            else
                pr->rchild = p;
        }
    }
    return root;
}
```

## 七、二叉树的遍历

按照某种方法/路径遍历二叉排序树中的每个节点。约定：节点的左孩子在右孩子前面。

### 三种遍历方式

| 遍历方式 | 顺序 |
|----------|------|
| **先序遍历** | 根 → 左 → 右 |
| **中序遍历** | 左 → 根 → 右 |
| **后序遍历** | 左 → 右 → 根 |

### 遍历方式对比与选用场景

| 遍历方式 | 核心特点 | 典型应用场景 |
|----------|----------|-------------|
| **先序遍历** | 先访问根节点，再递归左右子树 | ① 序列化/反序列化二叉树（配合空标记）；② 打印树形结构（缩进显示）；③ 复制/镜像二叉树 |
| **中序遍历** | 先递归左子树，再访问根，最后右子树 | ① 对 BST 进行升序输出（中序即有序序列）；② 与先序结合还原二叉树结构；③ 二叉搜索树中查找第 k 小元素 |
| **后序遍历** | 先递归左右子树，最后访问根 | ① 计算二叉树高度/深度（先算子树高度再汇总）；② 删除整棵树（先释放子节点再释放根，防止内存泄漏）；③ 计算表达式的值（后缀表达式求值） |
| **层序遍历** | 按层从上到下、从左到右依次访问 | ① 求二叉树宽度（节点最多的一层）；② 判断是否为完全二叉树；③ 打印二叉树的右视图 / 左视图；④ 最短路径问题（BFS 天然最短路径） |

**总结口诀**："先序知根，中序分左右，后序算子树，层序求层级"。

### 递归实现

```c
// 先序遍历
void pre_printf(struct Binode *root)
{
    if (root == NULL) return;
    printf("%c ", root->data);
    pre_printf(root->lchild);
    pre_printf(root->rchild);
}

// 中序遍历
void mid_printf(struct Binode *root)
{
    if (root == NULL) return;
    mid_printf(root->lchild);
    printf("%c ", root->data);
    mid_printf(root->rchild);
}

// 后序遍历
void rea_printf(struct Binode *root)
{
    if (root == NULL) return;
    rea_printf(root->lchild);
    rea_printf(root->rchild);
    printf("%c ", root->data);
}
```

### 层序遍历（利用队列）

```
把根节点入队
while (队列不为空)
{
    访问队首节点
    if (节点有左孩子) 左孩子入队
    if (节点有右孩子) 右孩子入队
    队首元素出队
}
```

```c
void lever_printf(struct Binode *root, struct queue *p)
{
    if (root == NULL || p == NULL) return;
    Enqueue(p, root->data);
    while (!QueueisEmpty(p))
    {
        printf("%c ", p->data[p->front]);
        struct Binode *d = Find_x(root, p->data[p->front]);
        if (d->lchild) Enqueue(p, d->lchild->data);
        if (d->rchild) Enqueue(p, d->rchild->data);
        Outqueue(p);
    }
    printf("\n");
}
```

## 八、二叉排序树的删除

删除一个节点后需保持二叉排序树的性质。

**步骤**：
1. 找到要删除的节点 px 及其父节点 pr
2. 分情况讨论：
   - **情况 a**：px 是叶子节点（lchild == NULL && rchild == NULL）→ 直接删除
   - **情况 b**：px 只有一个子树 → 用子树代替 px
   - **情况 c**：px 左右子树都不为空 → 找到**替罪羊**：
     - 左子树中最大的节点 x，**或**
     - 右子树中最小的节点 y
     - 用 x 或 y 的数据替换 px，再删除 x 或 y

```c
struct Binode *Delete_x(struct Binode *root, char x)
{
    if (root == NULL) return NULL;

    // 查找 x 对应的节点
    struct Binode *pr = NULL;
    struct Binode *px = root;
    while (px)
    {
        if (px->data > x)      { pr = px; px = px->lchild; }
        else if (px->data < x) { pr = px; px = px->rchild; }
        else break;
    }
    if (px == NULL) return root;  // 没找到

loop:
    if (px->lchild == NULL && px->rchild == NULL)  // 叶子节点
    {
        if (px == root) { free(px); return NULL; }
        else if (pr->lchild == px) { pr->lchild = NULL; free(px); }
        else { pr->rchild = NULL; free(px); }
    }
    else if (px->rchild && px->lchild == NULL)  // 只有右孩子
    {
        if (px == root) { root = px->rchild; px->rchild = NULL; free(px); }
        else if (pr->lchild == px) { pr->lchild = px->rchild; px->rchild = NULL; free(px); }
        else { pr->rchild = px->rchild; px->rchild = NULL; free(px); }
    }
    else if (px->lchild && px->rchild == NULL)  // 只有左孩子
    {
        // 类似上面
    }
    else  // 左右子树都不为空
    {
        // 找左子树中最大值作为替罪羊
        struct Binode *p = px;
        pr = px;
        px = px->lchild;
        while (px->rchild) { pr = px; px = px->rchild; }
        p->data = px->data;
        goto loop;
    }
    return root;
}
```

## 九、平衡二叉树 (AVL 树)

### 引入原因

BST 极端情况下退化为链表（如 ABCDEFGH...），查找时间复杂度从 O(log n) 变为 O(n)。

> 如果有 2^20 - 1 个节点，极端情况需要遍历 2^20 - 1 次；但如果是满二叉树，最坏只需访问 20 次。

### 定义

AVL 树是最先发现的自平衡二叉查找树，满足：
- 是一棵二叉排序树
- 左子树和右子树也是一棵平衡二叉树
- **右子树与左子树的高度差绝对值不超过 1**

**平衡因子** = 左子树高度 − 右子树高度，取值为 **0、1、-1**

### 平衡因子计算示例（分步详解）

以下面这颗 AVL 树为例，逐步计算每个节点的平衡因子。

```
         D (4)
       /     \
     B (2)    F (3)
    /  \     /   \
  A (1) C(1) E(1) G (2)
                   /
                 H (1)
```

节点高度定义：叶子节点高度为 1，空节点高度为 0。

**步骤一：自底向上确定叶子节点高度**
- `A` 的左右子节点均为空，高度 = max(0, 0) + 1 = 1
- `C`、`E` 同理，高度 = 1
- `H` 左右子节点均为空，高度 = 1

**步骤二：计算内部节点高度**
- `B`：左孩子 A 高度 = 1，右孩子 C 高度 = 1 → B 的高度 = max(1, 1) + 1 = **2**
  - B 的平衡因子 = 左子树高度 − 右子树高度 = 1 − 1 = **0**
- `G`：左孩子 H 高度 = 1，右孩子为空高度 = 0 → G 的高度 = max(1, 0) + 1 = **2**
  - G 的平衡因子 = 1 − 0 = **1**
- `F`：左孩子 E 高度 = 1，右孩子 G 高度 = 2 → F 的高度 = max(1, 2) + 1 = **3**
  - F 的平衡因子 = 1 − 2 = **−1**（安全范围内）
- `D`：左孩子 B 高度 = 2，右孩子 F 高度 = 3 → D 的高度 = max(2, 3) + 1 = **4**
  - D 的平衡因子 = 2 − 3 = **−1**（安全范围内）

| 节点 | 左子树高度 | 右子树高度 | 节点高度 | 平衡因子 | 是否平衡 |
|------|-----------|-----------|---------|---------|---------|
| A | 0 | 0 | 1 | 0 | 是 |
| B | 1 | 1 | 2 | 0 | 是 |
| C | 0 | 0 | 1 | 0 | 是 |
| D | 2 | 3 | 4 | −1 | 是 |
| E | 0 | 0 | 1 | 0 | 是 |
| F | 1 | 2 | 3 | −1 | 是 |
| G | 1 | 0 | 2 | 1 | 是 |
| H | 0 | 0 | 1 | 0 | 是 |

**插入导致失衡示例**：在上述树中插入新节点 `I`（挂在 H 的右子树），则：
- 更新 H 的高度 = 1 → 不变
- 更新 G 的平衡因子：左子树 H 高度 1，右子树 I 高度 1 → 平衡因子 = 1 − 1 = **0**
- 更新 F 的平衡因子：左 1，右 3 → 平衡因子 = 1 − 3 = **−2** → 失衡！
- 此时需要针对 F 做 **先右后左双旋** 恢复平衡。

### AVL 树 vs 红黑树（简要对比）

| 特性 | AVL 树 | 红黑树 |
|------|--------|--------|
| **平衡条件** | 左右子树高度差 ≤ 1（严格平衡） | 从根到叶子的最长路径不超过最短路径的 2 倍（近似平衡） |
| **查找性能** | O(log n)，更优（更严格的平衡） | O(log n)，略差于 AVL |
| **插入/删除性能** | 可能需要多次旋转（最多 O(log n) 次） | 最多 2 次旋转（插入）或 3 次旋转（删除），旋转次数更少 |
| **额外存储** | 每个节点存高度（int） | 每个节点存颜色（1 bit） |
| **适用场景** | 查询远多于插入/删除的场景（如数据库索引） | 插入/删除频繁的场景（如 Linux 内核调度、C++ STL map/set、Java HashMap） |

### 四种平衡操作

| 操作 | 适用情况 | 处理 |
|------|----------|------|
| **单向右旋** | 在左子节点的**左边**添加节点导致不平衡 | 对不平衡节点"向右折枝" |
| **单向左旋** | 在右子节点的**右边**添加节点导致不平衡 | 对不平衡节点"向左折枝" |
| **先左后右** | 在左子节点的**右边**添加节点导致不平衡 | 先对左子节点左旋，再对不平衡节点右旋 |
| **先右后左** | 在右子节点的**左边**添加节点导致不平衡 | 先对右子节点右旋，再对不平衡节点左旋 |

### AVL 树实现

```c
#include "avltree.h"

int Height(struct Binode *root)
{
    if (root == NULL) return 0;
    return root->h;
}

struct Binode *Creat_avltree(void)
{
    struct Binode *root = NULL;
    char d;
    while (1)
    {
        scanf("%c", &d);
        if (d == '#') break;
        struct Binode *p = (struct Binode *)malloc(sizeof(struct Binode));
        p->data = d;
        p->lchild = NULL;
        p->rchild = NULL;
        p->h = 1;
        root = insert(root, p);
    }
    return root;
}

struct Binode *insert(struct Binode *root, struct Binode *p)
{
    if (root == NULL) return p;

    if (root->data > p->data)  // 往左子树插入
    {
        root->lchild = insert(root->lchild, p);
        root->h = (Height(root->lchild) > Height(root->rchild)
                   ? Height(root->lchild) + 1
                   : Height(root->rchild) + 1);

        if (Height(root->lchild) - Height(root->rchild) > 1)
        {
            if (p->data < root->lchild->data)
                root = Single_right(root);      // 右旋
            else
                root = Both_leftright(root);    // 先左后右
        }
    }
    else  // 往右子树插入
    {
        root->rchild = insert(root->rchild, p);
        root->h = (Height(root->lchild) > Height(root->rchild)
                   ? Height(root->lchild) + 1
                   : Height(root->rchild) + 1);

        if (Height(root->rchild) - Height(root->lchild) > 1)
        {
            if (p->data > root->rchild->data)
                root = Single_left(root);       // 左旋
            else
                root = Both_rightleft(root);    // 先右后左
        }
    }
    return root;
}

// 单向左旋
struct Binode *Single_left(struct Binode *k2)
{
    struct Binode *k1 = k2->rchild;
    k2->rchild = k1->lchild;
    k1->lchild = k2;
    k2->h = Height(k2->lchild) > Height(k2->rchild)
            ? Height(k2->lchild) + 1 : Height(k2->rchild) + 1;
    k1->h = Height(k1->lchild) > Height(k1->rchild)
            ? Height(k1->lchild) + 1 : Height(k1->rchild) + 1;
    return k1;
}

// 单向右旋
struct Binode *Single_right(struct Binode *k2)
{
    struct Binode *k1 = k2->lchild;
    k2->lchild = k1->rchild;
    k1->rchild = k2;
    k2->h = Height(k2->lchild) > Height(k2->rchild)
            ? Height(k2->lchild) + 1 : Height(k2->rchild) + 1;
    k1->h = Height(k1->lchild) > Height(k1->rchild)
            ? Height(k1->lchild) + 1 : Height(k1->rchild) + 1;
    return k1;
}

// 先左旋再右旋
struct Binode *Both_leftright(struct Binode *k2)
{
    k2->lchild = Single_left(k2->lchild);
    return Single_right(k2);
}

// 先右旋再左旋
struct Binode *Both_rightleft(struct Binode *k2)
{
    k2->rchild = Single_right(k2->rchild);
    return Single_left(k2);
}
```

## 十、多叉树和森林

### 孩子兄弟表示法

用二叉链表描述多叉树/森林：

```c
struct Binode
{
    char data;              // 保存数据
    struct Binode *lchild;  // 指向第一个孩子
    struct Binode *rchild;  // 指向兄弟节点
};
```

> 向左分支连接第一个孩子，向右分支连接兄弟。

## 树在嵌入式系统中的应用

### 1. FAT 文件系统中的目录树结构

FAT（File Allocation Table）文件系统使用树形结构管理目录。每个目录项可以包含文件和子目录，形成一棵多叉树。当遍历 FAT 目录时，本质上就是对该目录树进行先序遍历或层序遍历。

```
根目录 (/)
├── boot.ini       (文件)
├── System Volume Information/  (目录)
│   └── MountPointManagerRemoteDatabase
├── Windows/
│   ├── System32/
│   │   ├── kernel32.dll
│   │   ├── user32.dll
│   │   └── ...
│   └── ...
└── Users/
    └── ...
```

FAT 的目录项采用**链式存储 + 树形索引**的方式：根目录下的每个目录项要么是文件（叶子节点），要么是子目录（分支节点）。深度优先遍历可递归列出所有路径。

### 2. Linux 内核中的设备树 (Device Tree)

嵌入式 Linux 使用设备树（Device Tree, DTS/DTB）描述硬件拓扑结构，本质上是一棵**描述硬件资源的树**：

```
/ {
    compatible = "vendorb,example-soc";
    cpus {
        cpu@0 { compatible = "arm,cortex-a9"; };
        cpu@1 { compatible = "arm,cortex-a9"; };
    };
    memory {
        reg = <0x40000000 0x80000000>;
    };
    serial@12C00000 {
        compatible = "vendorb,example-uart";
        reg = <0x12C00000 0x100>;
    };
};
```

内核启动时解析设备树，将硬件节点组织为 `struct device_node` 构成的树，设备驱动通过树状路径查找匹配的硬件资源。设备树的遍历（`of_find_node_by_name`、`for_each_child_of_node` 等 API）本质是对树进行 DFS 遍历。

### 3. 二叉堆与 RTOS 优先级调度

RTOS（如 FreeRTOS、uC/OS）的任务调度常使用**二叉堆（Binary Heap）**实现优先级就绪队列。二叉堆是一棵完全二叉树，可用数组表示，满足：

- **最大堆**：根节点优先级最高（值最大），每次调度取根节点 → O(1)
- 插入新任务 → 上浮操作（percolate up），时间复杂度 O(log n)
- 删除最高优先级任务 → 下沉操作（percolate down），时间复杂度 O(log n)

```
优先级就绪队列（最大堆示例）:
        10 (最高优先级任务)
       /  \
      8    7
     / \  / \
    5  6 3  4
   /
  1
```

本质上就是用完全二叉树和数组顺序存储，利用堆的性质实现高效的任务调度。

## 面试练习题

### 二叉树的前序/中序/后序遍历（递归 + 迭代实现）

**虚拟来源**：虚拟搜索公司丁 2021

**题目**：实现二叉树的前序、中序和后序遍历，要求分别给出递归和迭代（非递归）两种实现方式。

**答案**：

递归实现简洁直观，利用函数调用栈天然进行深度优先遍历；迭代实现需要显式维护栈来模拟递归过程。

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

// ========== 先序遍历 ==========

// 递归
void preorder_recursive(struct TreeNode *root) {
    if (root == NULL) return;
    printf("%d ", root->val);
    preorder_recursive(root->left);
    preorder_recursive(root->right);
}

// 迭代（显式栈，根 → 左 → 右）
void preorder_iterative(struct TreeNode *root) {
    if (root == NULL) return;
    struct TreeNode *stack[1000];
    int top = -1;
    stack[++top] = root;
    while (top >= 0) {
        struct TreeNode *p = stack[top--];
        printf("%d ", p->val);
        // 先压右孩子，再压左孩子（出栈时左孩子先出）
        if (p->right) stack[++top] = p->right;
        if (p->left)  stack[++top] = p->left;
    }
}

// ========== 中序遍历 ==========

// 递归
void inorder_recursive(struct TreeNode *root) {
    if (root == NULL) return;
    inorder_recursive(root->left);
    printf("%d ", root->val);
    inorder_recursive(root->right);
}

// 迭代
void inorder_iterative(struct TreeNode *root) {
    struct TreeNode *stack[1000];
    int top = -1;
    struct TreeNode *curr = root;
    while (curr != NULL || top >= 0) {
        // 一路向左，将所有左子节点压栈
        while (curr != NULL) {
            stack[++top] = curr;
            curr = curr->left;
        }
        // 弹出并访问
        curr = stack[top--];
        printf("%d ", curr->val);
        // 转向右子树
        curr = curr->right;
    }
}

// ========== 后序遍历 ==========

// 递归
void postorder_recursive(struct TreeNode *root) {
    if (root == NULL) return;
    postorder_recursive(root->left);
    postorder_recursive(root->right);
    printf("%d ", root->val);
}

// 迭代（使用两个栈或一个栈 + 标记法，这里给出双栈法）
void postorder_iterative(struct TreeNode *root) {
    if (root == NULL) return;
    struct TreeNode *s1[1000], *s2[1000];
    int top1 = -1, top2 = -1;
    s1[++top1] = root;
    // s1 按根→左→右压栈，s2 出栈顺序即为后序
    while (top1 >= 0) {
        struct TreeNode *p = s1[top1--];
        s2[++top2] = p;
        if (p->left)  s1[++top1] = p->left;
        if (p->right) s1[++top1] = p->right;
    }
    while (top2 >= 0) {
        printf("%d ", s2[top2--]->val);
    }
}
```

**复杂度分析**：所有遍历方式的时间复杂度均为 O(n)，空间复杂度 O(h)（h 为树高，递归中为调用栈深度，迭代中为显式栈大小）。

### 二叉树的层序遍历（含 Z 字形遍历）

**虚拟来源**：虚拟互联网公司甲 2022

**题目**：实现二叉树的层序遍历（逐层输出），进一步实现 Z 字形（锯齿形）遍历，即奇数行从左到右，偶数行从右到左。

**答案**：

层序遍历本质是广度优先搜索（BFS），使用队列完成。Z 字形遍历只需额外记录当前层号，偶数层逆序输出即可。

```c
#include <stdio.h>
#include <stdlib.h>

#define MAX_QUEUE 1000

// 基础层序遍历（一行输出一层）
void level_order(struct TreeNode *root) {
    if (root == NULL) return;
    struct TreeNode *queue[MAX_QUEUE];
    int front = 0, rear = 0;
    queue[rear++] = root;
    while (front < rear) {
        int level_size = rear - front;  // 当前层节点数
        for (int i = 0; i < level_size; i++) {
            struct TreeNode *p = queue[front++];
            printf("%d ", p->val);
            if (p->left)  queue[rear++] = p->left;
            if (p->right) queue[rear++] = p->right;
        }
        printf("\n");  // 一层结束
    }
}

// Z 字形（锯齿形）层序遍历
void zigzag_level_order(struct TreeNode *root) {
    if (root == NULL) return;
    struct TreeNode *queue[MAX_QUEUE];
    int front = 0, rear = 0;
    queue[rear++] = root;
    int level = 0;
    while (front < rear) {
        int level_size = rear - front;
        int temp[level_size];
        for (int i = 0; i < level_size; i++) {
            struct TreeNode *p = queue[front++];
            // 根据层号决定存放顺序
            int idx = (level % 2 == 0) ? i : (level_size - 1 - i);
            temp[idx] = p->val;
            if (p->left)  queue[rear++] = p->left;
            if (p->right) queue[rear++] = p->right;
        }
        for (int i = 0; i < level_size; i++) {
            printf("%d ", temp[i]);
        }
        printf("\n");
        level++;
    }
}
```

**复杂度分析**：时间复杂度 O(n)，空间复杂度 O(n)（队列最多存半层节点数，最坏 O(n)）。

### 验证二叉搜索树 (BST)

**虚拟来源**：虚拟互联网公司丙 2021

**题目**：给定一棵二叉树，判断它是否是有效的二叉搜索树。要求不能仅判断左 < 根 < 右，因为还需要满足整个左子树都小于根、整个右子树都大于根。

**答案**：

利用 BST 的性质：中序遍历结果为严格递增序列，或者递归时传递上下界（min/max）约束。

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <limits.h>

struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

// 解法一：递归 + 上下界约束
bool isValidBST_helper(struct TreeNode *root, long long min, long long max) {
    if (root == NULL) return true;
    if (root->val <= min || root->val >= max) return false;
    // 左子树所有节点值 < root->val，右子树所有节点值 > root->val
    return isValidBST_helper(root->left, min, root->val)
        && isValidBST_helper(root->right, root->val, max);
}

bool isValidBST(struct TreeNode *root) {
    return isValidBST_helper(root, LLONG_MIN, LLONG_MAX);
}

// 解法二：中序遍历判断严格递增
bool isValidBST_inorder(struct TreeNode *root) {
    struct TreeNode *stack[1000];
    int top = -1;
    long long prev = LLONG_MIN;
    struct TreeNode *curr = root;
    while (curr != NULL || top >= 0) {
        while (curr != NULL) {
            stack[++top] = curr;
            curr = curr->left;
        }
        curr = stack[top--];
        if (curr->val <= prev) return false;  // 非严格递增则无效
        prev = curr->val;
        curr = curr->right;
    }
    return true;
}
```

**关键点**：仅检查 `root->left->val < root->val < root->right->val` 是错误的，因为子树中可能存在更深层的不合法节点。必须传递全局边界或利用中序递增性质。

### 二叉树的最近公共祖先 (LCA)

**虚拟来源**：虚拟互联网公司甲 2022

**题目**：给定一棵二叉树（不一定是 BST）和两个节点 p、q，找到它们最近的公共祖先节点。

**答案**：

采用递归的 DFS 搜索：从根节点向下查找，如果当前节点等于 p 或 q，则返回当前节点；否则分别在左右子树中查找。

```c
struct TreeNode* lowestCommonAncestor(struct TreeNode* root,
                                      struct TreeNode* p,
                                      struct TreeNode* q) {
    if (root == NULL) return NULL;
    // 当前节点就是目标节点之一
    if (root == p || root == q) return root;

    struct TreeNode *left = lowestCommonAncestor(root->left, p, q);
    struct TreeNode *right = lowestCommonAncestor(root->right, p, q);

    // p 和 q 分别在左右子树中 → 当前节点即为 LCA
    if (left != NULL && right != NULL) return root;

    // 否则返回非空的那一侧
    return (left != NULL) ? left : right;
}
```

**算法思路**：从根节点递归遍历，对每个节点：
1. 如果当前节点是 p 或 q，则向上返回
2. 左子树递归查找结果记作 left，右子树递归结果记作 right
3. 如果 left 和 right 都不为空 → 说明 p 和 q 在当前节点的两侧 → 当前节点就是 LCA
4. 否则返回非空的那一侧（说明 p 和 q 在同一子树中）

**复杂度分析**：时间复杂度 O(n)，空间复杂度 O(h)（递归栈深度，最坏 O(n)）。

### 平衡二叉树判断

**虚拟来源**：虚拟生活服务公司戊 2021

**题目**：给定一棵二叉树，判断它是否为平衡二叉树（任意节点的左右子树高度差不超过 1）。

**答案**：

自顶向下的方法会重复计算高度，效率低。推荐使用自底向上的方法——在递归计算高度的同时判断平衡性，一旦发现不平衡即提前终止。

```c
#include <stdio.h>
#include <stdbool.h>
#include <stdlib.h>

struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

// 自底向上判断：返回值 -1 表示不平衡，否则返回树高
int checkBalance(struct TreeNode *root) {
    if (root == NULL) return 0;

    int left = checkBalance(root->left);
    if (left == -1) return -1;  // 左子树已不平衡，提前返回

    int right = checkBalance(root->right);
    if (right == -1) return -1;  // 右子树已不平衡，提前返回

    if (abs(left - right) > 1) return -1;  // 当前节点不平衡

    return (left > right ? left : right) + 1;  // 返回当前树高
}

bool isBalanced(struct TreeNode *root) {
    return checkBalance(root) != -1;
}
```

**关键点**：
- 避免自顶向下重复计算高度导致 O(n²) 的时间复杂度
- 自底向上（后序遍历思想）只需遍历一次，时间复杂度 O(n)
- 用特殊返回值（如 −1）标记不平衡状态，减少额外变量

### 二叉树的最大深度

**虚拟来源**：虚拟通信公司己 2020

**题目**：给定一棵二叉树，求其最大深度（根节点到最远叶子节点的路径上的节点数）。

**答案**：

递归解法最简洁，本质是后序遍历——先求左右子树的高度，取最大值 +1。

```c
#include <stdio.h>

struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

// 递归解法
int maxDepth(struct TreeNode *root) {
    if (root == NULL) return 0;
    int leftDepth = maxDepth(root->left);
    int rightDepth = maxDepth(root->right);
    return (leftDepth > rightDepth ? leftDepth : rightDepth) + 1;
}

// 迭代解法（层序遍历）
int maxDepth_iterative(struct TreeNode *root) {
    if (root == NULL) return 0;
    struct TreeNode *queue[10000];
    int front = 0, rear = 0;
    queue[rear++] = root;
    int depth = 0;
    while (front < rear) {
        int level_size = rear - front;
        for (int i = 0; i < level_size; i++) {
            struct TreeNode *p = queue[front++];
            if (p->left)  queue[rear++] = p->left;
            if (p->right) queue[rear++] = p->right;
        }
        depth++;  // 每遍历完一层深度 +1
    }
    return depth;
}
```

**复杂度**：递归 O(n) 时间、O(h) 空间；迭代 O(n) 时间、O(n) 空间。

**注意**：如果题目定义深度为节点数（根节点深度 1），则空树返回 0；如果定义为边数（根节点深度 0），则需调整。面试时建议先和面试官确认。

### 对称二叉树判断

**虚拟来源**：虚拟电商公司乙 2021

**题目**：给定一棵二叉树，判断它是否对称（镜面对称）。

**答案**：

对称二叉树的核心条件是：对于任意对称位置的两个节点，值相等，且左子树的左孩子与右子树的右孩子对称、左子树的右孩子与右子树的左孩子对称。

```c
#include <stdio.h>
#include <stdbool.h>

struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

// 递归解法
bool isMirror(struct TreeNode *t1, struct TreeNode *t2) {
    if (t1 == NULL && t2 == NULL) return true;
    if (t1 == NULL || t2 == NULL) return false;
    return (t1->val == t2->val)
        && isMirror(t1->left, t2->right)
        && isMirror(t1->right, t2->left);
}

bool isSymmetric(struct TreeNode *root) {
    if (root == NULL) return true;
    return isMirror(root->left, root->right);
}

// 迭代解法（使用双端队列或两个队列）
#include <stdio.h>
#define MAXQ 1000

bool isSymmetric_iterative(struct TreeNode *root) {
    if (root == NULL) return true;
    struct TreeNode *q1[MAXQ], *q2[MAXQ];
    int f1 = 0, r1 = 0, f2 = 0, r2 = 0;
    q1[r1++] = root->left;
    q2[r2++] = root->right;
    while (f1 < r1 && f2 < r2) {
        struct TreeNode *a = q1[f1++];
        struct TreeNode *b = q2[f2++];
        if (a == NULL && b == NULL) continue;
        if (a == NULL || b == NULL) return false;
        if (a->val != b->val) return false;
        // a 的左 vs b 的右，a 的右 vs b 的左
        q1[r1++] = a->left;  q2[r2++] = b->right;
        q1[r1++] = a->right; q2[r2++] = b->left;
    }
    return true;
}
```

**易错点**：初学者容易只检查左右孩子值相等，但忽略了递归的交叉比较（`left->left` vs `right->right` 和 `left->right` vs `right->left`）。

### 根据前序 + 中序遍历还原二叉树

**虚拟来源**：58集团 2020

**题目**：给定一棵二叉树的前序遍历和中序遍历结果（无重复值），还原整棵二叉树结构。

**答案**：

前序确定根节点，中序确定左右子树范围。递归构建即可。

```c
#include <stdio.h>
#include <stdlib.h>

struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

// 在前序遍历数组中的位置索引
int preIndex = 0;

// 在中序数组中查找值的索引
int search(int *inorder, int inStart, int inEnd, int val) {
    for (int i = inStart; i <= inEnd; i++) {
        if (inorder[i] == val) return i;
    }
    return -1;
}

struct TreeNode* buildTreeHelper(int *preorder, int *inorder,
                                  int inStart, int inEnd) {
    if (inStart > inEnd) return NULL;

    // 前序的第一个值是当前子树的根
    int rootVal = preorder[preIndex++];
    struct TreeNode *root = (struct TreeNode *)malloc(sizeof(struct TreeNode));
    root->val = rootVal;

    // 在中序中找到根的位置
    int inIndex = search(inorder, inStart, inEnd, rootVal);

    // 递归构建左右子树
    root->left  = buildTreeHelper(preorder, inorder, inStart, inIndex - 1);
    root->right = buildTreeHelper(preorder, inorder, inIndex + 1, inEnd);

    return root;
}

struct TreeNode* buildTree(int *preorder, int preorderSize,
                           int *inorder, int inorderSize) {
    preIndex = 0;
    return buildTreeHelper(preorder, inorder, 0, inorderSize - 1);
}
```

**优化**：中序中的值查找可以用哈希表（值 → 下标映射）将时间复杂度从 O(n²) 降为 O(n)。

**思路要点**：
1. 前序遍历的第一个元素就是根节点
2. 在中序遍历中找到根节点位置，左边是左子树，右边是右子树
3. 根据中序划分的左右子树长度，在前序中确定左右子树对应的子数组
4. 递归上述过程

### 二叉树的右视图

**虚拟来源**：虚拟互联网公司甲 2021

**题目**：给定一棵二叉树，从右侧看它，返回从上到下看到的节点值序列（即每层最右边的节点）。

**答案**：

使用层序遍历（BFS），每层最后一个节点即为该层右视图可见节点。

```c
#include <stdio.h>
#include <stdlib.h>

struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

int* rightSideView(struct TreeNode *root, int *returnSize) {
    if (root == NULL) {
        *returnSize = 0;
        return NULL;
    }

    struct TreeNode *queue[2000];
    int front = 0, rear = 0;
    queue[rear++] = root;

    int *result = (int *)malloc(sizeof(int) * 2000);
    int count = 0;

    while (front < rear) {
        int level_size = rear - front;
        for (int i = 0; i < level_size; i++) {
            struct TreeNode *p = queue[front++];
            // 当前层最后一个节点 → 右视图可见
            if (i == level_size - 1) {
                result[count++] = p->val;
            }
            if (p->left)  queue[rear++] = p->left;
            if (p->right) queue[rear++] = p->right;
        }
    }

    *returnSize = count;
    return result;
}
```

**扩展**：如果要求**左视图**，只需将条件 `i == level_size - 1` 改为 `i == 0`（每层第一个节点）。如果要求**俯视图**，则需要记录水平偏移量，属于更复杂的问题，面试中出现较少。

### 求二叉树中最大路径和

**虚拟来源**：虚拟互联网公司甲 2022

**题目**：给定一棵非空二叉树，求最大路径和。路径定义为从任意节点出发到任意节点结束的一条路径（路径上的节点连接方式必须遵循父子关系），路径和是路径上所有节点值的总和。注意：路径可以不经过根节点，也可以不经过叶子节点。

**答案**：

这是 LeetCode 124 题（Hard），核心思路是后序遍历 + 局部最优合并。对每个节点，计算"经过该节点且包含其某侧子树的最大贡献值"，然后尝试用"左贡献 + 右贡献 + 当前值"更新全局最大值。

```c
#include <stdio.h>
#include <stdlib.h>
#include <limits.h>

struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

int maxSum = INT_MIN;  // 全局最大路径和

// 返回包含当前节点在内的、向一侧延伸的最大贡献值
int maxGain(struct TreeNode *root) {
    if (root == NULL) return 0;

    // 左右子树贡献值（负数则不选取，贡献取 0）
    int leftGain  = maxGain(root->left);
    int rightGain = maxGain(root->right);
    if (leftGain < 0)  leftGain = 0;
    if (rightGain < 0) rightGain = 0;

    // 经过当前节点的"完整路径"和（左贡献 + 当前 + 右贡献）
    int priceNewPath = leftGain + root->val + rightGain;

    // 更新全局最大值
    if (priceNewPath > maxSum) {
        maxSum = priceNewPath;
    }

    // 返回单侧最大贡献给父节点使用
    return root->val + (leftGain > rightGain ? leftGain : rightGain);
}

int maxPathSum(struct TreeNode *root) {
    maxSum = INT_MIN;
    maxGain(root);
    return maxSum;
}
```

**核心要点**：
1. 每个节点计算"左贡献 + 当前值 + 右贡献"作为完整路径的候选值，更新全局最大值
2. 向上返回时，只能选择左或右中较大的那一条"单侧路径" + 当前值（因为路径不能分叉后再合并）
3. 遇到负贡献直接丢弃（取 0），因为不选一定比选了更好
4. 全局最大值可能出现在树中任意位置，所以需要在每个节点处尝试合并

**示例**：
```
       -10
       / \
      9  20
        /  \
       15   7
```
- 15 和 7 都是叶子节点，贡献值分别为 15、7 → 候选路径和 15、7
- 节点 20：左贡献 15，右贡献 7 → 候选路径和 15+20+7 = 42
- 节点 -10：左贡献 9，右贡献 42 → 候选路径和 9+(−10)+42 = 41
- 最终最大路径和为 42（即 15→20→7）
