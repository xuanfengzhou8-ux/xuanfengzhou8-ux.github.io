五、编程题（第一题10分，第二题10分，共20分）
1.编写程序：判断输入的正整数是否既是3的整倍数又是8的整倍数。若是,则输出 yes;否则输出no。并画出该程序的流程图。(10分)。
参考源代码及评分标准：
#include <stdio.h>
int main( )
{
    int x;
    scanf("%d",&x);
    if(x>=0)
    {
        if(x%3==0&&x%8==0) printf("yes\n");
        else   printf("no\n") ;
    }
    else printf("输出的数据不是正数\n");
    return 0;
}
（1）具有C程序的基本结构（1分）标识符命名正确、语法逻辑正确（1分）
（2）实现要求的功能（2分）
（3）对输入的数据进行正数判断（1分）
（4）流程图正确、逻辑正确、流程图符号使用正确（5分）
2.编写程序：不使用strcpy()函数实现字符串的复制功能。在自定义函数中实现复制功能，主函数调用。(共10分)
参考源代码及评分标准：
#include <stdio.h>
void cpy(char *str1,char *str2)
{
    int i=0;
    while(str2[i]!=0)
    {
        str1[i]=str2[i];
        i++;
    }//4分
    str1[i]='\0';//2分
}
int main( )
{
    char str1[20];
    char str2[20];//2分
    gets(str1);gets(str2);
    cpy(str1,str2);//2分
    puts(str1);
    return 0;
}
（1）具有C程序的基本结构（1分）标识符命名正确、语法逻辑正确（1分）
（2）实现要求的功能（6分）
（3）使用函数实现该功能（2分）
