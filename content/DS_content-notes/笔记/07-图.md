# 图

---

## 一、图的基本概念

### 定义

图 (Graph) 是一种非线性结构，形式化描述为：

```
Graph = (V, R)
```

- **V**：图中的顶点集合，V = {vi | i = 0, 1, 2, 3...}，n 代表图中顶点个数
- **R**：V 集合中任意两个顶点之间的关系，P(vi, vj) 表示顶点 vi 到 vj 的路径

---

## 二、图的分类

| 类型 | 特点 |
|------|------|
| **有向图** | 两个顶点之间的路径是"弧"，有方向 |
| **无向图** | 若 P(vi, vj) 存在则 P(vj, vi) 一定存在，两点之间的关系是"边" |
| **网** | 给关系 <vi, vj> 加上权值 w（带权图），权值含义根据应用而定（如城市距离） |

### 术语

| 术语 | 含义 |
|------|------|
| **顶点的度** | 顶点的边或弧的数量（有向图分入度和出度） |
| **连通图/非连通图** | 任意两个顶点是否有路径相连 |
| **路径** | 从一个顶点到另一个顶点：直接路径 / 间接路径 |

## 四、邻接矩阵（数组表示法）

用两个数组存储一个图：
- 一个数组存储 V（每个顶点）
- 一个数组存储 R（两个顶点之间的关系/权值）

### 数据类型定义

```c
#define MAX 100
#define VREY_BIG 65535

struct graph
{
    char V[MAX];          // 存储顶点（最多 100 个）
    int data[MAX][MAX];   // 存储两个顶点之间的权值
    int num;              // 图中顶点的个数
};

int visit[MAX];           // 访问数组，标记顶点是否被访问过
```

- `data[i][j]`：从顶点 i 出发到顶点 j 的权值
- 第 i 行 = 出发顶点，第 j 列 = 终点

### 头文件 graph.h

```c
#ifndef __GRAPH_H__
#define __GRAPH_H__
#include <stdio.h>
#include <stdlib.h>
#include "queue.h"
#include <string.h>

#define MAX 100
#define VREY_BIG 65535

struct graph
{
    char V[MAX];
    int data[MAX][MAX];
    int num;
};
int visit[MAX];

void printf_graph(struct graph *p);
struct graph *Creat_graph(void);
int Find_i(struct graph *p, char x);
void DFS(struct graph *p, int v0);
void BFS(struct graph *p, struct queue *l);

#endif
```

### 创建图

```c
#include "graph.h"
#include "queue.h"

// 根据顶点值查找下标
int Find_i(struct graph *p, char x)
{
    if (p == NULL) return 0;
    int i;
    for (i = 0; i < p->num; i++)
    {
        if (p->V[i] == x)
            return i;
    }
    return -1;
}

struct graph *Creat_graph(void)
{
    int i, j;
    struct graph *p = (struct graph *)malloc(sizeof(struct graph));
    p->num = 0;
    char d;

    // 输入顶点
    while (1)
    {
        scanf("%c", &d);
        if (d == '#') break;
        p->V[p->num++] = d;
    }

    // 初始化邻接矩阵
    for (i = 0; i < p->num; i++)
        for (j = 0; j < p->num; j++)
            p->data[i][j] = VREY_BIG;

    // 初始化访问数组
    for (i = 0; i < p->num; i++)
        visit[i] = 0;

    // 输入边（起点、终点、权值）
    char start, stop;
    int w, start_i, stop_i;
    while (1)
    {
        scanf("%c%c%d", &start, &stop, &w);
        if (start == '#' || stop == '#' || w == 0) break;
        start_i = Find_i(p, start);
        stop_i = Find_i(p, stop);
        p->data[start_i][stop_i] = w;
        p->data[stop_i][start_i] = w;  // 无向图
        getchar();
    }
    return p;
}

// 打印邻接矩阵
void printf_graph(struct graph *p)
{
    if (p == NULL) return;
    int i, j;
    printf("  ");
    for (i = 0; i < p->num; i++)
        printf("%c ", p->V[i]);
    printf("\n");
    for (i = 0; i < p->num; i++)
    {
        printf("%c ", p->V[i]);
        for (j = 0; j < p->num; j++)
        {
            if (p->data[i][j] == VREY_BIG)
                printf("# ");
            else
                printf("%d ", p->data[i][j]);
        }
        printf("\n");
    }
}
```

## 五、图的遍历

图的遍历是树的遍历的推广，将网状结构按某种规则线性化。

- `visit[i] == 0`：顶点 i 未被访问
- `visit[i] == 1`：顶点 i 已被访问

### 深度优先搜索 (DFS)

```
从 V0 出发：
1. 访问 V0，标记 visit[V0] = 1
2. 找 V0 的下一个邻接点 Vi：
   - 判断能不能去（是否有路径，! = VREY_BIG）
   - 判断该不该去（visit[Vi] == 0）
   - 如果满足 → DFS(Vi)
3. 如果 V0 所有邻接点都被访问过 → 回溯
```

```c
void DFS(struct graph *p, int v0)
{
    int vi;
    // 访问 V0
    printf("%c ", p->V[v0]);
    visit[v0] = 1;

    // 找 V0 的下一个邻接点
    for (vi = 0; vi < p->num; vi++)
    {
        if (p->data[v0][vi] != VREY_BIG)  // 能不能去
        {
            if (visit[vi] == 0)           // 该不该去
            {
                DFS(p, vi);
            }
        }
    }
}
```

### 广度优先搜索 (BFS)

类似于树的层序遍历：

```
1. 从 V0 出发，V0 入队
while (队列不为空)
{
    2. 访问队首元素
    3. 找队首元素所有的邻接点：
       - 能去且没被访问过 → 入队并标记
    4. 队首元素出队
}
```

```c
void BFS(struct graph *p, struct queue *l)
{
    int i, x;
    // 先让第一个顶点入队
    Enqueue(l, p->V[0]);
    visit[0] = 1;
    while (!QueueisEmpty(l))
    {
        printf("%c ", l->data[l->front]);
        x = Find_i(p, l->data[l->front]);
        // 找邻接点
        for (i = 0; i < p->num; i++)
        {
            if (p->data[x][i] != VREY_BIG)  // 能不能去
            {
                if (visit[i] == 0)          // 该不该去
                {
                    Enqueue(l, p->V[i]);
                    visit[i] = 1;
                }
            }
        }
        Outqueue(l);
    }
}
```

## 七、最短路径问题

解决带权有向图中两点之间的最短路径的两种算法：

| 算法 | 思想 | 用途 |
|------|------|------|
| **Dijkstra（迪杰斯特拉）** | 贪心算法 | 图中一点到其他各点的最短路径 |
| **Floyd（弗洛伊德）** | 动态规划（三循环） | 任意两点之间的最短路径 |

### Dijkstra 算法

需要三个辅助数组：

| 数组 | 含义 |
|------|------|
| `s[n]` | 标记数组：s[i]=0（未找到最短路径），s[i]=1（已找到） |
| `dist[n]` | 存储当前源点 V0 到终点 Vi 的最短路径长度 |
| `path[n][]` | 存放从 V0 到 Vi 最短路径上依次经过的每一个顶点 |

#### 算法步骤

假设图中有 n 个顶点，求 n−1 条最短路径：

```
Step 1：从源点 V0 到其他未找到最短路径的顶点中，找到一条最短路径
        dist[u] = min{dist[a], dist[b], dist[c]...}
        dist[u] 即为一条最短路径，s[u] = 1

Step 2：对于 s[i] == 0 的顶点，用 dist[u] 更新 dist[i]
        if (dist[w] + data[w][u] < dist[u])
            dist[u] = dist[w] + data[w][u]

goto Step 1（直到所有顶点都找到最短路径）
```

#### Dijkstra 算法详解 —— 以具体图为例

假设有向图有 6 个顶点 (0 ~ 5) 和以下带权边：

| 起点 | 终点 | 权值 |
|:----:|:----:|:----:|
| 0 | 1 | 4 |
| 0 | 2 | 6 |
| 1 | 2 | 1 |
| 1 | 3 | 2 |
| 2 | 3 | 5 |
| 3 | 4 | 3 |
| 4 | 5 | 1 |

邻接矩阵表示为：

```
   0  1  2  3  4  5
0  #  4  6  #  #  #
1  4  #  1  2  #  #
2  6  1  #  5  #  #
3  #  2  5  #  3  #
4  #  #  #  3  #  1
5  #  #  #  #  1  #
```

求源点 0 到所有其他顶点的最短路径。

**初始化：**
- `s = [1, 0, 0, 0, 0, 0]`        （0 自身已经找到）
- `dist = [0, 4, 6, ∞, ∞, ∞]`     （0→1=4, 0→2=6, 其余不可达）
- `path = [[0], [0,1], [0,2], [], [], []]`

**第 1 轮：**
1. 未标记顶点 `{1,2,3,4,5}` 中 `dist` 最小的是 `dist[1]=4` → 标记 `s[1]=1`
2. 用顶点 1 更新其余未标记顶点：
   - `dist[2]`：当前 6，通过 1 为 `dist[1]+data[1][2]=4+1=5` → 更新 `dist[2]=5, path[2]=[0,1,2]`
   - `dist[3]`：当前 ∞，通过 1 为 `4+2=6` → 更新 `dist[3]=6, path[3]=[0,1,3]`
   - 其余不变

**第 2 轮：**
1. 未标记 `{2,3,4,5}` 中 `dist` 最小的是 `dist[2]=5` → 标记 `s[2]=1`
2. 用顶点 2 更新：
   - `dist[3]`：当前 6，通过 2 为 `5+5=10` → 不更新
   - 其余不变

**第 3 轮：**
1. 未标记 `{3,4,5}` 中最小是 `dist[3]=6` → 标记 `s[3]=1`
2. 用顶点 3 更新：
   - `dist[4]`：当前 ∞，通过 3 为 `6+3=9` → 更新 `dist[4]=9, path[4]=[0,1,3,4]`
   - 其余不变

**第 4 轮：**
1. 未标记 `{4,5}` 中最小是 `dist[4]=9` → 标记 `s[4]=1`
2. 用顶点 4 更新：
   - `dist[5]`：当前 ∞，通过 4 为 `9+1=10` → 更新 `dist[5]=10, path[5]=[0,1,3,4,5]`

**第 5 轮：**
1. 标记 `dist[5]=10` → `s[5]=1`，算法结束。

**最终结果：**

| 终点 | 最短距离 | 最短路径 |
|:----:|:--------:|:---------:|
| 0 | 0 | 0 |
| 1 | 4 | 0→1 |
| 2 | 5 | 0→1→2 |
| 3 | 6 | 0→1→3 |
| 4 | 9 | 0→1→3→4 |
| 5 | 10 | 0→1→3→4→5 |

## 八、拓扑排序

### 定义

拓扑排序（Topological Sorting）是针对 **有向无环图（DAG）** 的顶点排序算法，使得对于每一条有向边 `<u, v>`，u 在排序中都出现在 v 之前。

### 应用场景（嵌入式相关）

| 场景 | 说明 |
|------|------|
| **依赖构建系统** | Make / CMake 根据依赖关系确定源文件编译顺序 |
| **任务调度** | FreeRTOS 或裸机系统中任务之间存在先后依赖 |
| **模块初始化顺序** | 嵌入式驱动的 probe 顺序依赖，如 I2C 依赖 GPIO，SPI 依赖 DMA |
| **编译流程** | 链接器（ld）解析符号依赖，确定目标文件链接顺序 |

### 算法步骤（Kahn 算法）

```
入度表法（Kahn）：
1. 计算所有顶点的入度
2. 将所有入度为 0 的顶点入队
3. 循环直到队列为空：
   a. 出队一个顶点，加入结果集
   b. 遍历该顶点的所有邻接点，将邻接点的入度减 1
   c. 若邻接点入度变为 0，则入队
4. 若结果集顶点数 < 总顶点数，说明图中存在环
```

```c
#define MAX 100

void TopologicalSort(struct graph *p)
{
    int indegree[MAX] = {0};
    int queue[MAX], front = 0, rear = 0;
    int i, j, count = 0;

    // 1. 计算所有顶点的入度
    for (j = 0; j < p->num; j++)
        for (i = 0; i < p->num; i++)
            if (p->data[i][j] != 0 && p->data[i][j] != VREY_BIG)
                indegree[j]++;

    // 2. 入度为 0 的顶点入队
    for (i = 0; i < p->num; i++)
        if (indegree[i] == 0)
            queue[rear++] = i;

    // 3. 循环处理
    while (front != rear)
    {
        int v = queue[front++];
        printf("%c ", p->V[v]);
        count++;

        for (j = 0; j < p->num; j++)
        {
            if (p->data[v][j] != 0 && p->data[v][j] != VREY_BIG)
            {
                indegree[j]--;
                if (indegree[j] == 0)
                    queue[rear++] = j;
            }
        }
    }

    // 4. 检查是否有环
    if (count != p->num)
        printf("\n图中存在环，拓扑排序失败！");
}
```

## 九、DFS 与 BFS 对比

| 对比维度 | DFS（深度优先搜索） | BFS（广度优先搜索） |
|----------|---------------------|---------------------|
| **数据结构** | 栈（递归本质是栈） | 队列 |
| **空间复杂度** | O(h)，h 为递归深度（稀疏图优势明显） | O(w)，w 为最大宽度（稠密图劣势） |
| **最短路径** | 不能保证最短路径 | 无权图中可求单源最短路径 |
| **连通分量** | 适合判断图是否连通、找环 | 同样可以，但 DFS 更简洁 |
| **使用时机** | 回溯、拓扑排序、连通分量、迷宫求解、寻找环路 | 层级遍历、无权图最短路径、社交网络"跳数"、网络广播 |
| **典型应用** | 检测环、拓扑排序、0-1 背包回溯 | 简单路由跳数、广播泛洪、Web 爬虫层级爬取 |

## 十、图在嵌入式系统中的应用

### PCB 布线算法

PCB（印刷电路板）自动布线广泛使用 **Lee 算法**（BFS 变种）和 **A\*** 算法，将布线区域建模为网格图，每个网格是顶点，相邻网格之间的可布线连接是边。BFS 保证找出最短绕障路径，而 A\* 通过启发式函数进一步减少搜索空间。

### IoT 无线网状网络（Mesh）

在 Zigbee / Thread / BLE Mesh 等网络中，节点构成一个 **多跳无线网络拓扑图**：
- 路由协议（如 RPL、AODV）本质是在网络拓扑图上运行最短路径算法
- 网络层需要维护邻接关系（类似邻接表），周期性更新链路质量（权值）
- 广播风暴问题恰是 BFS 在无线网络中的具体体现，需要通过 TTL 和序列号优化

### 构建系统依赖解析

Make / CMake / Ninja 等构建工具的依赖关系图是 **有向无环图（DAG）**：
- 每个源文件是顶点，`#include` 或编译依赖构成有向边
- 增量编译时只需要 DFS 遍历受影响的目标文件子树进行重编译
- 拓扑排序用来确定链接顺序（链接器要求目标文件按依赖顺序输入）
- 环检测用于发现头文件循环包含或 Makefile 循环依赖

## 十一、面试练习题

### 课程表问题（拓扑排序）

**题目：** 你总共要修 numCourses 门课程，记为 0 到 numCourses - 1。给定 prerequisites = [[a, b], ...] 表示学习课程 a 必须先学习 b。判断是否可能完成所有课程。

**来源：** 虚拟互联网公司丙 2022，虚拟互联网公司甲 2021

**思路：** 这是一个典型的拓扑排序 / 环检测问题。将课程看作 DAG 顶点，先修关系为有向边。统计入度后用 Kahn 算法或 DFS 检测是否有环。

```c
#include <stdbool.h>
#include <string.h>

#define MAX_COURSES 2000

bool canFinish(int numCourses, int** prerequisites, int prerequisitesSize, int* prerequisitesColSize)
{
    // 邻接表和入度数组
    int *adj[MAX_COURSES], adjSize[MAX_COURSES];
    int indegree[MAX_COURSES] = {0};
    int i, j;

    for (i = 0; i < numCourses; i++)
        adjSize[i] = 0;

    // 建图
    for (i = 0; i < prerequisitesSize; i++)
    {
        int a = prerequisites[i][0];  // 后修课程
        int b = prerequisites[i][1];  // 先修课程
        adj[b][adjSize[b]++] = a;
        indegree[a]++;
    }

    // Kahn 算法
    int queue[MAX_COURSES], front = 0, rear = 0, count = 0;
    for (i = 0; i < numCourses; i++)
        if (indegree[i] == 0)
            queue[rear++] = i;

    while (front != rear)
    {
        int v = queue[front++];
        count++;
        for (j = 0; j < adjSize[v]; j++)
        {
            int u = adj[v][j];
            indegree[u]--;
            if (indegree[u] == 0)
                queue[rear++] = u;
        }
    }

    return count == numCourses;
}
```

### 克隆图

**题目：** 给你无向连通图中的一个节点的引用，返回该图的深拷贝（clone）。图中每个节点包含一个值 val 和邻居列表 neighbors。

**来源：** 虚拟互联网公司甲 2021

**思路：** 使用 DFS 或 BFS 遍历原图，同时建立原节点到新节点的映射（HashMap），避免重复复制和无限循环。

```c
#include <stdlib.h>

// 图节点定义（LeetCode 风格）
struct Node {
    int val;
    int numNeighbors;
    struct Node** neighbors;
};

// HashMap 节点
struct HashNode {
    struct Node *key;
    struct Node *val;
    struct HashNode *next;
};

#define HASH_SIZE 1000

struct HashNode* hash[HASH_SIZE];

unsigned int hash_func(struct Node *key) {
    return (unsigned long)key % HASH_SIZE;
}

void hash_insert(struct Node *key, struct Node *val) {
    unsigned int idx = hash_func(key);
    struct HashNode *hn = malloc(sizeof(struct HashNode));
    hn->key = key; hn->val = val; hn->next = hash[idx];
    hash[idx] = hn;
}

struct Node* hash_find(struct Node *key) {
    unsigned int idx = hash_func(key);
    struct HashNode *cur = hash[idx];
    while (cur) {
        if (cur->key == key) return cur->val;
        cur = cur->next;
    }
    return NULL;
}

struct Node* cloneGraph(struct Node* s) {
    if (s == NULL) return NULL;

    // BFS
    struct Node *q[100]; int front = 0, rear = 0;
    struct Node *new_root = malloc(sizeof(struct Node));
    new_root->val = s->val;
    new_root->numNeighbors = 0;
    new_root->neighbors = NULL;
    hash_insert(s, new_root);
    q[rear++] = s;

    while (front != rear) {
        struct Node *u = q[front++];
        struct Node *new_u = hash_find(u);

        for (int i = 0; i < u->numNeighbors; i++) {
            struct Node *v = u->neighbors[i];
            struct Node *new_v = hash_find(v);
            if (new_v == NULL) {
                new_v = malloc(sizeof(struct Node));
                new_v->val = v->val;
                new_v->numNeighbors = 0;
                new_v->neighbors = NULL;
                hash_insert(v, new_v);
                q[rear++] = v;
            }
            // 将新邻居加入新节点的邻居列表
            new_u->neighbors = realloc(new_u->neighbors,
                (new_u->numNeighbors + 1) * sizeof(struct Node*));
            new_u->neighbors[new_u->numNeighbors++] = new_v;
        }
    }
    return new_root;
}
```

### 岛屿数量（DFS / BFS）

**题目：** 给你一个由 '1'（陆地）和 '0'（水）组成的二维网格，请你计算网格中岛屿的数量（被水包围的连续陆地区域）。

**来源：** 虚拟生活服务公司戊 2022

**思路：** 遍历每个格子，遇到 '1' 时计数 +1，然后用 DFS 或 BFS 将其连通的全部 '1' 标记为已访问（改为 '0' 或使用 visited 数组）。

```c
void dfs(char** grid, int m, int n, int i, int j)
{
    if (i < 0 || i >= m || j < 0 || j >= n || grid[i][j] == '0')
        return;
    grid[i][j] = '0';  // 标记为水，避免重复访问
    dfs(grid, m, n, i - 1, j);
    dfs(grid, m, n, i + 1, j);
    dfs(grid, m, n, i, j - 1);
    dfs(grid, m, n, i, j + 1);
}

int numIslands(char** grid, int m, int* gridColSize)
{
    if (grid == NULL || m == 0) return 0;
    int n = gridColSize[0];
    int count = 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (grid[i][j] == '1')
            {
                count++;
                dfs(grid, m, n, i, j);
            }
    return count;
}
```

**复杂度分析：** 时间复杂度 O(m × n)，空间复杂度 O(m × n)（递归栈深度最坏情况）。

### 网络延迟时间（Dijkstra）

**题目：** 有 N 个网络节点，标记为 1 到 N。给定 times[i] = (u, v, w) 表示从节点 u 到节点 v 的信号传播延迟。从节点 k 发出一个信号，求所有节点都收到信号的最短时间。如果某个节点无法收到，返回 -1。

**来源：** 虚拟通信公司己 2021

**思路：** 这是一个典型的单源最短路径问题。使用 Dijkstra 算法求出从节点 k 到其他所有节点的最短距离，取最大值即为答案。因节点数 <= 100，可以用邻接矩阵实现。

```c
#include <stdlib.h>
#include <string.h>

#define INF 0x3f3f3f3f
#define MAX 110

int networkDelayTime(int** times, int timesSize, int* timesColSize,
                     int N, int k)
{
    int graph[MAX][MAX];
    int dist[MAX], s[MAX];
    int i, j;

    // 初始化邻接矩阵
    for (i = 1; i <= N; i++)
        for (j = 1; j <= N; j++)
            graph[i][j] = (i == j) ? 0 : INF;

    for (i = 0; i < timesSize; i++)
        graph[times[i][0]][times[i][1]] = times[i][2];

    // 初始化 dist 和 s
    for (i = 1; i <= N; i++) {
        dist[i] = graph[k][i];
        s[i] = 0;
    }
    s[k] = 1;
    dist[k] = 0;

    // Dijkstra 主循环
    for (i = 1; i < N; i++) {
        int u = -1, min = INF;
        for (j = 1; j <= N; j++)
            if (!s[j] && dist[j] < min)
                min = dist[u = j];

        if (u == -1) break;  // 剩余节点不可达
        s[u] = 1;

        for (j = 1; j <= N; j++)
            if (!s[j] && graph[u][j] != INF
                && dist[u] + graph[u][j] < dist[j])
                dist[j] = dist[u] + graph[u][j];
    }

    // 取最大值
    int ans = 0;
    for (i = 1; i <= N; i++)
        if (dist[i] == INF) return -1;
        else if (dist[i] > ans) ans = dist[i];

    return ans;
}
```

### 判断图中是否存在环

**题目：** 给定一个有向图，判断图中是否存在环。

**来源：** 虚拟互联网公司丙 2021

**思路：** 两种常用方法：
1. **DFS + 三色标记法**：白色（未访问）、灰色（正在访问）、黑色（访问结束）。DFS 过程中遇到灰色顶点说明存在环。
2. **Kahn 算法（拓扑排序）**：统计入度，不断删除入度为 0 的顶点。若最终剩余顶点不等于总顶点数，说明有环。

```c
#define MAXV 100

// 方法一：DFS + 三色标记
int color[MAXV];  // 0=白色, 1=灰色, 2=黑色
int has_cycle;

void dfs_cycle(struct graph *p, int v)
{
    color[v] = 1;  // 灰色
    for (int i = 0; i < p->num; i++)
    {
        if (p->data[v][i] != VREY_BIG && p->data[v][i] != 0)
        {
            if (color[i] == 1)  // 遇到灰色 → 有环
                has_cycle = 1;
            else if (color[i] == 0)
                dfs_cycle(p, i);
        }
    }
    color[v] = 2;  // 黑色
}

int detectCycle(struct graph *p)
{
    has_cycle = 0;
    for (int i = 0; i < p->num; i++)
        color[i] = 0;

    for (int i = 0; i < p->num; i++)
        if (color[i] == 0)
        {
            dfs_cycle(p, i);
            if (has_cycle) return 1;
        }
    return 0;
}
```

### 最短路径（Dijkstra 算法实现）

**题目：** 给定一个带权有向图，实现 Dijkstra 算法求从源点到其余各顶点的最短路径长度，并输出路径。

**来源：** 虚拟电商公司乙 2020

**思路：** 按 Dijkstra 标准算法实现，使用 path 数组记录前驱节点，最终递归或迭代输出最短路径。

```c
#include <stdio.h>
#include <stdlib.h>

#define MAXV 100
#define INF 65535

// 打印从 src 到 v 的最短路径
void printPath(int path[], int v)
{
    if (path[v] == -1) return;
    printPath(path, path[v]);
    printf(" → %d", v);
}

void Dijkstra(struct graph *p, int src)
{
    int dist[MAXV], s[MAXV], path[MAXV];
    int i, j;

    // 初始化
    for (i = 0; i < p->num; i++)
    {
        dist[i] = p->data[src][i];
        s[i] = 0;
        path[i] = (p->data[src][i] != INF && i != src) ? src : -1;
    }
    s[src] = 1;
    dist[src] = 0;

    // 主循环
    for (i = 1; i < p->num; i++)
    {
        int u = -1, min = INF;
        for (j = 0; j < p->num; j++)
            if (!s[j] && dist[j] < min)
                min = dist[u = j];

        if (u == -1) break;
        s[u] = 1;

        for (j = 0; j < p->num; j++)
            if (!s[j] && p->data[u][j] != INF
                && dist[u] + p->data[u][j] < dist[j])
            {
                dist[j] = dist[u] + p->data[u][j];
                path[j] = u;
            }
    }

    // 输出结果
    for (i = 0; i < p->num; i++)
    {
        if (i == src) continue;
        printf("从 %d 到 %d 的最短距离: %d，路径: %d", src, i, dist[i], src);
        printPath(path, i);
        printf("\n");
    }
}
```
