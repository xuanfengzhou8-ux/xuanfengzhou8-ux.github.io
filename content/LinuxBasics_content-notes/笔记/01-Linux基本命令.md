# Linux 基本命令

> 本章目标：把 Linux 命令行当成日常开发工具，而不是只会照着命令复制粘贴。

## 1. 学习路线

这一章建议按下面的顺序学习：

1. 先理解软件包管理：知道软件从哪里来、如何安装和卸载。
2. 再掌握编辑器：能够在终端里快速修改配置和源码。
3. 然后熟悉文件系统：会查看、复制、移动、删除、打包和解压文件。
4. 最后学习系统与用户相关命令：能观察进程、权限、磁盘和网络状态。

> 自学建议：每看到一个命令，都要问自己三个问题：它操作谁？会不会修改文件？失败时怎么确认原因？

## 2. 软件包管理：APT

APT 是 Ubuntu/Debian 系统常用的软件包管理工具。它负责从软件源获取软件列表，处理依赖关系，并完成安装、升级和卸载。

| 命令 | 作用 | 常见场景 |
|---|---|---|
| `sudo apt-get update` | 更新本地软件包索引 | 换源后、安装软件前 |
| `sudo apt-get install <包名>` | 安装软件包 | 安装编译器、工具、库 |
| `sudo apt-get remove <包名>` | 卸载软件包 | 删除不再需要的软件 |
| `apt-cache search <关键字>` | 搜索软件包 | 不确定包名时先查找 |

软件源配置通常在：

```bash
/etc/apt/sources.list
```

更新软件包索引：

```bash
sudo apt-get update
```

搜索拼音输入法相关包：

```bash
apt-cache search pinyin
```

安装一个示例输入法包：

```bash
sudo apt-get install ibus-pinyin-example
```

### 易错点

- `update` 只更新软件包索引，不会升级已经安装的软件。
- 安装失败时，先看错误信息，不要连续重复执行同一条命令。
- 修改系统配置前，建议先备份原文件。

## 3. 终端编辑器：vi / vim

`vi` 是基础编辑器，`vim` 是更强的增强版。嵌入式开发中，经常需要在没有图形界面的系统里修改文件，所以至少要掌握基本操作。

### 3.1 三种常用模式

| 模式 | 用途 | 如何进入 |
|---|---|---|
| 命令模式 | 移动光标、删除、复制、保存 | 打开文件后默认进入 |
| 插入模式 | 输入文本 | `i`、`a`、`o` |
| 末行模式 | 保存、退出、替换、设置行号 | 命令模式下输入 `:` |

### 3.2 常用操作速查

| 操作 | 命令 | 说明 |
|---|---|---|
| 进入插入模式 | `i` | 在光标前插入 |
| 追加输入 | `a` | 在光标后插入 |
| 新开下一行 | `o` | 在当前行下方新建一行 |
| 保存 | `:w` | 写入文件 |
| 退出 | `:q` | 未修改时退出 |
| 强制退出 | `:q!` | 放弃修改退出 |
| 保存并退出 | `:wq` 或 `:x` | 常用退出方式 |
| 删除一行 | `dd` | 删除当前行 |
| 复制一行 | `yy` | 复制当前行 |
| 粘贴 | `p` | 粘贴到当前行后 |
| 撤销 | `u` | 撤销上一步 |
| 搜索 | `/关键字` | 按 `n` 查看下一个 |
| 显示行号 | `:set nu` | 调试配置文件时常用 |

### 3.3 替换命令

基本格式：

```vim
:{范围}s/{旧内容}/{新内容}/{标志}
```

示例：把全文中的 `foo` 替换为 `bar`：

```vim
:%s/foo/bar/g
```

含义：

- `%` 表示全文。
- `s` 表示 substitute。
- `g` 表示当前行内全部匹配都替换。

## 4. 文件系统常用命令

| 命令 | 作用 |
|---|---|
| `pwd` | 显示当前目录 |
| `ls -la` | 查看文件详细信息和隐藏文件 |
| `cd <目录>` | 切换目录 |
| `mkdir <目录>` | 创建目录 |
| `touch <文件>` | 创建空文件或更新时间戳 |
| `cp <源> <目标>` | 复制文件 |
| `mv <源> <目标>` | 移动或重命名 |
| `rm <文件>` | 删除文件 |
| `rm -r <目录>` | 递归删除目录 |
| `cat <文件>` | 输出整个文件 |
| `less <文件>` | 分页查看文件 |

### 路径理解

```bash
/home/student/project/main.c
```

- `/`：根目录。
- `/home/student`：用户目录。
- `project/main.c`：项目里的源文件。

相对路径示例：

```bash
cd project
ls ../
```

`..` 表示上一级目录，`.` 表示当前目录。

## 5. 权限与用户

Linux 权限通常分为三组：文件所有者、同组用户、其他用户。

```bash
ls -l
```

示例输出：

```text
-rwxr-xr-- 1 student dev 1024 Jul 09 app
```

可以这样理解：

| 片段 | 含义 |
|---|---|
| `r` | 可读 |
| `w` | 可写 |
| `x` | 可执行 |
| `rwx` | 所有者权限 |
| `r-x` | 同组用户权限 |
| `r--` | 其他用户权限 |

给脚本添加可执行权限：

```bash
chmod +x run.sh
```

## 6. 进程与系统观察

| 命令 | 用途 |
|---|---|
| `ps aux` | 查看进程列表 |
| `top` | 动态查看 CPU/内存占用 |
| `kill <pid>` | 给进程发送终止信号 |
| `df -h` | 查看磁盘空间 |
| `du -sh <目录>` | 查看目录占用 |
| `free -h` | 查看内存 |
| `uname -a` | 查看系统内核信息 |

示例：找出占用 CPU 较高的进程：

```bash
top
```

如果需要结束某个进程，先确认 PID，再执行：

```bash
kill 1234
```
