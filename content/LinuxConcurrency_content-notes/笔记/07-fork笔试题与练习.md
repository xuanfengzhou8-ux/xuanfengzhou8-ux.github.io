# fork 笔试题与练习

> 本章目标：掌握分析 fork 程序输出的方法，而不是靠猜。

## 1. 分析 fork 题的基本方法

遇到 fork 题，建议按下面的步骤分析：

1. 给每个进程画一条执行路径。
2. 标记每次 `fork()` 在父进程和子进程中的返回值。
3. 遇到 `&&`、`||` 时考虑短路求值。
4. 区分带换行和不带换行的输出。
5. 最后再统计进程数量或输出次数。

## 2. 基础规则回顾

`fork()` 调用一次，成功时会变成两个执行流：

| 执行流 | fork 返回值 |
|---|---|
| 父进程 | 子进程 PID，非 0 |
| 子进程 | 0 |

因此：

```c
fork();
printf("A\n");
```

会打印两次 `A`。

## 3. 练习一：连续 fork

代码：

```c
#include <stdio.h>
#include <unistd.h>

int main(void) {
    fork();
    fork();
    printf("hello\n");
    return 0;
}
```

分析：

```text
开始：1 个进程
第一次 fork 后：2 个进程
第二次 fork 后：4 个进程
```

所以 `hello` 通常会输出 4 次。顺序不固定，因为多个进程由系统调度。

## 4. 练习二：循环中的 fork

代码：

```c
#include <stdio.h>
#include <unistd.h>

int main(void) {
    for (int i = 0; i < 2; ++i) {
        fork();
        printf("_\n");
    }
    return 0;
}
```

分析：

| 轮次 | 进入本轮的进程数 | fork 后进程数 | 本轮打印次数 |
|---|---:|---:|---:|
| 第 0 轮 | 1 | 2 | 2 |
| 第 1 轮 | 2 | 4 | 4 |

总打印次数：

```text
2 + 4 = 6
```

因为每次打印都有换行，输出通常比较容易数清楚。

## 5. 练习三：无换行输出

代码：

```c
#include <stdio.h>
#include <unistd.h>

int main(void) {
    for (int i = 0; i < 2; ++i) {
        fork();
        printf("_");
    }
    return 0;
}
```

理论执行到 `printf` 的次数仍然是 6 次，但实际看到的输出可能受标准 I/O 缓冲影响。

为什么？

- `printf("_\n")` 遇到换行更容易刷新。
- `printf("_")` 没有换行，缓冲区可能在 `fork` 后被多个进程复制。

分析 fork 输出题时，要特别注意缓冲区。

## 6. 练习四：短路表达式中的 fork

代码：

```c
#include <unistd.h>

int main(void) {
    fork();
    fork() && fork() || fork();
    fork();
    return 0;
}
```

分析这类题时，不建议心算。建议画表：

1. 第一行 `fork()`：进程数从 1 变 2。
2. 表达式 `A && B || C`：
   - `A` 是一次 `fork()`。
   - 在父进程中，`A` 返回非 0，需要继续执行 `B`。
   - 在子进程中，`A` 返回 0，`A && B` 短路为假，需要执行 `C`。
   - `B` 和 `C` 自己也会继续分裂进程。
3. 最后一行 `fork()`：当前每个进程再复制一次。

这类题的重点不是背答案，而是练会“按返回值分支画进程树”。

## 7. 推荐画法

用 `P` 表示父分支，用 `C` 表示子分支：

```text
fork A
├─ A-P：返回非 0
└─ A-C：返回 0
```

遇到 `&&`：

```text
左边为真，才执行右边
```

遇到 `||`：

```text
左边为假，才执行右边
```

## 8. 常见陷阱

- 忘记父子进程都会继续执行后续代码。
- 忽略 `&&` 和 `||` 的短路规则。
- 把输出顺序当成固定顺序。
- 忽略标准 I/O 缓冲对输出次数的影响。
- 没有区分“进程数量”和“打印次数”。

## 9. 自学任务

1. 分析下面代码会打印几次 `A`：

```c
fork();
fork();
fork();
printf("A\n");
```

2. 分析下面代码父子分支分别打印什么：

```c
pid_t pid = fork();
if (pid == 0) {
    printf("child\n");
} else {
    printf("parent\n");
}
```

3. 把 `printf("_\n")` 改成 `printf("_")`，观察输出差异。
4. 用进程树分析 `fork() || fork()`。
5. 用进程树分析 `fork() && fork()`。
