3、若函数声明为 int fun(int x, int y);，则定义时写成 int fun(int y, int x) { return x+y; } 是合法的，且调用 fun(3,5) 会返回 8。（   ）
4、设有 typedef int ARR[5];，则 ARR a, b; 等价于 int a[5], b[5];，且 sizeof(ARR) 的值等于 sizeof(int) * 5。（   ）
5、执行 char *str = "hello"; str[0] = 'H'; 会导致程序运行时错误，因为字符串常量存储在只读数据区（.rodata），不允许修改。（   ）
6、若有 int x = 10; int *p = &x;，则表达式 (void *)p == (void *)&x 和 p == &x 的结果均为真，但 (char *)p + 1 == (char *)&x + 1 的结果不一定为真。（   ）
7、宏定义 #define MAX(a,b) (a)>(b)?(a):(b) 用于计算 MAX(3+2, 4) 时结果为 5，计算 MAX(3, 2+4) 时结果为 6，因此该宏定义是可靠的。（   ）
8、C 语言中，static 修饰的局部变量和全局变量均存储在静态数据区，且其生命周期与程序一致，但局部静态变量的作用域仅限于所在函数，全局静态变量的作用域仅限于所在文件。（   ）
9、设有 union Data { int i; char c; float f; } d;，则 d.i = 0x12345678; 后，若系统为小端字节序，d.c 的值为 0x78；若为大端字节序，d.c 的值为 0x12，因此 d.c 的值由字节序决定。（   ）
10、执行 int a[2][3] = {{1},{2,3}}; 后，a[1][2] 的值为 0，a[0][1] 的值为 0，a[0][2] 的值为 0，该初始化方式是完全合法的。（   ）
