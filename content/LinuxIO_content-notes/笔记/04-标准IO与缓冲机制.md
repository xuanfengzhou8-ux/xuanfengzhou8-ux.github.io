# 标准 I/O 与缓冲机制

> 本章目标：理解 `FILE *`、标准 I/O 缓冲和系统 I/O 的差异，能正确使用 `fopen/fread/fwrite/fseek/fclose`。

## 1. 为什么需要标准 I/O

系统 I/O 直接调用内核接口，控制力强，但频繁调用会有系统调用开销。标准 I/O 在用户态增加了一层缓冲，常用于文本处理和一般文件读写。

| 对比项 | 系统 I/O | 标准 I/O |
|---|---|---|
| 代表接口 | `open/read/write` | `fopen/fread/fwrite` |
| 句柄类型 | 文件描述符 `int` | `FILE *` |
| 缓冲 | 主要由内核处理 | 用户态有标准 I/O 缓冲 |
| 适合场景 | 设备、底层控制 | 文本、普通文件、格式化输入输出 |

## 2. 标准输入、输出、错误

程序启动后默认有三个标准 I/O 流：

| 流 | 说明 |
|---|---|
| `stdin` | 标准输入 |
| `stdout` | 标准输出 |
| `stderr` | 标准错误 |

常见函数：

```c
scanf("%d", &x);       // 从 stdin 读
printf("hello\n");     // 写 stdout
perror("open");        // 写 stderr
```

## 3. fopen / fclose

```c
#include <stdio.h>

FILE *fp = fopen("data.txt", "r");
if (fp == NULL) {
    perror("fopen");
    return 1;
}

fclose(fp);
```

常见模式：

| 模式 | 含义 |
|---|---|
| `"r"` | 只读，文件必须存在 |
| `"w"` | 只写，文件不存在则创建，存在则清空 |
| `"a"` | 追加写 |
| `"r+"` | 读写，文件必须存在 |
| `"w+"` | 读写，先清空 |
| `"a+"` | 读和追加写 |

二进制文件可加 `b`，例如 `"rb"`、`"wb"`。

## 4. 字符读写

```c
int c = fgetc(fp);
if (c != EOF) {
    putchar(c);
}
```

写字符：

```c
fputc('A', fp);
```

`getchar()` 等价于从 `stdin` 读一个字符，`putchar()` 等价于向 `stdout` 写一个字符。

## 5. 字符串读写

```c
char line[128];
if (fgets(line, sizeof(line), fp) != NULL) {
    fputs(line, stdout);
}
```

> 不建议使用 `gets`，因为它无法限制输入长度，容易造成缓冲区溢出。

## 6. 块读写

读取二进制数据：

```c
unsigned char buf[1024];
size_t n = fread(buf, 1, sizeof(buf), fp);
```

写入二进制数据：

```c
fwrite(buf, 1, n, out);
```

参数含义：

```c
fread(buffer, 每个元素大小, 元素个数, 文件流);
```

返回值是成功读到的元素个数。

## 7. fseek / ftell / rewind

移动文件位置：

```c
fseek(fp, 0, SEEK_SET);
```

获取当前位置：

```c
long pos = ftell(fp);
```

回到文件开头：

```c
rewind(fp);
```

获取文件大小：

```c
fseek(fp, 0, SEEK_END);
long size = ftell(fp);
rewind(fp);
```

## 8. 缓冲机制

标准 I/O 常见缓冲方式：

| 缓冲方式 | 说明 |
|---|---|
| 全缓冲 | 缓冲区满或手动刷新时写出 |
| 行缓冲 | 遇到换行或缓冲区满时写出 |
| 无缓冲 | 尽量立即写出 |

手动刷新：

```c
fflush(stdout);
```

刷新所有输出流：

```c
fflush(NULL);
```

## 9. 缓冲带来的典型现象

下面的程序可能不会马上在终端看到输出：

```c
printf("hello");
sleep(10);
```

原因是没有换行，输出可能还停留在缓冲区。可以改成：

```c
printf("hello\n");
```

或者：

```c
printf("hello");
fflush(stdout);
```

## 10. 易错点

- 把 `FILE *` 当成文件描述符传给 `read/write`。
- 使用 `gets` 读取字符串。
- 忘记 `fclose`。
- 不理解 `fread` 返回的是元素个数。
- 认为 `printf` 一定会立刻显示。
