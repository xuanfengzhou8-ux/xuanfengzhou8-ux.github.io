## 本章与工作的关系

运算符是 C 语言书写任何表达式的"词汇"。对运算符的掌握程度直接影响代码质量和调试效率。

- **企业开发**：逻辑运算短路特性广泛用于条件判断前的安全检查（如非空判断）；自增自减运算符在循环和数组遍历中高频出现；运算符优先级错误是代码审查中常见的"一眼 bug"。
- **嵌入式开发**：位运算是硬件寄存器操作的基础（置位/清零/读取特定位），几乎每一行底层驱动代码都在用。
- **笔试面试**：面试官喜欢考察混合表达式求值（包含自增、位运算、类型转换的混合场景）、优先级陷阱（如 `*p++` 的含义）、以及标识未定义行为（如 `i = i++`）。

## 运算符分类概览

C 语言的运算符按照功能可分为以下类别：

| 类别 | 运算符 | 说明 |
|------|--------|------|
| 算术运算符 | `+` `-` `*` `/` `%` `++` `--` | 数值计算和自增自减 |
| 关系运算符 | `==` `!=` `<` `>` `<=` `>=` | 比较运算，结果为 0 或 1 |
| 逻辑运算符 | `&&` `||` `!` | 逻辑与/或/非，支持短路求值 |
| 位运算符 | `&` `|` `^` `~` `<<` `>>` | 按位操作 |
| 赋值运算符 | `=` `+=` `-=` `*=` `/=` `%=` `&=` `|=` `^=` `<<=` `>>=` | 赋值及复合赋值 |
| 条件运算符 | `?:` | C 中唯一的三目运算符 |
| 逗号运算符 | `,` | 顺序求值 |
| 其他 | `sizeof` `(类型)` `&` `*` `.` `->` `[]` `()` | 包括取址/解引用/成员访问/函数调用 |

本章后续章节将逐一详细讲解各类运算符，并在"运算符优先级与结合性"一节给出完整的优先级表。

## 算术运算符

### 基本算术运算

```c
#include <stdio.h>

int main(void)
{
    int a = 10, b = 3;

    printf("a + b = %d\n", a + b);   // 13
    printf("a - b = %d\n", a - b);   // 7
    printf("a * b = %d\n", a * b);   // 30
    printf("a / b = %d\n", a / b);   // 3（整数除法，截断小数部分）
    printf("a %% b = %d\n", a % b);   // 1（取模/求余数）

    // 浮点除法
    double c = 10.0;
    printf("c / b = %.2f\n", c / b); // 3.33（浮点除法保留小数）
    return 0;
}
```

#### 整数除法的截断

当 `/` 两边均为整数类型时，执行整数除法，结果向零截断（truncation toward zero，C99 起的规定）：

```c
 5 / 2 =  2     // 向零取整
-5 / 2 = -2     // 向零取整（不是 -3！）
-5 / 2 = -2     // C99 起标准行为：向零取整
```

#### 取模（%）与负数

C99 起，`%` 的结果满足：`(a / b) * b + a % b == a`，且 `a % b` 的符号与 `a` 相同（而不是与 `b` 相同）：

```c
 5 %  3 =  2       // 正数取模，直观
-5 %  3 = -2       // 结果是 -2（不是 1！）
 5 % -3 =  2       // 结果是 2
-5 % -3 = -2       // 结果是 -2
```

> **说明**：在 C89 标准中，负数的 `/` 和 `%` 结果是实现定义（implementation-defined）的。C99 起明确定义为向零截断，余数的符号与被除数相同。写跨平台代码时仍需注意编译器的 C 标准版本。

### 自增与自减（++ / --）

前缀和后缀形式存在本质区别：

| 表达式 | 表达式自身的值 | 执行后 i 的值 |
|--------|:-------------:|:-----------:|
| `i++`（后缀自增） | i 的**原值** | i 增加 1 |
| `++i`（前缀自增） | i + 1 | i 增加 1 |
| `i--`（后缀自减） | i 的**原值** | i 减少 1 |
| `--i`（前缀自减） | i - 1 | i 减少 1 |

```c
#include <stdio.h>

int main(void)
{
    int i = 3;
    int a = i++;        // a = 3, 然后 i = 4
    int b = ++i;        // 先 i = 5, 然后 b = 5

    printf("a = %d, b = %d, i = %d\n", a, b, i);  // a = 3, b = 5, i = 5
    return 0;
}
```

### 序列点与自增陷阱

两个序列点之间对同一个变量进行多次修改会导致**未定义行为（Undefined Behavior, UB）**：

```c
int i = 0;
i = i++;       // 未定义行为！在两个序列点之间对 i 修改了两次

int arr[5] = {0};
int j = 0;
arr[j] = j++;  // 未定义行为！无法确定 arr[j] 中的 j 是在递增之前还是之后求值的

printf("%d %d %d\n", i++, i++, i++);  // 未定义行为！函数参数求值顺序是未指定的
```

> **工程规则**：避免在同一个表达式中对同一变量多次使用自增/自减。如果确实需要用，将自增操作拆到单独的语句中。

## 关系与逻辑运算符

### 关系运算符

| 运算符 | 含义 | 示例（a=5, b=3）|
|:------:|------|:--------------:|
| `>` | 大于 | `a > b` → 1 |
| `>=` | 大于等于 | `a >= b` → 1 |
| `<` | 小于 | `a < b` → 0 |
| `<=` | 小于等于 | `a <= b` → 0 |
| `==` | 等于（注意：两个等号！） | `a == b` → 0 |
| `!=` | 不等于 | `a != b` → 1 |

关系运算符的结果为 `int` 类型的 1（真）或 0（假）。

```c
#include <stdio.h>

int main(void)
{
    int a = 5, b = 3;

    printf("5 > 3  => %d\n", a > b);    // 1
    printf("5 < 3  => %d\n", a < b);    // 0
    printf("5 == 3 => %d\n", a == b);   // 0

    // 常见陷阱：连续比较
    printf("5 > 4 > 3 => %d\n", 5 > 4 > 3);  // (5>4)=1, 1>3=0，结果为 0

    // 正确写法：分段比较
    printf("5 > 4 && 4 > 3 => %d\n", (5 > 4) && (4 > 3));  // 1
    return 0;
}
```

### 逻辑运算符

| 运算符 | 名称 | 类型 | 说明 |
|:------:|:----:|:----:|------|
| `!` | 逻辑非（NOT） | 单目 | 操作数为真时结果为假，反之亦然 |
| `&&` | 逻辑与（AND） | 双目 | 两个操作数均为真时结果为真 |
| `||` | 逻辑或（OR） | 双目 | 至少一个操作数为真时结果为真 |

在 C 语言中，"假"是 0，"真"是**任何非零值**（不限于 1）。

### 短路求值（Short-circuit Evaluation）

这是 C 语言逻辑运算符最重要的特性，也是面试必问题：

- **`expr1 && expr2`**：如果 `expr1` 为假（0），整个表达式已确定为假，`expr2` **不会被求值**
- **`expr1 || expr2`**：如果 `expr1` 为真（非 0），整个表达式已确定为真，`expr2` **不会被求值**

```c
#include <stdio.h>

int main(void)
{
    // 短路求值——&&
    int a = 0, b = 10;
    int result = (a != 0) && (b / a > 1);   // a != 0 为假，b / a 不会执行
    printf("result = %d, b = %d\n", result, b);  // result = 0, b = 10

    // 短路求值——||
    int x = 1, y = 0;
    result = x || (y = 5);                  // x 非零，y = 5 不会执行
    printf("result = %d, y = %d\n", result, y);  // result = 1, y = 0（未改变）

    // 工程实践：安全检查
    int *ptr = NULL;
    if (ptr != NULL && *ptr == 42) {        // 如果 ptr 是 NULL，*ptr 被短路，安全！
        printf("安全性检查通过\n");
    }

    return 0;
}
```

### 常见陷阱：= 与 == 混淆

```c
int x = 5;

// 意图：判断 x 是否等于 5
if (x = 5) {            // 编译通过！但这是赋值，不是比较！
    printf("总是执行\n"); // 因为 x = 5 的值为 5，非零即为真
}

// 防御性写法：将常量写在左侧
if (5 == x) {           // 正确：比较
    printf("x 等于 5\n");
}
// if (5 = x) { ... }   // 编译错误！不能给常量赋值，编译器会立刻报错
```

> **工程建议**：如果使用 GCC/Clang，开启 `-Wall` 会在 `if (x = 5)` 处发出警告。将常量放在 == 左侧是经典的防御性编程技巧。

## 位运算符深度

位运算符直接操作整数的二进制位序列。操作数必须为整数类型（不能用于浮点数）。

| 运算符 | 名称 | 类型 | 说明 |
|:------:|:----:|:----:|------|
| `&` | 按位与（AND） | 双目 | 两个位均为 1 时结果为 1 |
| `|` | 按位或（OR） | 双目 | 至少一个位为 1 时结果为 1 |
| `^` | 按位异或（XOR） | 双目 | 两个位不同时结果为 1 |
| `~` | 按位取反（NOT） | 单目 | 0 变 1，1 变 0 |
| `<<` | 左移 | 双目 | 各二进制位左移，低位补 0 |
| `>>` | 右移 | 双目 | 各二进制位右移，高位补 0 或符号位 |

### 基本位操作

```c
#include <stdio.h>

int main(void)
{
    unsigned char a = 0b0011;   // 3
    unsigned char b = 0b0101;   // 5

    printf("a & b  = %d\n", a & b);   // 0001 = 1
    printf("a | b  = %d\n", a | b);   // 0111 = 7
    printf("a ^ b  = %d\n", a ^ b);   // 0110 = 6
    printf("~a     = %d\n", ~a);      // 11111100 = 252（unsigned char 视角）

    // 移位
    printf("2 << 1 = %d\n", 2 << 1);  // 4
    printf("8 >> 2 = %d\n", 8 >> 2);  // 2
    return 0;
}
```

### 位操作常见模式（嵌入式开发核心技能）

```c
#include <stdio.h>
#include <stdint.h>

// 定义操作的位序号
#define BIT(n)  (1UL << (n))

int main(void)
{
    uint32_t reg = 0;

    // 1. 置位（set bit）：将第 3 位置为 1
    reg |= BIT(3);                  // reg = reg | (1 << 3)
    printf("置位后: 0x%08X\n", reg); // 0x00000008

    // 2. 清位（clear bit）：将第 3 位清零
    reg &= ~BIT(3);
    printf("清位后: 0x%08X\n", reg); // 0x00000000

    // 3. 翻转位（toggle bit）：第 3 位取反
    reg ^= BIT(3);
    printf("翻转后: 0x%08X\n", reg); // 0x00000008

    // 4. 读取位（test bit）：判断第 3 位是否为 1
    if (reg & BIT(3)) {
        printf("第 3 位是 1\n");
    }

    // 5. 批量操作多 bit
    reg = 0x0000FFFF;
    reg &= ~(BIT(7) | BIT(8));      // 同时清零第 7 和第 8 位
    printf("批量清位: 0x%08X\n", reg); // 0x0000FE7F

    // 6. 按位与的掩码提取
    uint32_t status = 0xA5;
    uint8_t lower_nibble = status & 0x0F;  // 取低 4 位
    uint8_t upper_nibble = (status >> 4) & 0x0F; // 取高 4 位
    printf("低位 = %d, 高位 = %d\n", lower_nibble, upper_nibble);

    return 0;
}
```

### 逻辑右移 vs 算术右移

右移（`>>`）的行为取决于操作数的类型：

- **无符号数**：高位始终补 0（逻辑右移，logical right shift）
- **有符号数**：高位补符号位（算术右移，arithmetic right shift），这是**实现定义**的，但绝大多数主流编译器采用算术右移

```c
#include <stdio.h>

int main(void)
{
    unsigned int u = 0x80000000;    // 最高位为 1
    signed int   s = 0x80000000;    // 最高位为 1，作为有符号数是负数

    printf("u >> 1 = 0x%08X\n", u >> 1);  // 0x40000000（逻辑右移，补 0）
    printf("s >> 1 = 0x%08X\n", s >> 1);  // 0xC0000000（算术右移，补符号位 1）

    // 负数右移
    signed int neg = -16;
    printf("neg >> 2 = %d\n", neg >> 2);  // -4（算术右移）
    return 0;
}
```

### 移位运算的未定义行为和实现定义行为

1. **移位位数为负数**：未定义行为
2. **移位位数大于或等于操作数的位宽**：未定义行为

```c
int x = 1;
x << -1;      // 未定义行为！移位位数为负数
x << 32;      // 未定义行为！假设 int 为 32 位，移位位数 ≥ 位宽
x << 31;      // 如果 int 为 32 位，移 31 位是合法的（但 x 为有符号时可能溢出——UB）
x >> 40;      // 未定义行为！移位位数超过类型位宽
```

> **工程规则**：移位前必须确保移位位数在 0 和类型位宽减 1 之间（含边界）。对 `uint32_t`，合法的移位范围是 0 ~ 31。

## 赋值与复合赋值

### 简单赋值 `=`

赋值是**表达式**，不是语句——它本身有值，值为赋值完成后的左值的内容。结合性从右到左。

```c
int a, b, c;
a = b = c = 5;      // 等价于 a = (b = (c = 5))，三个变量都是 5
                    // 1. c = 5 → 5
                    // 2. b = 5 → 5
                    // 3. a = 5 → 5

// 赋值在条件中的使用
int x;
if ((x = get_value()) != 0) {   // 先赋值，再比较赋值结果
    printf("获取到非零值: %d\n", x);
}
```

### 复合赋值运算符

复合赋值将算术/位运算与赋值合并为一个运算符。`a op= b` 等价于 `a = a op b`（但 `a` 只被求值一次）。

```c
#include <stdio.h>

int main(void)
{
    int a = 10;

    a += 5;       // a = 15
    a -= 3;       // a = 12
    a *= 2;       // a = 24
    a /= 4;       // a = 6
    a %= 4;       // a = 2

    unsigned int reg = 0x00FF;
    reg &= 0x0F0F;     // 等价于 reg = reg & 0x0F0F
    reg |= 0x00F0;     // 等价于 reg = reg | 0x00F0
    reg ^= 0x000F;     // 等价于 reg = reg ^ 0x000F
    reg <<= 2;         // 等价于 reg = reg << 2

    printf("reg = 0x%04X\n", reg);  // 0xF0C0
    return 0;
}
```

## 运算符优先级与结合性

### 完整优先级表（从高到低）

| 优先级 | 运算符 | 名称 | 结合性 |
|:------:|:------:|------|:------:|
| 1（最高） | `()` `[]` `->` `.` | 函数调用、数组下标、间接/直接成员访问 | 从左到右 |
| 2 | `!` `~` `++` `--` `+` `-` `*` `&` `(类型)` `sizeof` | 单目运算符（逻辑非、按位取反、自增自减、正负号、解引用、取址、类型转换、sizeof） | 从右到左 |
| 3 | `*` `/` `%` | 乘、除、取模 | 从左到右 |
| 4 | `+` `-` | 加、减 | 从左到右 |
| 5 | `<<` `>>` | 左移、右移 | 从左到右 |
| 6 | `<` `<=` `>` `>=` | 关系比较 | 从左到右 |
| 7 | `==` `!=` | 相等性比较 | 从左到右 |
| 8 | `&` | 按位与 | 从左到右 |
| 9 | `^` | 按位异或 | 从左到右 |
| 10 | `|` | 按位或 | 从左到右 |
| 11 | `&&` | 逻辑与 | 从左到右 |
| 12 | `||` | 逻辑或 | 从左到右 |
| 13 | `?:` | 条件（三目）运算符 | 从右到左 |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `|=` | 赋值和复合赋值 | 从右到左 |
| 15（最低） | `,` | 逗号运算符 | 从左到右 |

**简化记忆口诀**：**单目 > 算术 > 移位 > 关系 > 位逻辑 > 逻辑 > 条件 > 赋值 > 逗号**

### 常见优先级陷阱

```c
// 陷阱 1：*p++ 的含义
int arr[] = {10, 20, 30};
int *p = arr;
int val = *p++;          // 等价于 *(p++)：先取 *p（10），然后 p 自增
// 不是 (*p)++！(*p)++ 是递增 arr[0] 的值

// 陷阱 2：& 和 == 的优先级
int a = 1, b = 2;
if (a & b == 0) {        // 等价于 a & (b == 0)，即 a & 0 = 0
    printf("永远不会执行\n"); // 条件恒为假
}
// 正确写法：if ((a & b) == 0)

// 陷阱 3：移位与加减的优先级
int result = 1 << 2 + 3;     // 等价于 1 << (2+3) = 1 << 5 = 32
// 不是 (1<<2) + 3 = 4+3 = 7

// 陷阱 4：赋值与比较
int x;
if (x = 5) {              // 赋值，结果为 5（真），不是比较
    printf("总是执行\n");
}
```

> **工程建议**：不要依赖记忆中的优先级规则——当你对任何表达式的求值顺序不确定时，**立即加括号**。括号不会影响代码效率（它们只是告诉解析器你真正想要的方式），但能防止大量难以调试的 bug。

## 表达式求值与副作用

### 序列点（Sequence Point）

**序列点**是程序执行中的一个时刻，在该时刻之前的所有副作用（side effects）都已生效，之后的所有副作用尚未开始。在两个序列点之间，对一个标量对象的修改不应超过一次。

C 语言中的序列点包括：
- 语句末尾的分号（`;`）
- `&&` 和 `||` 的短路求值点
- 条件运算符 `?:` 的条件求值后
- 逗号运算符 `,` 的左侧表达式求值后
- 函数调用时（所有实参求值之后、函数体执行之前）

### 典型未定义行为——同一个表达式中多次修改

```c
int i = 0;

i = i++;                // UB：两个序列点间对 i 修改两次
i = i++ + ++i;          // UB：同上
printf("%d %d", i, i++);// UB：函数参数的求值顺序是未指定的，
                        // 且 i 和 i++ 之间没有序列点分隔

// 安全做法：拆分成独立的语句
i = 0;
int old = i++;          // old = 0, i = 1
int new = ++i;          // i = 2, new = 2
```

### 函数参数求值顺序是未指定的（Unspecified）

```c
#include <stdio.h>

int f1(void) { printf("f1 "); return 1; }
int f2(void) { printf("f2 "); return 2; }
int f3(void) { printf("f3 "); return 3; }

int main(void)
{
    int result = f1() + f2() * f3();  // 加法左右操作数的求值顺序未指定
    printf("= %d\n", result);
    // 可能的输出："f1 f2 f3 = 7" 或 "f2 f3 f1 = 7" 等
    // 但乘法的优先级保证 f2() * f3() 先于加法执行——这是语言语义，
    // 但谁先被求值（f2 还是 f3？）是未指定的

    printf("%d %d %d\n", f1(), f2(), f3());
    // 函数参数的求值顺序未指定！
    // 可能是 "f1 f2 f3"，也可能是 "f3 f2 f1"

    return 0;
}
```

> **关键理解**：**优先级（precedence）与求值顺序（evaluation order）是不同的概念**。优先级决定了运算符的分组方式，但**不决定**操作数或子表达式的求值顺序。例如 `f1() + f2() * f3()` 优先级保证 `f2() * f3()` 的乘法结果先获得，但无法确定 `f1`、`f2`、`f3` 三个函数的调用顺序。

## 条件运算符（三元运算符 `?:`）

### 基本语法

`条件表达式 ? 表达式1 : 表达式2`

- 条件表达式为真（非零）：整个表达式的值等于"表达式1"的值
- 条件表达式为假（零）：整个表达式的值等于"表达式2"的值

```c
#include <stdio.h>

int main(void)
{
    int a = 10, b = 20;
    int max = (a > b) ? a : b;             // max = 20
    printf("最大值: %d\n", max);

    // 嵌套使用（不推荐过多嵌套）
    int x = 15;
    const char *category = (x < 0)  ? "负数"
                         : (x == 0) ? "零"
                         :            "正数";
    printf("%d 是%s\n", x, category);       // 15 是正数

    return 0;
}
```

### 类型兼容规则

`?:` 的第二个和第三个表达式必须是**类型兼容**的。如果不兼容，编译器会尝试隐式类型转换：

```c
int a = 10;
double b = 3.14;
void *p = NULL;

int result = (a > 5) ? a : b;      // 10（a 被隐式转换为 double 再比较，
                                   // 但结果赋值给 int 时又被截断为 10）
// int *ptr = (a > 5) ? &a : p;    // 编译错误：int* 和 void* 不兼容
```

### 在宏定义中的用途

```c
// 安全的宏：获取两个值的最大值（避免多次求值）
#define MAX(a, b) ((a) > (b) ? (a) : (b))

// 但注意：MAX(++x, y) 中的 ++x 会被求值两次（宏展开）！
// 更好的做法（GCC 扩展，不建议跨平台）：
// #define MAX(a, b) ({ typeof(a) _a = (a); typeof(b) _b = (b); \
//                      _a > _b ? _a : _b; })
```

## 逗号运算符

### 语法和行为

逗号运算符 `,` 具有**最低的优先级**，从左到右求值。先求左侧表达式的值并丢弃（作为副作用执行），再求右侧表达式的值，整个逗号表达式的值为右侧表达式的值。逗号运算符是一个序列点——左侧的副作用在右侧开始求值前完成。

```c
#include <stdio.h>

int main(void)
{
    int a, b;

    // 先执行 b = 3，再执行 b + 5，整个表达式的值为 8
    a = (b = 3, b + 5);
    printf("a = %d, b = %d\n", a, b);  // a = 8, b = 3

    // 逗号运算符优先级最低——注意与函数参数括号的区别
    int x = 1, y = 2;
    int z = (x++, y++);       // z = 2（y++ 的值），x = 2, y = 3
    printf("z = %d\n", z);    // z = 2

    // 无括号的情况
    int v = (x++, ++y);       // v = ?（考虑优先级）
    return 0;
}
```

### 在 for 循环中的使用

```c
#include <stdio.h>

int main(void)
{
    // 同时初始化多个变量，并在每次迭代中更新多个变量
    for (int i = 0, j = 10; i < j; i++, j--) {
        printf("i = %d, j = %d\n", i, j);
    }

    // 逗号运算符在循环体内用于多个操作
    int sum = 0;
    int arr[] = {1, 2, 3, 4, 5};
    int *p = arr;
    while (*p) {
        sum += *p++;
    }
    return 0;
}
```

### 逗号运算符 vs 函数参数分隔符

```c
// 函数调用中的逗号是参数分隔符，不是逗号运算符
printf("%d %d\n", 1, 2);   // 这里的逗号是参数分隔符

// 真正的逗号运算符需要括号
int a = (1, 2, 3);          // 逗号表达式：1 → 2 → 3，a = 3
// 如果没有括号：
int b = 1, 2, 3;            // 编译错误！1 不是左值，无法赋值
// 实际上 b = 1 被解析为变量声明和初始化（int b = 1），后面的 ", 2" 非法
```

## 嵌入式开发中的运算符

### 位操作是寄存器访问的核心

嵌入式开发中，对硬件寄存器的操作几乎全部通过位运算实现：

```c
#include <stdint.h>

// 典型 MCU 寄存器操作模式
#define GPIOA_BASE      0x40020000UL

// 寄存器定义（使用 volatile 防止编译器优化）
#define GPIOA_MODER    (*(volatile uint32_t *)(GPIOA_BASE + 0x00))
#define GPIOA_OTYPER   (*(volatile uint32_t *)(GPIOA_BASE + 0x04))
#define GPIOA_OSPEEDR  (*(volatile uint32_t *)(GPIOA_BASE + 0x08))
#define GPIOA_PUPDR    (*(volatile uint32_t *)(GPIOA_BASE + 0x0C))
#define GPIOA_ODR      (*(volatile uint32_t *)(GPIOA_BASE + 0x14))
#define GPIOA_IDR      (*(volatile uint32_t *)(GPIOA_BASE + 0x10))

#define BIT(n)  (1UL << (n))

// 设置 GPIOA 引脚 5 为输出模式
void gpio_init(void)
{
    // MODER 寄存器：每 2 位控制一个引脚（00=输入, 01=输出, 10=复用, 11=模拟）
    GPIOA_MODER &= ~(0x3 << (5 * 2));    // 先清零 PA5 的 MODER 位段
    GPIOA_MODER |=  (0x1 << (5 * 2));    // 设为输出模式（01）

    // 设置推挽输出类型
    GPIOA_OTYPER &= ~BIT(5);             // 0 = 推挽输出（push-pull）

    // 设置输出速度为高速
    GPIOA_OSPEEDR |= (0x2 << (5 * 2));   // 10 = 高速

    // 使能内部上拉
    GPIOA_PUPDR |= (0x1 << (5 * 2));     // 01 = 上拉
}

// 写引脚
void gpio_write(int value)
{
    if (value) {
        GPIOA_ODR |= BIT(5);             // 置位：输出高电平
    } else {
        GPIOA_ODR &= ~BIT(5);            // 清零：输出低电平
    }
}

// 读引脚
int gpio_read(void)
{
    return (GPIOA_IDR >> 5) & 0x1;       // 读取第 5 位的值
}
```

### volatile 与位操作的配合

```c
// 硬件寄存器必须使用 volatile——编译器绝不允许优化掉对寄存器的读写
volatile uint32_t *timer_counter = (volatile uint32_t *)0x40004000;

// 每次读取都真正从硬件读取
while (*timer_counter < 1000) {
    // 等待硬件计数器达到 1000
}

// 连续写入——编译器必须保留每次写入
*timer_counter = 0;     // 重置计数器
*timer_counter = 100;   // 预装载值
// 如果 timer_counter 不是 volatile，编译器可能会优化掉"冗余"的写入
```

### 位段提取与合并

```c
// 从 32 位寄存器中提取特定位段
// 例如：寄存器位 [15:8] 表示状态值
uint32_t status_reg = 0xA5F0;
uint8_t status = (status_reg >> 8) & 0xFF;   // 0xA5

// 合并多个字段为一个寄存器值
// 字段 A：位 [3:0]，字段 B：位 [7:4]，字段 C：位 [15:8]

uint32_t field_b = 0xA;
uint32_t field_c = 0x55;

                 | (field_b << 4)
                 | (field_c << 8);
// reg_val = 0x55A3
```

## 面试直连

### Q1: 什么是短路求值？（What is short-circuit evaluation?）

**答案**：短路求值是 C 语言逻辑运算符 `&&` 和 `||` 的特性：当左侧操作数已经能够确定整个表达式的值时，右侧操作数**不会被求值**。`a && b`：若 a 为假，b 不会被执行；`a || b`：若 a 为真，b 不会被执行。这在工程上常用于前置条件检查，如 `if (ptr != NULL && *ptr == 42)`——如果 ptr 是 NULL，*ptr 不会被求值，避免了空指针解引用。

### Q2: `i++` 和 `++i` 有什么区别？（Explain the difference between i++ and ++i）

**答案**：`i++`（后缀自增）表达式的值是 i 递增**之前**的值；`++i`（前缀自增）表达式的值是 i 递增**之后**的值。两者都会使 i 最终增加 1。在 for 循环中使用前缀或后缀自增对内建类型通常没有性能差异（现代编译器会优化），但对于迭代器等重载了 `operator++` 的类型，前缀版本通常更高效（因为后缀需要拷贝原值）。**注意**：不要在同一个表达式中对同一变量多次使用自增——`i = i++` 是未定义行为。

### Q3: 为什么 `a[i]` 等价于 `*(a + i)`？（Why is a[i] equivalent to *(a+i)?）

**答案**：C 标准明确定义：下标运算符 `[]` 等价于指针运算的语法糖。`a[i]` 被定义为 `*( (a) + (i) )`。这意味着 `a[0]` 等价于 `*a`，而且 **`a[i]` 等价于 `i[a]`**（虽然正常人不会这么写）。这个设计反映了 C 语言的一个核心理念：数组名在表达式中退化为指向首元素的指针。

### Q4: 逗号运算符的作用是什么？（What does the comma operator do?）

**答案**：逗号运算符 `,` 从左到右依次求值，整个表达式的值等于最右侧操作数的值。它常被用于 for 循环中同时更新多个变量（`for (int i=0, j=10; i<j; i++, j--)`）。注意：逗号运算符的优先级是所有运算符中最低的，而函数调用中的逗号是参数分隔符，不是逗号运算符。

### Q5: 如何编写宏来置位、清零、翻转一个位？（Write a macro to set/clear/toggle a bit）

```c
#define BIT(n)          (1UL << (n))
#define SET_BIT(reg, n)   ((reg) |= BIT(n))
#define CLEAR_BIT(reg, n) ((reg) &= ~BIT(n))
#define TOGGLE_BIT(reg, n)((reg) ^= BIT(n))
#define READ_BIT(reg, n)  (((reg) >> (n)) & 1U)
```

### Q6: 将值移位超过其位宽会怎样？（What happens when you shift a value by more than its bit width?）

**答案**：移位的位数如果为负数或大于等于操作数的位宽（以位计），产生**未定义行为（UB）**。例如对 32 位的 `int` 执行 `x << 32` 或 `x >> -1` 都是 UB。编译器可以生成任意代码，可能产生任何结果。一定要在移位前确保移位位数在合法范围内（0 到类型位宽减 1）。

### Q7: `*p++` 做了什么？（Explain operator precedence: what does *p++ do?）

**答案**：`*p++` 等价于 `*(p++)`。优先级表中，后缀自增 `++` 的优先级（第 2 级，结合性从右到左，但注意后缀自增优先于单目 `*`）高于单目解引用 `*`。所以：
1. `p++` 先被求值（返回 p 的原值，副作用使 p 指向下一元素）
2. `*` 对 p 的原值解引用，得到当前指向的元素值
3. 结果：取当前值，然后指针前移

这与 `(*p)++` 完全不同后者解引用后递增元素的值。

### Q8: 优先级和求值顺序有什么不同？（Precedence vs evaluation order）

**答案**：**优先级（precedence）** 决定运算符的分组方式——哪些操作数和哪个运算符结合。**求值顺序（evaluation order）** 决定子表达式在何时被求值。优先级不决定求值顺序！例如 `f1() + f2() * f3()`：优先级保证 `f2() * f3()` 先被计算（乘法结果作为加法的右操作数），但无法保证 `f1()` 和 `f2()` 哪个先被调用——这是未指定的（unspecified）。只有在序列点处，C 标准才保证所有之前的副作用已经完成。

### Q9: 什么是序列点？为什么重要？

**答案**：序列点是程序执行中的一个时刻，在该时刻所有之前的副作用都已生效。两个序列点之间对同一个标量对象**最多只能修改一次**，否则产生未定义行为。序列点包括：语句尾的分号、`&&` 和 `||` 的左操作数之后、条件运算符 `?:` 的条件之后、逗号运算符的左操作数之后、函数调用所有实参求值之后。典型的 UB：`i = i++`（两个序列点间改了两次 i）。

### Q10: 如何在嵌入式开发中安全地读取/写入硬件寄存器？

**答案**：三个关键点：1）寄存器指针必须有 `volatile` 限定符，防止编译器优化掉看似冗余的连续读写；2）位操作（置位/清零）使用 `|=` 和 `&= ~` 模式，避免干扰其他位；3）对只读寄存器使用 `const volatile` 修饰（程序不能写，但硬件可以更新）。此外，对某些需要特定读/写顺序的寄存器序列，可能需要内存屏障（memory barrier）来防止编译器或 CPU 重排指令。

## 代码阅读题

### 题 1：优先级与自增

```c
#include <stdio.h>

int main(void)
{
    int a = 0, b = 0, c = 0;
    int x, y, z, w;

    x = ++a + ++a;
    printf("a = %d, x = %d\n", a, x);  // ①

    y = b++ + b++;
    printf("b = %d, y = %d\n", b, y);  // ②

    int arr[] = {10, 20, 30};
    int *p = arr;
    z = *p++;
    printf("z = %d, arr[0] = %d\n", z, arr[0]);  // ③

    w = ++*p;
    printf("w = %d, arr[1] = %d\n", w, arr[1]);  // ④

    return 0;
}
```

**问题**：分析上述代码的输出。注意：`++a + ++a` 和 `b++ + b++` 可能产生不同的编译器行为。

<details>
<summary>答案与解析</summary>

- ① `++a + ++a`：**未定义行为**。在一个表达式中两次修改 a，之间没有序列点。不同的编译器可能输出不同的结果（GCC 可能输出 a=2, x=4；Clang 也可能不同）。这种代码不应出现在任何生产代码中。
- ② `b++ + b++`：同样是**未定义行为**，理由同上。
- ③ `*p++`：等价于 `*(p++)`。先取 `*p` 得到 10（arr[0]），然后 p 前移指向 arr[1]。所以 z=10, arr[0]=10（未被修改）。
- ④ `++*p`：等价于 `++(*p)`。p 现在指向 arr[1]，先解引用得到 20，再自增为 21。所以 w=21, arr[1]=21。
</details>

### 题 2：位运算与移位

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint8_t a = 0xAB;        // 171 = 10101011
    uint8_t b = 0xCD;        // 205 = 11001101

    uint8_t r1 = a & b;
    uint8_t r2 = a | b;
    uint8_t r3 = a ^ b;
    uint8_t r4 = ~a;

    printf("r1 = 0x%02X\n", r1);
    printf("r2 = 0x%02X\n", r2);
    printf("r3 = 0x%02X\n", r3);
    printf("r4 = 0x%02X\n", r4);

    int x = -8;
    printf("x >> 2 = %d\n", x >> 2);          // ⑤
    printf("(unsigned)x >> 2 = %u\n", (unsigned)x >> 2); // ⑥

    return 0;
}
```

**问题**：写出每行输出（假设 32 位 int、二进制补码、算术右移）。解释 ⑤ 和 ⑥ 的结果差异。

<details>
<summary>答案与解析</summary>

- `r1 = 0x89`（10001001）：a & b 的按位与结果
- `r2 = 0xEF`（11101111）：a | b 的按位或结果
- `r3 = 0x66`（01100110）：a ^ b 的按位异或结果
- `r4 = 0x54`（01010100）：~a（对 `uint8_t` 提升为 int 后取反，再截断回 8 位）

⑤ `x >> 2 = -2`：有符号数 -8（0xFFFFFFF8）算术右移 2 位，高位补符号位 1，结果为 -2（0xFFFFFFFE）。

⑥ `(unsigned)x >> 2 = 1073741822`：将 -8 转为 unsigned int（0xFFFFFFF8 = 4294967288），逻辑右移 2 位（高位补 0），结果为 0x3FFFFFFE = 1073741822。
</details>

### 题 3：复杂表达式求值

```c
#include <stdio.h>

int main(void)
{
    int a = 1, b = 2, c = 3;
    int result = 0;

    result = a++ + b * c - --b;
    printf("result = %d, a = %d, b = %d\n", result, a, b);  // ①

    // 优先级测试
    int x = 3, y = 5, z = 2;
    int v = x++ > 3 ? y += z : --z + y;
    printf("v = %d, x = %d, y = %d, z = %d\n", v, x, y, z);  // ②

    // 逗号与赋值
    int m, n;
    m = (n = 5, n + 2);
    printf("m = %d, n = %d\n", m, n);  // ③

    return 0;
}
```

**问题**：分析每一行 printf 的输出。

<details>
<summary>答案与解析</summary>

① `result = a++ + b * c - --b`
- 优先级：`*` 最高，然后 `++` 和 `--`，最后 `+` 和 `-`
- `b * c = 2 * 3 = 6`
- `--b` → b = 1
- `a++` → 表达式值为 1（a 变为 2）
- `1 + 6 - 1 = 6`
- 输出：result = 6, a = 2, b = 1

② `v = x++ > 3 ? y += z : --z + y`
- `x++ > 3` → 3 > 3 为假（0），x 变为 4
- 走 `: --z + y`
- `--z` → z = 1
- `--z + y = 1 + 5 = 6`
- v = 6
- 输出：v = 6, x = 4, y = 5（y += z 未被求值，因为条件为假）, z = 1

③ `m = (n = 5, n + 2)`
- 逗号表达式：先 n = 5，再 n + 2 = 7，整个逗号表达式值为 7
- m = 7, n = 5
</details>

### 练习 2：宏优先级陷阱分析

```c
#include <stdio.h>

#define SQR(x) x * x
#define CUBE(x) (x) * (x) * (x)
#define MAX(a, b) a > b ? a : b

int main(void)
{
    int a = 3;
    int result1 = SQR(a + 1);         // ①
    int result2 = 100 / SQR(5);       // ②
    int result3 = CUBE(a + 1);        // ③
    int result4 = MAX(++a, a + 1);    // ④

    printf("① %d, ② %d, ③ %d, ④ a = %d\n", result1, result2, result3, a);
    return 0;
}
```

**问题**：
1. 写出上述程序的输出（分析宏展开后的表达式）

## 本章总结

1. **运算符分类**：C 语言的运算符按功能分为算术、关系、逻辑、位、赋值、条件、逗号、sizeof、类型转换等。
2. **整数除法向零截断**：整数 `/` 截断小数部分，`%` 的符号与被除数相同（C99 起标准行为）。
3. **自增自减**：`++i` 返回递增后的值，`i++` 返回递增前的值。不要在同一个表达式中对同一变量多次使用自增。
4. **短路求值**：`&&` 在左侧为假时停止，`||` 在左侧为真时停止，右侧操作数**不会**被执行。
5. **位运算**：置位用 `|=`、清位用 `&=` 和 `~`、翻转用 `^=`。移位超过类型位宽是未定义行为。
6. **优先级与结合性**：单目 > 算术 > 移位 > 关系 > 位逻辑 > 逻辑 > 条件 > 赋值 > 逗号。不确定时就加括号。
7. **序列点**：两个序列点间对同一变量最多修改一次。`i = i++` 等是未定义行为。
8. **条件运算符**：常用于简洁的条件赋值，宏定义中需要谨慎处理参数多次求值的问题。
9. **逗号运算符**：从左到右依次求值，表达式的值为最右侧的值。在 for 循环中多变量更新时常用。
10. **嵌入式应用**：位运算是嵌入式驱动开发的基础，配合 volatile 使用可实现安全的 MMIO 访问。
