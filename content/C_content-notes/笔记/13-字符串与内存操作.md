# 字符串与内存操作

## 学习目标

- 理解 C 语言中字符串的本质：以 `\0` 结尾的字符数组（ASCIIZ 格式）
- 掌握 `sizeof`（编译期运算符，返回含 `\0` 的字节数）与 `strlen`（运行期函数，返回不含 `\0` 的字符数）的严格区别
- 掌握标准字符串处理函数族（`strcpy`、`strcat`、`strcmp`、`strstr` 等）的原理、用法与陷阱
- 掌握标准内存操作函数族（`memset`、`memcpy`、`memmove`、`memcmp`）的原理与安全用法
- 理解 `memcpy` 与 `memmove` 重叠区域的本质区别及正确选择
- 理解字符串/数字转换的安全做法及错误处理
- 能够识别并避免日常编码中常见的字符串与内存错误（缓冲区溢出、未初始化、越界访问等）
- 建立嵌入式环境下的字符串与内存安全意识

## 本章与工作的关系

字符串与内存操作在 C 语言开发中无处不在，其重要性体现在以下几个核心场景：

**日志输出：** 嵌入式设备通过 UART 输出调试日志，涉及格式化字符串（`snprintf`）和逐字符发送。日志缓冲区通常使用环形缓冲区（ring buffer），需要手动管理写指针和读指针。错误的字符串操作可能导致日志覆盖、信息丢失甚至系统崩溃。

**协议解析：** 网络协议（如 TCP/IP、MQTT、Modbus）和自定义通信协议的数据帧通常是字节流，解析时大量使用 `memcpy`、`memcmp`、`strstr`、`strtok` 等函数。一个字节的越界可能造成安全漏洞。

**配置读取：** 配置文件（INI、JSON 子集、键值对）的解析依赖字符串分割、比较和转换函数。配置项通常存储在静态 buffer 中，用 `strncpy` 或 `snprintf` 写入。

**Buffer 管理：** 嵌入式开发中大量使用固定大小的静态 buffer。`memset` 用于初始化或清除 buffer，`memcpy`/`memmove` 用于数据搬运。DMA（直接存储器访问）传输中需要精确控制内存地址和长度，错误的 size 计算会导致硬件错误。

**安全影响：** 缓冲区溢出是 C 语言最经典的安全漏洞（CWE-120）。攻击者通过精心构造的输入覆盖栈上的返回地址，实现代码执行。此类漏洞历史上造成过无数次严重安全事件（如 Morris 蠕虫、Heartbleed）。因此，理解并防范字符串操作的安全问题不仅是编码规范要求，更是安全底线。

## C语言中的字符串

C 语言没有像 Python 或 Java 那样的原生字符串类型。字符串在 C 中是以**空字符 `'\0'`（null terminator）结尾的字符数组**。这种格式常被称为 ASCIIZ（ASCII Zero-terminated）字符串。

### 字符数组与字符串

字符数组和字符串的关系是包含关系：字符数组不一定以 `\0` 结尾，而字符串一定是**以 `\0` 结尾的字符数组**。

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    // 以下三种定义方式完全等价
    char s1[] = "hello";
    // s1 是 char[6]，自动添加 '\0'
    // 内存布局: {'h','e','l','l','o','\0'}

    char s2[] = {'h', 'e', 'l', 'l', 'o', '\0'};
    // 手工逐个给出字符，必须自己包含 '\0'

    char s3[6] = {'h', 'e', 'l', 'l', 'o', '\0'};
    // 指定大小，明确为 6

    printf("s1 = %s\n", s1);      // hello
    printf("s2 = %s\n", s2);      // hello
    printf("s3 = %s\n", s3);      // hello

    // 字符数组如果不以 '\0' 结尾，用 %s 打印会越界（UB）
    char not_a_string[] = {'a', 'b', 'c'};
    // 没有 '\0'，下面这行是 未定义行为（UB）
    // printf("%s\n", not_a_string);  // 危险！

    return 0;
}
```

### 内存布局

```
字符串 "hello" 在内存中：

  地址偏移:  +0    +1    +2    +3    +4    +5
            +-----+-----+-----+-----+-----+-----+
            | 'h' | 'e' | 'l' | 'l' | 'o' |'\0' |
            +-----+-----+-----+-----+-----+-----+
  下标:       0     1     2     3     4     5

'\0' 的 ASCII 值是 0，占用 1 字节。
```

### `char arr[]` 与 `char *` 的关键区别

这是 C 语言初学者最常见的混淆点之一。

```c
char arr[] = "hello";   // arr 是一个数组，大小 6 字节
char *p    = "hello";   // p 是一个指针，指向字符串字面量
```

| 特性 | `char arr[]` | `char *p` |
|---|---|---|
| 存储位置 | 栈上（自动变量） | 指针在栈上，指向只读数据段（.rodata） |
| 内容是否可修改 | **可以**修改（arr 是可变副本） | **不可以**修改（修改是 UB） |
| `sizeof(arr)` / `sizeof(p)` | 6（整个数组大小） | 8 或 4（指针本身大小，64/32 位） |
| `&arr` vs `&p` | `&arr` 类型是 `char (*)[6]` | `&p` 类型是 `char **` |
| 赋值行为 | `arr = other` 编译报错（数组不可赋值） | `p = other` 可以 |

```c
#include <stdio.h>

int main(void)
{
    char arr[] = "hello";
    char *p    = "hello";

    // arr 可以修改
    arr[0] = 'H';               // OK，arr 变为 "Hello"
    printf("arr: %s\n", arr);   // Hello

    // p 指向只读内存，修改是 未定义行为（UB）
    // p[0] = 'H';              // 可能会导致段错误（segmentation fault）崩溃

    // 但 p 本身可以重新指向别的字符串
    p = "world";                // OK
    printf("p: %s\n", p);       // world

    return 0;
}
```

### 关键概念

1. **`'\0'` 是字符串结束标志**：所有 C 标准字符串函数（`strlen`、`strcpy`、`strcmp` 等）都依赖 `'\0'` 来判断字符串何时结束。如果缺少 `'\0'`，这些函数会继续读取后续内存直到碰巧遇到 0 字节，导致**缓冲区溢出读取**（UB）。

2. **`'\0'` 和 `NULL` 不同**：`'\0'` 是空字符（ASCII 值为 0 的字符），`NULL` 是空指针（通常是 `(void*)0`），`0` 是整数字面量。三者在数值上都是 0，但用途和类型完全不同。

3. **字符串长度与 buffer 大小的关系**：buffer 大小必须 `>=` 字符串长度 `+ 1`（给 `'\0'` 预留位置）。

## 字符串字面量

### 定义与存储

字符串字面量（string literal）是用双引号括起来的字符序列，如 `"hello"`、`"world"`。在 C 标准中，字符串字面量的类型是 `char[N]`（N 为包含 `'\0'` 的字符数），但它的存储位置是**只读数据段（.rodata）**。

```c
#include <stdio.h>

int main(void)
{
    // "hello" 是一个字符串字面量，存储在 .rodata 段
    // arr 是局部数组，编译器在栈上为 arr 分配 6 字节
    // 然后在运行时将 .rodata 中的 "hello\0" 拷贝到栈上
    char arr[] = "hello";

    // p 是指向字符串字面量的指针
    // 编译器和链接器将 "hello" 放在 .rodata 段
    // p 的值是这个只读区域的首地址
    char *p = "hello";

    // 检查 .rodata 的地址（不同平台地址可能不同）
    printf("arr 地址: %p\n", (void*)arr);
    printf("p 指向:  %p\n", (void*)p);

    return 0;
}
```

### 字符串字面量是不可修改的

修改字符串字面量是**未定义行为（UB）**。在实际执行中，操作系统会将 `.rodata` 段所在的内存页标记为只读，写入操作将触发段错误（segmentation fault）。

```c
#include <stdio.h>

int main(void)
{
    char *p = "hello";

    // 尝试修改字符串字面量——UB！
    // 在大多数现代系统上会导致段错误（崩溃）
    // p[0] = 'H';  // 取消注释试试看

    // 正确做法：用数组创建可变副本
    char arr[] = "hello";
    arr[0] = 'H';
    printf("%s\n", arr);  // Hello

    return 0;
}
```

### `char arr[] = "hello"` 与 `char *p = "hello"` 的本质区别

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char arr[] = "hello";   // arr: char[6] 栈上可变副本
    char *p    = "hello";   // p:  const char* 指向 .rodata

    // sizeof 的结果完全不同
    printf("sizeof(arr) = %zu\n", sizeof(arr));  // 6（数组的总字节数）
    printf("sizeof(p)   = %zu\n", sizeof(p));    // 8（64位）或 4（32位）

    // 取地址的结果类型不同
    printf("&arr 类型: char (*)[6]\n");
    printf("&p   类型: char **\n");

    // 赋值行为不同
    // arr = "world";     // 编译错误：数组名不是可修改的左值
    p = "world";          // OK：p 重新指向另一个字符串字面量

    return 0;
}
```

### 字符串字面量的拼接

C 编译器会自动连接相邻的字符串字面量，这在定义长字符串时非常有用。

```c
#include <stdio.h>

int main(void)
{
    // 相邻的字符串字面量会在编译期自动拼接
    char s[] = "hello" ", " "world" "!";
    printf("%s\n", s);  // hello, world!

    // 适用于宏定义
    #define LOG_PREFIX "[DEBUG] "
    printf(LOG_PREFIX "file %s line %d\n", __FILE__, __LINE__);
    // 输出: [DEBUG] file test.c line 12

    return 0;
}
```

## sizeof 与 strlen（重要）

这是 C 语言面试中最高频的问题之一，也是实际开发中最容易混淆的概念。

### 核心区别对照表

| 对比项 | `sizeof` | `strlen` |
|---|---|---|
| **类别** | **编译期运算符**（operator） | **运行期函数**（function in `<string.h>`） |
| **返回值** | 操作数的**字节数**（包含 `'\0'`） | 字符串的**字符数**（不含 `'\0'`） |
| **参数类型** | 任何类型、变量、表达式（不计算表达式） | 只接受 `const char*`（必须是以 `\0` 结尾的字符串） |
| **对数组** | 返回整个数组占用的字节数 | 从首地址开始计数，直到遇到 `'\0'` 为止 |
| **对指针** | 返回**指针本身**占用的字节数（64位→8，32位→4） | 仍正常工作，遍历指针指向的内存直到 `'\0'` |
| **计算时机** | **编译期**（VLA 除外） | **运行期**（逐字节扫描） |
| **是否受 `\0` 影响** | 受数组定义时的初始化影响（包含 `\0`） | 受运行时 `\0` 位置影响（不包含 `\0`） |

### 典型例子

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[] = "hello";  // s: char[6] = {'h','e','l','l','o','\0'}

    printf("sizeof(s)  = %zu\n", sizeof(s));   // 6（6 个字节）
    printf("strlen(s)  = %zu\n", strlen(s));   // 5（5 个字符，不含 '\0'）

    char s2[100] = "hi";
    printf("sizeof(s2) = %zu\n", sizeof(s2));  // 100（整个数组大小）
    printf("strlen(s2) = %zu\n", strlen(s2));  // 2（只有两个字符）

    // 陷阱：对指针使用 sizeof
    char *p = s;
    printf("sizeof(p)  = %zu\n", sizeof(p));   // 8（指针本身的字节数，64位系统）
    printf("strlen(p)  = %zu\n", strlen(p));   // 5（没问题，strlen 通过指针访问字符串）

    // 陷阱：sizeof 对函数参数中的"数组"（实为指针）
    // 详见下面的函数示例

    return 0;
}
```

### 函数参数中的陷阱

当数组作为函数参数传递时，它**退化（decay）为指针**。此时 `sizeof` 只能得到指针的大小。

```c
#include <stdio.h>
#include <string.h>

// 虽然写的是 char s[]，但在函数参数中它完全等价于 char *s
// 数组已经退化成了指针！
void print_sizeof(char s[])
{
    // 这里 sizeof(s) 是 8（指针大小），不是数组大小！
    printf("在函数内部: sizeof(s) = %zu\n", sizeof(s));
}

int main(void)
{
    char arr[] = "hello";
    printf("在 main 中: sizeof(arr) = %zu\n", sizeof(arr));  // 6

    print_sizeof(arr);
    // 输出: 在函数内部: sizeof(s) = 8

    return 0;
}
```

### 内存示意图

```
char s[] = "hello";

  内存:  [ h ][ e ][ l ][ l ][ o ][\0 ]
          ^
          | s[0]
          |
          +--- strlen(s) 从这开始数到 \0 之前 = 5
          +--- sizeof(s) 从这开始的全部 6 字节 = 6

char s2[100] = "hi";

  内存:  [ h ][ i ][\0 ][   ][   ] ... [   ]  (剩余 97 个未初始化的字节)
          0    1    2    3    4         99
          |_______________|_____________________|
               strlen=2        sizeof=100
```

### 实际开发中的注意事项

1. **用 `sizeof` 计算数组元素个数**：`sizeof(arr) / sizeof(arr[0])`
2. **用 `strlen` 计算字符串长度**（不含 `\0`），以便确定需要多少额外空间
3. **传递 buffer 大小时务必用 `sizeof`**：`snprintf(buf, sizeof(buf), "%s", src);`
4. **绝对不要对指针用 `sizeof` 获取"数组大小"**——这是最常见的 bug 之一

## 标准字符串函数

所有标准字符串函数声明在 `<string.h>`。这些函数操作的都是以 `\0` 结尾的字符串。

### `strlen` — 计算字符串长度

```c
size_t strlen(const char *s);
```

- **功能**：计算字符串 `s` 的长度（字符数），不包含结尾的 `'\0'`
- **返回值**：类型 `size_t`（无符号整数），字符串的长度
- **注意**：如果 `s` 不是以 `\0` 结尾的合法字符串，函数会一直扫描直到内存中碰巧出现 0 字节，这是 UB

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s1[] = "hello";
    printf("strlen(\"hello\") = %zu\n", strlen(s1));  // 5

    char s2[] = "";
    printf("strlen(\"\") = %zu\n", strlen(s2));        // 0（空字符串）

    // strlen 时间复杂度 O(n)，因为必须扫描整个字符串
    // 频繁调用的场景应考虑缓存长度

    return 0;
}
```

### `strcpy` — 字符串拷贝（无边界检查）

```c
char *strcpy(char *dest, const char *src);
```

- **功能**：将 `src` 指向的字符串（包括 `\0`）拷贝到 `dest` 指向的缓冲区
- **返回值**：返回 `dest`（方便链式调用）
- **危险**：**完全不检查目标缓冲区大小**，如果 `src` 比 `dest` 长，必然发生缓冲区溢出（UB）

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char dest[10];

    // 安全情况：src 足够短
    strcpy(dest, "hi");
    printf("dest = %s\n", dest);  // hi

    // 危险情况：缓冲区溢出！
    // char src[] = "this is a very long string";
    // strcpy(dest, src);  // 溢出 dest[10]，UB！

    // strcpy 的返回值可以链式调用
    char buf[100];
    printf("%s\n", strcpy(buf, "hello"));  // hello

    return 0;
}
```

### `strncpy` — 有限拷贝（不保证添加 `\0`！）

```c
char *strncpy(char *dest, const char *src, size_t n);
```

- **功能**：最多从 `src` 拷贝 `n` 个字符到 `dest`
- **关键陷阱**：如果 `src` 的长度 `>= n`，则 `strncpy` **不会**在 `dest` 末尾添加 `'\0'`
- **行为细节**：如果 `src` 长度 `< n`，则拷贝完 `src`（含 `\0`）后，剩余部分用 `'\0'` 填充
- **返回值**：返回 `dest`

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char buf[5];

    // 情况1：src 长度 < n — 安全，会补 '\0'
    strncpy(buf, "ab", sizeof(buf));
    // buf = {'a', 'b', '\0', '\0', '\0'}
    printf("buf = \"%s\"\n", buf);  // ab

    // 情况2：src 长度 >= n — 危险！不会加 '\0'
    strncpy(buf, "abcdefgh", sizeof(buf));
    // buf = {'a', 'b', 'c', 'd', 'e'} — 没有 '\0'！
    // printf("%s\n", buf);  // UB！没有 '\0' 结尾

    // 标准做法：手动加 '\0'
    strncpy(buf, "abcdefgh", sizeof(buf) - 1);
    buf[sizeof(buf) - 1] = '\0';  // 手动保证以 '\0' 结尾
    printf("buf = \"%s\"\n", buf);  // abcd

    return 0;
}
```

### `strcat` — 字符串拼接（无边界检查）

```c
char *strcat(char *dest, const char *src);
```

- **功能**：将 `src` 追加到 `dest` 的末尾（覆盖 `dest` 原来的 `\0`，然后在新结尾加 `\0`）
- **前提**：`dest` 必须有足够空间容纳 `dest` 原字符串 + `src` 字符串 + `'\0'`
- **危险**：完全不检查目标缓冲区剩余空间！溢出风险极高

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[50] = "Hello";
    strcat(s, " World");
    printf("%s\n", s);  // Hello World

    // 危险示例：
    // char small[10] = "Hi";
    // strcat(small, " there, how are you?");  // 溢出！UB

    return 0;
}
```

### `strncat` — 有限拼接（保证添加 `\0`）

```c
char *strncat(char *dest, const char *src, size_t n);
```

- **功能**：将 `src` 中最多 `n` 个字符追加到 `dest` 末尾
- **与 `strncpy` 的重要区别**：`strncat` **一定会**在结果末尾添加 `'\0'`
- **注意**：即使 `src` 长度 `>= n`，也只拷贝 `n` 个字符 + 添加 1 个 `'\0'`
- **内存需求**：`dest` 必须有 `strlen(dest) + n + 1` 字节的空间

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[50] = "Hello";
    strncat(s, " World!!!", 6);
    printf("%s\n", s);  // Hello World

    // strncat 总会添加 '\0'
    char buf[10] = "Hi";
    strncat(buf, "1234567890", 5);  // 最多取 5 个，然后加 '\0'
    printf("%s\n", buf);            // Hi12345

    return 0;
}
```

### `strcmp` / `strncmp` — 字符串比较

```c
int strcmp(const char *s1, const char *s2);
int strncmp(const char *s1, const char *s2, size_t n);
```

- **功能**：按字典序（lexicographical order）比较两个字符串（逐字节比较 ASCII 值）
- **返回值**：
  - `< 0`：`s1` 小于 `s2`
  - `== 0`：`s1` 等于 `s2`
  - `> 0`：`s1` 大于 `s2`
- **`strncmp`**：只比较前 `n` 个字符

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    printf("%d\n", strcmp("abc", "abc"));   // 0（相等）
    printf("%d\n", strcmp("abc", "abd"));   // 负数（'c' < 'd'）
    printf("%d\n", strcmp("abd", "abc"));   // 正数（'d' > 'c'）
    printf("%d\n", strcmp("abc", "ab"));    // 正数（'c' > '\0'）

    // strncmp：只比较前 N 个字符
    printf("%d\n", strncmp("hello1", "hello2", 5));  // 0（前 5 个相同）

    // 常见的：比较字符串前缀
    char url[] = "https://example.com";
    if (strncmp(url, "https", 5) == 0) {
        printf("这是一个 HTTPS 链接\n");
    }

    return 0;
}
```

**关于返回值符号的说明**：C 标准只要求返回值 `>0`、`<0` 或 `==0`，不规定具体数值。因此不能假设 `strcmp("a","b")` 的值是 `-1`，只能判断其正负。实际实现通常返回字符的 ASCII 差值，但依赖这个具体值是可移植性问题。

### `strchr` / `strrchr` — 查找字符

```c
char *strchr(const char *s, int c);
char *strrchr(const char *s, int c);
```

- **`strchr`**：在字符串 `s` 中从左到右查找字符 `c`，返回第一次出现的位置指针
- **`strrchr`**：从右到左查找（reverse），返回最后一次出现的位置指针
- **返回值**：找到则返回指向该字符的指针，没找到返回 `NULL`
- **注意**：参数 `c` 虽然是 `int` 类型，但会被当作 `char` 处理；会查找 `'\0'`（即传入 0 会返回字符串结尾指针）

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[] = "hello world";

    char *p = strchr(s, 'o');
    if (p) {
        printf("找到 'o' 在偏移: %ld\n", p - s);   // 4
        printf("从该位置开始: %s\n", p);             // o world
    }

    char *q = strrchr(s, 'o');
    if (q) {
        printf("最后一个 'o' 在偏移: %ld\n", q - s); // 7
    }

    // 查找文件扩展名
    char filename[] = "data.txt";
    char *dot = strrchr(filename, '.');
    if (dot) {
        printf("扩展名: %s\n", dot);  // .txt
    }

    return 0;
}
```

### `strstr` — 查找子串

```c
char *strstr(const char *haystack, const char *needle);
```

- **功能**：在 `haystack` 中查找子串 `needle` 第一次出现的位置
- **返回值**：找到则返回指向该位置的指针，没找到返回 `NULL`
- **注意**：如果 `needle` 是空字符串 `""`，返回 `haystack` 本身

```c
#include <stdio.h>
#include <string.h>

int main(void)
{

    char url[] = "https://example.com/page";
    char *host_start = strstr(url, "://");

        host_start += 3;  // 跳过 "://"

    }

    return 0;
}
```

### `strtok` — 分割字符串

```c
char *strtok(char *str, const char *delim);
```

- **功能**：将字符串按分隔符分割成 token（标记）
- **重要特性**：
  - **会修改原字符串**：用 `'\0'` 替换分隔符
  - **内部维护静态状态**：第一次调用传入字符串，后续传入 `NULL` 继续分割
  - **线程不安全**（有线程安全版本 `strtok_r`，POSIX 标准）
- **注意**：因为会修改字符串，不能传入字符串字面量（UB！）

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    // 注意：strtok 会修改字符串，因此不能用 char* 指向字面量
    char str[] = "apple,banana,grape,orange";
    const char *delim = ",";

    printf("原始字符串: %s\n", str);

    // 第一次调用：传入字符串
    char *token = strtok(str, delim);
    while (token) {
        printf("token: %s\n", token);
        // 后续调用：传入 NULL
        token = strtok(NULL, delim);
    }
    // 输出:
    // token: apple
    // token: banana
    // token: grape
    // token: orange

    // strtok 内部有静态指针，多线程同时调用会互相干扰
    // 多线程环境应使用 strtok_r：

    return 0;
}
```

**线程安全版本（POSIX `strtok_r` 或 Windows `strtok_s`）：**

### `strspn` / `strcspn` — 跨度函数

```c
size_t strspn(const char *s, const char *accept);
size_t strcspn(const char *s, const char *reject);
```

- **`strspn`**：返回字符串 `s` 开头连续由 `accept` 中字符组成的长度（span）
- **`strcspn`**：返回字符串 `s` 开头连续**不包含** `reject` 中任何字符的长度（complement span）

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    // strspn: 统计字符串开头连续的数字字符
    char s1[] = "123abc";
    size_t n = strspn(s1, "0123456789");
    printf("开头连续数字长度: %zu\n", n);  // 3
    printf("之后的内容: %s\n", s1 + n);     // abc

    // strcspn: 找到第一个分隔符的位置
    char s2[] = "user:password";
    size_t pos = strcspn(s2, ":");
    printf("分隔符前长度: %zu\n", pos);     // 4
    printf("用户名: %.*s\n", (int)pos, s2);  // user

    return 0;
}
```

## 安全字符串函数

C 标准库的字符串函数设计于 1970 年代，当时安全不作为首要目标。现代 C 编程中，必须注意以下安全要点。

### `strncpy` 不保证 `\0` 结尾（最大陷阱）

这是 C 字符串处理中最容易踩的坑。当源字符串长度大于等于指定长度 `n` 时，`strncpy` **不会在目标末尾添加 `'\0'`**。

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char buf[5];

    // 陷阱：源字符串长度 4，但只拷贝 5 个？
    // strncpy 的 n 参数是目标 buffer 大小，不是源长度！
    strncpy(buf, "hello", sizeof(buf));  // 5 个字符，不补 '\0'
    // buf = {'h','e','l','l','o'}，没有 '\0'！

    // 如果此时用 printf("%s", buf) 或 strlen(buf) — UB！

    // 安全用法：
    strncpy(buf, "hello", sizeof(buf) - 1);  // 只拷贝 4 个
    buf[sizeof(buf) - 1] = '\0';              // 手动补 '\0'
    printf("%s\n", buf);  // hell

    return 0;
}
```

### `strncat` 保证添加 `\0`

与 `strncpy` 不同，`strncat` **一定会在结果末尾添加 `'\0'`**，即使达到了最大拷贝数量。

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char buf[10] = "Hi";
    // strncat(dest, src, n) 最多取 src 的前 n 个字符
    // 即使 n 个字符取满，也会在末尾添加 '\0'
    strncat(buf, "1234567890", 5);
    // buf = "Hi12345\0"  （5 个字符 + '\0'）
    printf("%s\n", buf);  // Hi12345

    return 0;
}
```

### `snprintf` — 推荐的字符串构建方式

`snprintf` 是 C99 标准引入的安全格式化输出函数，**始终保证以 `'\0'` 结尾**（只要 `size > 0`）。

```c
#include <stdio.h>

int main(void)
{
    char buf[16];

    // snprintf(dst, size, fmt, ...) 最多写入 size-1 个字符，然后加 '\0'
    // 返回值：本想写入的字符数（不含 '\0'）

    // 安全写法：
    int n = snprintf(buf, sizeof(buf), "%s %d", "hello", 42);
    printf("buf = \"%s\"\n", buf);  // hello 42
    printf("本想写入 %d 字节\n", n);

    // 如果返回值 >= sizeof(buf)，说明被截断了
    if ((size_t)n >= sizeof(buf)) {
        printf("警告：输出被截断！\n");
    }

    // 推荐：用 snprintf 替代 strcpy
    char src[] = "hello world";
    snprintf(buf, sizeof(buf), "%s", src);
    printf("%s\n", buf);

    // 推荐：用 snprintf 替代 strcat
    snprintf(buf, sizeof(buf), "%s %s", "part1", "part2");
    printf("%s\n", buf);

    return 0;
}
```

**最佳实践：** 在大多数场景中，`snprintf` 是比 `strcpy`、`strcat`、甚至 `strncpy` 更安全的替代方案。

### `strlcpy`（BSD，非标准）

```c
size_t strlcpy(char *dst, const char *src, size_t size);
```

- BSD 系统中提供的安全拷贝函数
- 始终保证 `\0` 结尾（`size > 0` 时）
- 返回值：`strlen(src)`（源字符串长度），可用于判断是否截断
- **不是 C 标准**，但 macOS、FreeBSD、OpenBSD 等系统支持
- Linux 上默认不可用，需自行实现或使用 `libbsd`

```c

// size_t n = strlcpy(buf, src, sizeof(buf));
// if (n >= sizeof(buf)) { printf("被截断\n"); }
```

- `strcat_s(dest, destsz, src)` — 安全拼接
- 这些是 某软件厂商扩展，**不是 C 标准**（虽然 C11 定义了 Annex K，但几乎没有实现采用）

## sscanf 与 sprintf

### `sprintf` — 格式化输出到字符串（危险！）

```c
int sprintf(char *buf, const char *format, ...);
```

- **功能**：将格式化数据写入字符串 `buf`
- **返回值**：写入的字符数（不含 `'\0'`）
- **危险**：**完全不检查缓冲区大小**，溢出是经典安全漏洞

```c
#include <stdio.h>

int main(void)
{
    char buf[10];
    // 危险！"hello 12345" 有 14 个字符，远超 buf 的 10 字节
    // int n = sprintf(buf, "%s %d", "hello", 12345);  // 溢出！UB

    // 正确做法：用 snprintf
    int n = snprintf(buf, sizeof(buf), "%s %d", "hello", 12345);
    // 如果被截断，返回值（本想写入的字符数）>= sizeof(buf)
    if ((size_t)n >= sizeof(buf)) {
        printf("输出被截断，本想写入 %d 个字符\n", n);
    }
    printf("buf = \"%s\"\n", buf);

    return 0;
}
```

### `snprintf` — 安全版本（推荐）

```c
int snprintf(char *buf, size_t size, const char *format, ...);
```

- **C99 标准**，始终保证 `'\0'` 结尾（`size > 0` 时）
- `size` 参数：输出缓冲区总大小（包括 `'\0'` 的位置）
- **返回值**：如果缓冲区足够大时**本想写入的字符数**（不含 `'\0'`）
  - 返回值 `< size`：输出完整，未被截断
  - 返回值 `>= size`：输出被截断

```c
#include <stdio.h>

int main(void)
{
    char buf[16];
    int n = snprintf(buf, sizeof(buf), "value = %d", 1234567);
    printf("buf = \"%s\"\n", buf);  // value = 1234567
    printf("本想写入 %d 个字符\n", n);

    // 截断检测
    char small[8];
    n = snprintf(small, sizeof(small), "hello world");
    if ((size_t)n >= sizeof(small)) {
        printf("截断！本想写入 %d，缓冲区只有 %zu\n", n, sizeof(small));
    }

    return 0;
}
```

### `sscanf` — 从字符串解析数据

```c
int sscanf(const char *str, const char *format, ...);
```

- **功能**：从字符串 `str` 中按格式读取数据
- **返回值**：成功匹配并赋值的输入项数，如果到达字符串末尾（遇到文件结束）则返回 `EOF`
- **注意**：`%s` 读取时遇到空白字符即停止，且**不检查目标缓冲区大小**

```c
#include <stdio.h>

int main(void)
{
    // 基本用法
    const char *data = "Alice 25 175.5";
    char name[50];
    int age;
    double height;

    int n = sscanf(data, "%49s %d %lf", name, &age, &height);
    if (n == 3) {
        printf("姓名: %s, 年龄: %d, 身高: %.1f\n", name, age, height);
    } else {
        printf("解析失败，成功匹配 %d 项\n", n);
    }

    // 常见格式说明符
    // %d   — 十进制整数（int）
    // %u   — 无符号十进制整数（unsigned int）
    // %f   — 浮点数（float）
    // %lf  — 双精度浮点数（double）
    // %s   — 字符串（注意：不检查长度！用 %Ns 限制）
    // %c   — 单个字符（不会跳过空白）
    // %x   — 十六进制整数
    // %p   — 指针地址
    // %zu  — size_t 类型
    // %zd  — ssize_t 类型

    // 解析十六进制
    unsigned int val;
    sscanf("0xFF", "%x", &val);
    printf("十六进制 0xFF = %d\n", val);  // 255

    // 解析带格式的数据
    const char *line = "2024-01-15 10:30:00";
    int year, month, day, hour, minute, second;
    sscanf(line, "%d-%d-%d %d:%d:%d",
           &year, &month, &day, &hour, &minute, &second);
    printf("日期: %d年%d月%d日 %02d:%02d:%02d\n",
           year, month, day, hour, minute, second);

    // 始终检查返回值！
    const char *bad_data = "not_a_number";
    int result;
    if (sscanf(bad_data, "%d", &result) == 1) {
        printf("值是 %d\n", result);
    } else {
        printf("解析失败\n");
    }

    return 0;
}
```

## 内存操作函数

内存操作函数不关心数据的类型，它们直接操作原始字节（`void*`），所有函数声明在 `<string.h>`。

### `memset` — 填充内存

```c
void *memset(void *s, int c, size_t n);
```

- **功能**：将 `s` 指向的内存块的前 `n` 个字节设置为 `c`（`c` 被转换为 `unsigned char`）
- **返回值**：返回 `s`
- **注意**：`memset` 按字节操作，通常用于初始化结构体或数组

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    // 清零数组
    int arr[5];
    memset(arr, 0, sizeof(arr));
    for (int i = 0; i < 5; i++)
        printf("arr[%d] = %d\n", i, arr[i]);  // 全部为 0

    // 注意：memset 按字节赋值，通常只用于 0 或 -1
    // 将 int 数组填充为 -1：因为 -1 的每个字节都是 0xFF
    memset(arr, -1, sizeof(arr));
    for (int i = 0; i < 5; i++)
        printf("arr[%d] = %d\n", i, arr[i]);  // 全部为 -1

    // 错误使用：将 int 数组填充为 1
    memset(arr, 1, sizeof(arr));
    // 每个字节是 0x01，每个 int 变成 0x01010101 = 16843009
    printf("memset 为 1 后: arr[0] = %d\n", arr[0]);  // 16843009

    // 清零结构体
    struct Point { int x, y; };
    struct Point pt;
    memset(&pt, 0, sizeof(pt));

    // 清零字符串
    char buf[20] = "some data";
    memset(buf, 0, sizeof(buf));

    return 0;
}
```

### `memcpy` — 拷贝内存（禁止重叠）

```c
void *memcpy(void *dest, const void *src, size_t n);
```

- **功能**：从 `src` 拷贝 `n` 个字节到 `dest`
- **前提**：**`src` 和 `dest` 指向的内存区域不得重叠**，否则行为是 UB
- **返回值**：返回 `dest`

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int src[5] = {1, 2, 3, 4, 5};
    int dest[5];

    // 拷贝整个数组
    memcpy(dest, src, sizeof(src));

    for (int i = 0; i < 5; i++)
        printf("dest[%d] = %d\n", i, dest[i]);

    // 拷贝结构体
    struct Data {
        int id;
        double value;
        char name[20];
    } a = {1, 3.14, "test"}, b;

    memcpy(&b, &a, sizeof(a));
    printf("b.id = %d, b.value = %.2f, b.name = %s\n",
           b.id, b.value, b.name);  // 1, 3.14, test

    // memcpy 不关心类型，也用于字符串拷贝（比 strcpy 更高效）
    char buf[20];
    memcpy(buf, "hello world", 12);  // 必须指定包括 '\0' 的长度
    printf("buf = \"%s\"\n", buf);   // hello world

    return 0;
}
```

### `memmove` — 安全移动内存（允许重叠）

```c
void *memmove(void *dest, const void *src, size_t n);
```

- **功能**：从 `src` 拷贝 `n` 个字节到 `dest`
- **与 `memcpy` 的区别**：**允许 `src` 和 `dest` 重叠**，行为定义良好
- **实现方式**：通常使用临时 buffer 或根据地址方向选择拷贝顺序
- **返回值**：返回 `dest`

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[] = "abcdef";

    // 将前 3 个字符（"abc"）移动到位置 2（从 'c' 开始）
    // memcpy(s+2, s, 3);  // UB！src 和 dest 重叠

    memmove(s + 2, s, 3);
    printf("%s\n", s);  // ababcf

    // 常见用法：删除字符串中的子串
    char str[] = "Hello, World!";
    // 删除 "World"（偏移 7，长度 5）
    memmove(str + 7, str + 12, 2);  // 移动 "!\0" 覆盖 "Wo"
    printf("%s\n", str);  // Hello, !

    return 0;
}
```

### `memcmp` — 内存比较

```c
int memcmp(const void *s1, const void *s2, size_t n);
```

- **功能**：比较 `s1` 和 `s2` 的前 `n` 个字节
- **返回值**：同 `strcmp`（`<0`、`==0`、`>0`）
- **与 `strcmp` 的区别**：`memcmp` 不会在 `'\0'` 处停止；它精确比较 `n` 个字节

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int a[] = {1, 2, 3};
    int b[] = {1, 2, 4};

    int result = memcmp(a, b, sizeof(a));
    printf("比较结果: %d\n", result);  // 负数（因为 3 < 4）

    // 比较结构体（注意：结构体可能有 padding 字节）
    // union 或 memset 清零过后的结构体比较才可靠
    struct S { int x; char y; };
    struct S s1 = {10, 'a'};
    struct S s2 = {10, 'a'};

    // 不可靠！结构体可能有未初始化的 padding 字节
    // if (memcmp(&s1, &s2, sizeof(struct S)) == 0) { ... }

    // 可靠做法：逐成员比较
    if (s1.x == s2.x && s1.y == s2.y) {
        printf("结构体相等\n");
    }

    return 0;
}
```

### `memchr` — 在内存中查找字节

```c
void *memchr(const void *s, int c, size_t n);
```

- **功能**：在 `s` 指向的内存块的前 `n` 个字节中查找字符 `c`（`unsigned char` 类型）
- **返回值**：找到返回指向该字节的指针，没找到返回 `NULL`

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char data[] = {0x10, 0x20, 0x30, 0x40, 0x50};

    void *found = memchr(data, 0x30, sizeof(data));
    if (found) {
        size_t offset = (unsigned char*)found - (unsigned char*)data;
        printf("找到 0x30 在偏移 %zu\n", offset);  // 2
    }

    return 0;
}
```

## memcpy 与 memmove 的核心区别

### 对比表

| 对比项 | `memcpy` | `memmove` |
|---|---|---|
| **重叠处理** | **不允许重叠**，重叠是 UB | **安全处理重叠** |
| **性能** | 可能稍快（可假设不重叠，做优化） | 可能稍慢（需处理重叠） |
| **使用场景** | 确定不重叠时 | 不确定是否重叠时 |
| **实现方式** | 直接逐字节或逐字拷贝 | 判断方向或使用临时 buffer |
| **返回值** | 返回 `dest` | 返回 `dest` |

### 重叠区域问题

```c
char s[] = "abcdef";
// 内存:  [a][b][c][d][e][f][\0]

// 假设我们要将位置 0 开始的 3 个字节拷贝到位置 2：
// 我们希望 s 变成 "ababcf"

// 用 memcpy 做这件事是 未定义行为（UB）！
// 因为 src = &s[0], dest = &s[2], 范围重叠

// 用 memmove 正确：
memmove(s + 2, s, 3);
// 结果: [a][b][a][b][c][f][\0]
// 即 "ababcf"
```

### 为什么 memcpy 不允许重叠

`memcpy` 的设计中，允许实现做如下优化：从前往后逐字拷贝（例如按 4 字节或 8 字节对齐拷贝）。在重叠情况下，这种优化会导致数据损坏。

```
向高地址方向拷贝（memcpy 的典型实现方向）：

  源: [a][b][c][d][e][f]
        \   \   \
         \   \   \    (拷贝到目标区域)
          \   \   \
  目标: [a][b][c][d][e][f]
         ↑       ↑
        src     dest

  如果从前向后拷贝：
  第1步: dest[0] = src[0] → s = [a][b][a][d][e][f]  (c 被 a 覆盖了！)
  第2步: dest[1] = src[1] → s = [a][b][a][b][e][f]  (c 没了！)
  第3步: dest[2] = src[2] → s = [a][b][a][b][a][f]  (还要的 c 和 d 被覆盖了！)
  结果错误！
```

`memmove` 通过判断地址方向（src < dest 时从后往前拷贝，src > dest 时从前往后拷贝）来正确解决重叠问题。

### 何时用哪个

**使用 `memcpy`（禁重叠）**：
- 两个不同的 buffer 之间的拷贝
- 确定源和目标区域不重叠的任何场景

**使用 `memmove`（允许重叠）**：
- 操作同一个数组的不同部分
- 插入、删除数组元素
- 当你不确定是否可能重叠时

**黄金法则：当有疑问时，用 `memmove`。**

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    // 场景1：不重叠 → 用 memcpy
    int src[10], dst[10];
    memcpy(dst, src, sizeof(src));  // OK

    // 场景2：同一个数组内移动 → 用 memmove
    char s[] = "abcdef";
    memmove(s + 2, s, 3);           // 安全
    printf("memmove 结果: %s\n", s); // ababcf

    // 场景3：不确定 → 用 memmove
    // 在复杂的指针运算后，你可能不确定是否重叠
    char buffer[256];
    char *a = buffer + 10;
    char *b = buffer + 20;
    // 长度 50 的拷贝，a 和 b 有重叠可能
    memmove(a, b, 50);  // 安全
    // 如果确定不重叠，memcpy(a, b, 50) 也可

    return 0;
}
```

## 字符串与数字转换

### `atoi` / `atol` / `atoll` — 简单但不安全

```c
int atoi(const char *nptr);
long atol(const char *nptr);
long long atoll(const char *nptr);
```

- **优点**：简单易用
- **严重缺点**：**没有错误检测**！无法区分"转换结果为 0"和"转换失败（输入非法）"

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("%d\n", atoi("123"));   // 123
    printf("%d\n", atoi("-42"));   // -42
    printf("%d\n", atoi("0"));     // 0
    printf("%d\n", atoi("abc"));   // 0（错误，但无法检测）
    printf("%d\n", atoi(""));      // 0（错误，但无法检测）

    // 无法区分以下两种情况：
    // 1. 输入是 "0" → 合法转换，结果是 0
    // 2. 输入是 "abc" → 转换失败，atoi 也返回 0

    // 不推荐使用 atoi！应使用 strtol

    return 0;
}
```

### `strtol` — 安全转换（推荐）

```c
long strtol(const char *nptr, char **endptr, int base);
```

- **功能**：将字符串转换为 `long` 类型整数
- **参数**：
  - `nptr`：输入字符串
  - `endptr`：接收解析结束位置的指针（可为 `NULL`）
  - `base`：进制（0 表示自动检测，2~36）
- **错误检测机制**：
  1. `errno` 被设为 `ERANGE`（超出范围）
  2. `endptr` 指向第一个未解析的字符：如果 `*endptr == nptr`，说明完全没有解析到任何数字
- **还有 `strtoll`（`long long`）、`strtoul`（`unsigned long`）等变体**

```c
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <limits.h>

int main(void)
{
    const char *input = "  123abc";
    char *end;

    errno = 0;  // 先清空 errno
    long val = strtol(input, &end, 10);

    if (errno == ERANGE) {
        // 溢出（超出 long 的取值范围）
        printf("数值超出范围\n");
    } else if (end == input) {
        // 完全没有解析到任何数字
        printf("无法解析为数字\n");
    } else {
        // 成功解析
        printf("解析结果: %ld\n", val);
        printf("剩余未解析部分: \"%s\"\n", end);
    }

    // 安全地转换并检测所有错误
    const char *tests[] = {"123", "-42", "0", "abc", "",
                           "9999999999999999999999", "  456xyz"};
    for (size_t i = 0; i < sizeof(tests) / sizeof(tests[0]); i++) {
        errno = 0;
        char *ep;
        long v = strtol(tests[i], &ep, 10);

        if (ep == tests[i]) {
            printf("\"%s\" → 转换失败（无有效数字）\n", tests[i]);
        } else if (errno == ERANGE) {
            printf("\"%s\" → 溢出\n", tests[i]);
        } else {
            printf("\"%s\" → %ld\n", tests[i], v);
        }
    }

    return 0;
}
```

double strtod(const char *nptr, char **endptr);

- 功能类似 `strtol`，用于 `double` 类型
- 还有 `strtof`（`float`）、`strtold`（`long double`）

```c

int main(void)

```

### 用 `snprintf` 将数字转换为字符串

```c
#include <stdio.h>

int main(void)
{
    char buf[32];

    int num = 12345;
    snprintf(buf, sizeof(buf), "%d", num);
    printf("int 转字符串: \"%s\"\n", buf);  // "12345"

    double pi = 3.14159;
    snprintf(buf, sizeof(buf), "%.2f", pi);
    printf("double 转字符串: \"%s\"\n", buf);  // "3.14"

```

### 最佳实践总结

| 操作 | 推荐函数 | 不推荐 |
|---|---|---|
| 字符串 → `int` | `strtol` + 错误检测 | `atoi`（无错误检测）|
| 字符串 → `long` | `strtol` | `atol` |
| 字符串 → `double` | `strtod` | — |
| `int` → 字符串 | `snprintf` | `sprintf`、`itoa`（非标准） |
| 任意数字 → 字符串 | `snprintf` | `sprintf` |

## 嵌入式中的字符串

嵌入式环境与桌面环境有显著不同，字符串操作受限于硬件资源。

### Log 缓冲区：UART 输出的环形缓冲区

```c
#include <stdio.h>
#include <string.h>
#include <stdint.h>

#define LOG_BUF_SIZE 256

static char log_buffer[LOG_BUF_SIZE];
static volatile uint16_t write_idx = 0;
static volatile uint16_t read_idx = 0;

// 将日志字符串放入环形缓冲区
int log_put(const char *str)
{
    size_t len = strlen(str);
    for (size_t i = 0; i < len; i++) {
        uint16_t next = (write_idx + 1) % LOG_BUF_SIZE;
        if (next == read_idx) {
            // 缓冲区满了，丢弃
            return -1;
        }
        log_buffer[write_idx] = str[i];
        write_idx = next;
    }
    return 0;
}

// UART 中断或轮询中逐字符发送
char log_get(void)
{
    if (read_idx == write_idx) {
        return '\0';  // 空
    }
    char c = log_buffer[read_idx];
    read_idx = (read_idx + 1) % LOG_BUF_SIZE;
    return c;
}
```

        return -4;  // 长度不足
    }

    // 提取数据载荷
    uint8_t payload[FRAME_MAX_DATA];
    memcpy(payload, &frame[3], data_len);

    return 0;
}

### 嵌入式环境的特殊约束

1. **有限的栈空间**：典型的 MCU 栈空间为 1KB ~ 8KB，不能声明大的局部数组
2. **有限的堆空间**：许多嵌入式系统根本**禁止使用 malloc/free**（实时性要求、内存碎片）
3. **静态缓冲区**：常用全局或静态数组代替动态分配
4. **无操作系统或裸机**：没有标准库支持，可能需要自己实现字符串函数
5. **Flash 中的字符串**：字符串字面量存储在 Flash（只读），用 `const` 修饰可节省 RAM

```c
// 嵌入式环境中推荐的做法
#include <stdio.h>
#include <string.h>

// 使用静态 buffer 代替栈上大数组
static char cmd_buffer[128];  // 全局静态区，不占用栈空间

void process_command(const char *cmd)
{
    // 有限栈空间下，避免大的局部数组
    // char local_buf[256];   // 可能栈溢出！
    // 改为：
    strncpy(cmd_buffer, cmd, sizeof(cmd_buffer) - 1);
    cmd_buffer[sizeof(cmd_buffer) - 1] = '\0';

    // 处理命令...
}

// 字符串字面量存于 Flash，不占 RAM
const char *get_version_string(void)
{
    // "v1.2.3" 在 Flash（.rodata）中，不占用宝贵的 RAM
    return "v1.2.3";
}
```

## 面试直连

### Q1: `sizeof` 和 `strlen` 的区别是什么？请详细说明。

**A：** 两者有本质区别：

| | `sizeof` | `strlen` |
|---|---|---|
| **类别** | 编译期运算符 | 运行期函数 |
| **返回值** | 对象占用的总字节数（含 `\0`）| 字符串的字符数（不含 `\0`）|
| **参数** | 任何类型或变量 | `const char*` |
| **对数组** | 整个数组的字节数 | 扫描到 `\0` 为止的字符数 |
| **对指针** | 指针本身的字节数（4 或 8）| 仍正常扫描字符串 |

典型例子：
```c
char s[] = "hello";
sizeof(s)  → 6（整个数组 6 字节，含 '\0'）
strlen(s)  → 5（5 个字符，不含 '\0'）

char *p = s;
sizeof(p)  → 8（64位）或 4（32位）
strlen(p)  → 5（通过指针访问字符串）
```

### Q2: `strcpy` 和 `strncpy` 哪个更安全？为什么？

**A：** `strncpy` 理论上更安全（因为它接受长度参数），但存在重大陷阱：

- `strncpy` 当源字符串长度 `>= n` 时，**不会在目标末尾加 `'\0'`**
- 这意味着使用 `strncpy` 后，**必须手动确保 `\0` 结尾**

安全用法：
```c
strncpy(buf, src, sizeof(buf) - 1);
buf[sizeof(buf) - 1] = '\0';
```

相比之下，`snprintf` 总是保证 `\0` 结尾（`size > 0` 时），是更推荐的安全选择。

### Q3: 为什么字符串字面量不可修改？

**A：** 字符串字面量存储在进程地址空间的**只读数据段（.rodata）**。操作系统将该内存页标记为只读，任何写入操作都会触发段错误（segmentation fault），导致程序崩溃。从语言标准角度看，修改字符串字面量是**未定义行为（UB）**。

如果需要一个可修改的字符串副本，应该使用数组形式：
```c
char arr[] = "hello";  // 在栈上创建可变副本
arr[0] = 'H';          // OK
```

### Q4: `memcpy` 和 `memmove` 有什么区别？什么时候用哪个？

**A：** 核心区别在于对**重叠内存区域**的处理：

- **`memcpy`**：假设源和目标区域**不重叠**，如果重叠则行为是**未定义（UB）**
- **`memmove`**：**安全处理重叠**区域，即使重叠也能得到正确结果

何时使用：
- 两个独立的 buffer 之间拷贝 → `memcpy`（可能更高效）
- 同一个 buffer 内部的移动操作 → `memmove`
- 不确定是否重叠 → **用 `memmove`**（安全第一）

实现原理：`memmove` 根据地址方向选择拷贝顺序（源地址更低时从后往前拷贝，反之从前往后拷贝），确保重叠时原始数据不会被覆盖。

### Q5: 怎样安全地拼接字符串？

**A：** 安全的字符串拼接需要确保不会发生缓冲区溢出。最佳实践：

1. **推荐：使用 `snprintf`**
```c
char buf[100] = "Hello";
size_t pos = strlen(buf);
snprintf(buf + pos, sizeof(buf) - pos, " %s!", "World");
```

2. **使用 `strncat`**（保证 `\0` 结尾）
```c
char buf[100] = "Hello";
strncat(buf, " World!", sizeof(buf) - strlen(buf) - 1);
```

3. **手动追踪剩余空间**
```c
char buf[100];
size_t remaining = sizeof(buf);
size_t written = 0;

written += snprintf(buf + written, remaining, "%s", "Hello");
remaining -= written;
written += snprintf(buf + written, remaining, "%s", " World");
```

### Q6: `atoi` 和 `strtol` 哪个更安全？为什么？

**A：** `strtol` 更安全，因为 `strtol` 提供完整的错误检测机制，而 `atoi` 完全没有错误检测。

`atoi` 的问题：
- 输入 `"abc"` → 返回 0，但输入 `"0"` → 也返回 0，**无法区分**
- 溢出时行为是**未定义（UB）**

`strtol` 的优势：
- 通过 `errno` 检测溢出（`ERANGE`）
- 通过 `endptr` 判断是否解析到任何数字
- 支持任意进制（2~36）

```c
// 安全转换示例
long safe_atoi(const char *s)
{
    char *end;
    errno = 0;
    long val = strtol(s, &end, 10);
    if (end == s || errno == ERANGE) {
        return 0;  // 或设置错误标志
    }
    return val;
}
```

### Q7: `sprintf` 和 `snprintf` 有什么区别？

**A：** 关键区别在于缓冲区大小检查：

- **`sprintf(buf, fmt, ...)`**：**不检查缓冲区大小**，如果格式化结果超过 `buf` 大小则溢出，是**未定义行为（UB）**。这是经典的安全漏洞来源。
- **`snprintf(buf, size, fmt, ...)`**：指定缓冲区大小 `size`，最多写入 `size-1` 个字符，**始终在末尾添加 `'\0'`**（`size > 0` 时）。

返回值也不同：
- `sprintf`：返回实际写入的字符数（不含 `\0`）
- `snprintf`：返回**如果缓冲区足够大时**本想写入的字符数（不含 `\0`）。如果返回值 `>= size`，说明输出被截断。

**始终使用 `snprintf` 替代 `sprintf`。**

### Q8: `strncpy` 为什么不保证 `\0` 结尾？

**A：** 这是历史原因。`strncpy` 的设计初衷并非"安全的 `strcpy`"，而是用于 UNIX 系统的目录项操作（目录项中固定使用 14 字节的文件名，不总是以 `\0` 结尾）。它的行为是：

- 如果源字符串长度 `>= n`：拷贝 `n` 个字符，**不加 `\0`**
- 如果源字符串长度 `< n`：拷贝完源字符串后，剩余部分用 `\0` 填充

这个设计导致它作为"安全字符串拷贝函数"使用时非常容易出错。现代 C 编程的最佳实践是：
1. 使用 `snprintf` 替代 `strncpy`
2. 如果必须用 `strncpy`，手动补 `\0`：`buf[sizeof(buf) - 1] = '\0'`

### Q9: 什么是缓冲区溢出？如何防止？

**A：** 缓冲区溢出是指向固定大小的缓冲区写入超过其容量的数据，导致相邻内存被覆盖。

**后果**：覆盖栈上的返回地址、局部变量等，可能导致程序崩溃或被攻击者利用执行恶意代码。

**防范措施**：
1. 始终使用带大小限制的函数（`snprintf`、`strncat` 等）
2. 手动跟踪 buffer 剩余空间
3. 不要使用 `gets()`、`sprintf()`、`strcpy()`、`strcat()` 等无边界检查的函数
4. 字符串操作后确保 `\0` 结尾
5. 使用静态分析工具（如 Coverity、Clang Static Analyzer）检测潜在溢出

### Q10: 字符数组 `char a[]` 和字符指针 `char *p` 在作为函数参数时有什么区别？

**A：** 作为函数参数时，**两者没有任何区别**。数组参数会退化（decay）为指针：

```c
void func1(char a[]) { /* a 是指针，不是数组 */ }
void func2(char *p)  { /* 完全等价于 func1 */ }
```

在这两个函数内：
- `sizeof(a)` / `sizeof(p)` 都是指针大小（8 或 4）
- 都可以通过下标 `a[i]` 或 `p[i]` 访问元素
- 都可以通过 `a++` 或 `p++` 移动指针

但 `sizeof` 在参数中不能获取数组大小，需要额外传入大小参数。

strncpy(buf, "hello world", sizeof(buf) - 1);

### 练习 4：实现 `trim` 函数

**要求：** 去掉字符串首尾的空白字符（空格、制表符 `\t`、换行符 `\n`）。要求直接修改原字符串。

```c
#include <stdio.h>
#include <string.h>

// 判断字符是否为空白
static int is_whitespace(char c)
{
    return c == ' ' || c == '\t' || c == '\n' || c == '\r';
}

// 去掉首尾空白（直接修改原字符串）
char *trim(char *s)
{
    if (s == NULL) return NULL;

    char *end;

    // 去掉开头空白
    while (is_whitespace(*s)) {
        s++;
    }

    // 如果全是空白，返回空字符串
    if (*s == '\0') {
        return s;
    }

    // 去掉结尾空白
    end = s + strlen(s) - 1;
    while (end > s && is_whitespace(*end)) {
        end--;
    }

    // 添加新的结尾 '\0'
    *(end + 1) = '\0';

    return s;
}

// 测试
int main(void)
{
    char s1[] = "   hello world   \n";
    printf("'%s'\n", trim(s1));  // 'hello world'

    char s2[] = "\t\t  ";
    printf("'%s'\n", trim(s2));  // ''

    char s3[] = "no trim";
    printf("'%s'\n", trim(s3));  // 'no trim'

    return 0;
}
```

### Bonus: 安全的字符串拼接函数

**要求：** 实现一个安全的字符串拼接函数，保证不会缓冲区溢出，且始终确保 `'\0'` 结尾。

```c
#include <stdio.h>
#include <string.h>

// 安全字符串拼接：将 src 拼接到 dest 末尾
// dest: 目标缓冲区
// dest_size: 目标缓冲区总大小
// src: 要拼接的源字符串
// 返回值: 拼接后的字符串总长度（本想写入的长度），可用于判断是否截断
size_t safe_strcat(char *dest, size_t dest_size, const char *src)
{
    if (dest == NULL || dest_size == 0) return 0;

    // 找到 dest 中现有字符串的结尾
    size_t dest_len = strlen(dest);
    if (dest_len >= dest_size) {
        // dest 本身就没有 '\0'！重新设置
        dest[dest_size - 1] = '\0';
        dest_len = dest_size - 1;
    }

    // 剩余空间
    size_t remaining = dest_size - dest_len - 1;  // 留一个给 '\0'

    // 拷贝 src，最多 remaining 个字符
    size_t i = 0;
    while (i < remaining && src[i] != '\0') {
        dest[dest_len + i] = src[i];
        i++;
    }

    // 确保 '\0' 结尾
    dest[dest_len + i] = '\0';

    // 返回本想写入的总长度（用于截断检测）
    return dest_len + strlen(src);
}

// 测试
int main(void)
{
    char buf[10] = "Hello";

    size_t wanted = safe_strcat(buf, sizeof(buf), " World!!!");
    printf("结果: '%s'\n", buf);     // 'Hello Wor'
    printf("本想写入: %zu\n", wanted); // 15
    if (wanted >= sizeof(buf)) {
        printf("警告：输出被截断！\n");
    }

    // 正常情况
    char big[50] = "Hello";
    safe_strcat(big, sizeof(big), " World");
    printf("'%s'\n", big);  // 'Hello World'

    return 0;
}
```

## 本章总结

1. **C 语言字符串**本质是**以 `\0` 结尾的字符数组（ASCIIZ）**。没有 `\0` 就不是合法的字符串。

2. **`sizeof` 与 `strlen`** 有本质区别：`sizeof` 是**编译期运算符**，返回的是包含 `\0` 的**字节数**；`strlen` 是**运行期函数**，返回的是不含 `\0` 的**字符数**。对指针使用 `sizeof` 得到的是指针本身的大小，不是字符串的长度。

3. **字符串字面量**存储在只读数据段（`.rodata`），**不可修改**。修改字符串字面量是**未定义行为（UB）**。可修改的副本应使用字符数组。

4. **标准字符串函数**（`strcpy`、`strcat` 等）**不检查缓冲区大小**，缓冲区溢出是 C 语言最常见的安全漏洞。优先使用 `snprintf` 等安全函数。

5. **`strncpy` 不保证 `\0` 结尾**，使用时必须手动添加：`buf[sizeof(buf) - 1] = '\0'`。`snprintf` 始终保证 `\0` 结尾。

6. **`memcpy` 要求源和目标不重叠**，重叠时是 **UB**。**`memmove` 安全处理重叠**。不确定时用 `memmove`。

7. **`strtol` 优于 `atoi`**，因为 `strtol` 提供完整的错误检测（溢出和非法输入）。`atoi` 无法区分"结果为 0"和"转换失败"。

8. **嵌入式环境中**，注意栈空间限制、静态 buffer 的使用和 Flash 存储的字符串字面量。

9. **不要依赖未指定的表达式求值顺序**。例如在一个函数调用中同时修改和读取同一个字符串是危险的做法。

10. **`NULL` 指针解引用是未定义行为（UB）**，任何涉及空指针的字符串操作都是不可靠的。
